# 考研微分方程核心知识点（零基础友好版）

微分方程是考研数学（数一、数二、数三均考，侧重不同）的核心板块，题型以“求解方程”和“综合应用”为主，占分约10-15分。零基础学习需遵循“**概念→分类→求解方法→真题应用**”的逻辑，以下从基础到进阶详细梳理，覆盖考研所有考点。

## 一、核心基本概念（先搞懂“是什么”）

### 1. 微分方程的定义

含有未知函数及其**导数/微分**的方程，称为微分方程（简称“方程”）。

- 未知函数是一元函数：常微分方程（考研唯一考查类型）；
- 未知函数是多元函数：偏微分方程（考研不考）。

示例：

- 一阶方程：$y' = xy$（含$y'$）、$\frac{dy}{dx} + 2y = e^x$（含$\frac{dy}{dx}$）；
- 二阶方程：$y'' + 3y' + 2y = 0$（含$y''$）、$y'' = x + y$（含$y''$）。


### 2. 微分方程的“阶”

方程中出现的**最高阶导数的阶数**，称为方程的阶。

- 一阶方程：最高导数是$y'$（或$\frac{dy}{dx}$）；
- 二阶方程：最高导数是$y''$（或$\frac{d^2y}{dx^2}$）；
- 考研重点：一阶方程（必考）、二阶线性方程（重中之重），三阶及以上极少考。


### 3. 解、通解、特解、初始条件

- **解**：代入方程后能使等式成立的函数$y = \varphi(x)$（或隐函数$\Phi(x,y)=0$）；
- **通解**：含有与方程阶数“相等个数的独立任意常数”的解（比如一阶方程通解含1个$C$，二阶含2个$C_1,C_2$）；
- **特解**：确定了通解中任意常数的具体值的解（需通过“初始条件”确定）；
- **初始条件**：用来确定通解中任意常数的条件（阶数=初始条件个数）：
    - 一阶方程：$y(x_0) = y_0$（比如$y(0)=1$）；
    - 二阶方程：$y(x_0) = y_0$，$y'(x_0) = y_0'$（比如$y(0)=0$，$y'(0)=1$）。

示例：方程$y' = 2x$的通解是$y = x^2 + C$（含1个任意常数$C$）；若加初始条件$y(1)=2$，则特解为$y = x^2 + 1$（代入得$C=1$）。

## 二、考研重点：一阶微分方程（必考，基础中的基础）

一阶微分方程的通用形式：$F(x,y,y') = 0$，核心是“转化为可积分的形式”，按类型分类求解（考试优先考以下4类）。

### 1. 可分离变量的微分方程（最基础，必须掌握）

#### （1）定义形式

能转化为“$g(y)dy = f(x)dx$”的方程（左边只含$y$和$dy$，右边只含$x$和$dx$）。
常见形式：$y' = f(x)g(y)$ 或 $\frac{dy}{dx} = \frac{f(x)}{g(y)}$。

#### （2）求解步骤（3步走）

1. 分离变量：移项得$g(y)dy = f(x)dx$（注意：$g(y)≠0$，若$g(y)=0$，可能是常数解，需补充）；
2. 两边积分：$\int g(y)dy = \int f(x)dx + C$（**右边必须加任意常数$C$**，积分结果含对数时，$C$可写成$\ln C$简化）；
3. 整理结果：得到通解（显函数或隐函数均可，考研接受隐函数形式）。

#### （3）例题

求解方程$y' = xy$（可分离变量）：

- 分离变量：$\frac{1}{y}dy = xdx$（$y≠0$）；
- 积分：$\int \frac{1}{y}dy = \int xdx + C_1$ → $\ln|y| = \frac{1}{2}x^2 + C_1$；
- 整理：令$C = e^{C_1}$（$C>0$），则$|y| = e^{\frac{1}{2}x^2 + C_1} = Ce^{\frac{x^2}{2}}$，去掉绝对值得$y = Ce^{\frac{x^2}{2}}$（$C$为任意常数，含$y=0$的情况）。


### 2. 齐次微分方程（次重点，数一、数二考频高）

#### （1）定义形式

能转化为“$\frac{dy}{dx} = \varphi\left(\frac{y}{x}\right)$”的方程（分子分母都是“同次齐次式”）。
判断方法：若$f(tx,ty) = t^n f(x,y)$，则$f(x,y)$是$n$次齐次式。例如：$\frac{dy}{dx} = \frac{x+y}{x-y}$（分子分母都是1次齐次式）。

#### （2）求解核心：换元法

令$u = \frac{y}{x}$（即$y = xu$），则$\frac{dy}{dx} = u + x\frac{du}{dx}$（乘积求导），代入方程后转化为“可分离变量方程”。

#### （3）求解步骤

1. 换元：设$u = \frac{y}{x}$，则$y = xu$，$\frac{dy}{dx} = u + x\frac{du}{dx}$；
2. 代入化简：原方程→$u + x\frac{du}{dx} = \varphi(u)$ → $x\frac{du}{dx} = \varphi(u) - u$（可分离变量）；
3. 分离积分：$\int \frac{1}{\varphi(u) - u}du = \int \frac{1}{x}dx + C$；
4. 回代：积分后将$u = \frac{y}{x}$代回，得到通解。

#### （4）例题

求解$\frac{dy}{dx} = \frac{x+y}{x-y}$：

- 换元：$u = \frac{y}{x}$ → $y = xu$，$\frac{dy}{dx} = u + x\frac{du}{dx}$；
- 代入：$u + x\frac{du}{dx} = \frac{1 + u}{1 - u}$ → 化简得$x\frac{du}{dx} = \frac{1 + u^2}{1 - u}$；
- 分离积分：$\int \frac{1 - u}{1 + u^2}du = \int \frac{1}{x}dx + C$ → $\arctan u - \frac{1}{2}\ln(1 + u^2) = \ln|x| + C$；
- 回代：$u = \frac{y}{x}$ → $\arctan\frac{y}{x} - \frac{1}{2}\ln\left(1 + \frac{y^2}{x^2}\right) = \ln|x| + C$（隐函数通解，可整理为$\arctan\frac{y}{x} = \ln\sqrt{x^2 + y^2} + C$）。


### 3. 一阶线性非齐次微分方程（必考！高频考点）

#### （1）定义形式（标准型）

$\frac{dy}{dx} + P(x)y = Q(x)$（$P(x)$、$Q(x)$是关于$x$的已知函数）：

- 若$Q(x) = 0$：一阶线性齐次方程（$\frac{dy}{dx} + P(x)y = 0$）；
- 若$Q(x) ≠ 0$：一阶线性非齐次方程（核心考查类型）。


#### （2）求解方法：常数变易法（推导通解公式）

1. 先解对应的齐次方程：$\frac{dy}{dx} + P(x)y = 0$（可分离变量）；
分离变量得$\frac{1}{y}dy = -P(x)dx$ → 积分得齐次通解：$y_h = Ce^{-\int P(x)dx}$（$C$为任意常数）。
2. 常数变易：将齐次通解中的$C$换成“关于$x$的函数$C(x)$”，设非齐次特解为$y^* = C(x)e^{-\int P(x)dx}$；
3. 代入非齐次方程：求$y^*'$，代入$\frac{dy}{dx} + P(x)y = Q(x)$，化简得$C'(x)e^{-\int P(x)dx} = Q(x)$；
4. 求$C(x)$：积分得$C(x) = \int Q(x)e^{\int P(x)dx}dx + C$；
5. 非齐次通解：$y = y_h + y^* = e^{-\int P(x)dx}\left[ \int Q(x)e^{\int P(x)dx}dx + C \right]$（**务必背熟公式！**）。

#### （3）记忆口诀

“齐次通解乘积分因子，积分非齐次项乘积分因子”，其中“积分因子”是$e^{\int P(x)dx}$（无需记符号，直接代入公式）。

#### （4）例题

求解$\frac{dy}{dx} + 2y = e^x$（标准型：$P(x)=2$，$Q(x)=e^x$）：

- 积分因子：$e^{\int 2dx} = e^{2x}$；
- 代入公式：$y = e^{-2x}\left[ \int e^x \cdot e^{2x}dx + C \right] = e^{-2x}\left[ \int e^{3x}dx + C \right]$；
- 积分计算：$\int e^{3x}dx = \frac{1}{3}e^{3x} + C$ → 通解：$y = e^{-2x}\left( \frac{1}{3}e^{3x} + C \right) = \frac{1}{3}e^x + Ce^{-2x}$。


### 4. 伯努利方程（数一、数二考，数三不考）

#### （1）定义形式

$\frac{dy}{dx} + P(x)y = Q(x)y^n$（$n≠0,1$，是常数）。

#### （2）求解核心：换元转化为线性方程

令$v = y^{1 - n}$（降幂换元），则$\frac{dv}{dx} = (1 - n)y^{-n}\frac{dy}{dx}$，代入方程得：
$\frac{1}{1 - n}\frac{dv}{dx} + P(x)v = Q(x)$ → 标准一阶线性方程：$\frac{dv}{dx} + (1 - n)P(x)v = (1 - n)Q(x)$，用线性方程公式求解后，回代$v = y^{1 - n}$。

## 三、考研核心：二阶线性微分方程（占分最高，重中之重）

二阶线性微分方程的通用形式：$y'' + P(x)y' + Q(x)y = f(x)$，考研重点考查“**二阶常系数线性方程**”（$P(x)$、$Q(x)$是常数），分为“齐次”和“非齐次”两类。

### 1. 二阶线性方程的解的结构（理论基础，必须理解）

设方程：

- 齐次方程：$y'' + P(x)y' + Q(x)y = 0$（记为方程①）；
- 非齐次方程：$y'' + P(x)y' + Q(x)y = f(x)$（记为方程②）。


#### （1）齐次方程的解的结构

- 若$y_1(x)$、$y_2(x)$是方程①的两个解，且$\frac{y_1(x)}{y_2(x)} ≠$ 常数（即“线性无关”），则方程①的通解为：$y_h = C_1y_1(x) + C_2y_2(x)$（$C_1,C_2$为任意常数）；
- 关键：齐次通解 = 两个线性无关的特解的线性组合。


#### （2）非齐次方程的解的结构

- 若$y^*$是方程②的一个特解，$y_h$是方程①的通解，则方程②的通解为：$y = y_h + y^* = C_1y_1 + C_2y_2 + y^*$；
- 叠加原理：若$f(x) = f_1(x) + f_2(x)$，且$y_1^*$是$y'' + Py' + Qy = f_1(x)$的特解，$y_2^*$是$y'' + Py' + Qy = f_2(x)$的特解，则$y_1^* + y_2^*$是原方程的特解。


### 2. 二阶常系数线性齐次微分方程（必考）

#### （1）定义形式

$y'' + py' + qy = 0$（$p,q$为常数，核心是“常系数”）。

#### （2）求解方法：特征方程法（无需积分，代数运算）

核心逻辑：假设齐次方程的特解为$y = e^{rx}$（$r$为常数），代入方程得“特征方程”，解特征根$r$，再根据根的类型写通解。

#### （3）步骤与通解形式（3种情况）

1. 写出特征方程：$r^2 + pr + q = 0$（将$y''→r^2$，$y'→r$，$y→1$）；
2. 解特征根：用求根公式$r = \frac{-p ± \sqrt{p^2 - 4q}}{2}$，分3种情况：
| 特征根情况 | 齐次通解形式 |
| :-- | :-- |
| 1. 两个不同实根（$p^2 - 4q > 0$）：$r_1 ≠ r_2$ | $y_h = C_1e^{r_1x} + C_2e^{r_2x}$ |
| 2. 两个相同实根（$p^2 - 4q = 0$）：$r_1 = r_2 = r$ | $y_h = (C_1 + C_2x)e^{rx}$（需补$xe^{rx}$，保证线性无关） |
| 3. 一对共轭复根（$p^2 - 4q < 0$）：$r_{1,2} = α ± iβ$（$α=-p/2$，$β=\frac{\sqrt{4q - p^2}}{2}$） | $y_h = e^{αx}(C_1\cosβx + C_2\sinβx)$（复根实化，考研只写实函数解） |

#### （4）例题

- 例1：求解$y'' - 3y' + 2y = 0$（特征方程$r^2 - 3r + 2 = 0$→根$r_1=1$，$r_2=2$）→ 通解：$y = C_1e^x + C_2e^{2x}$；
- 例2：求解$y'' - 2y' + y = 0$（特征方程$r^2 - 2r + 1 = 0$→根$r=1$（二重））→ 通解：$y = (C_1 + C_2x)e^x$；
- 例3：求解$y'' + 2y' + 5y = 0$（特征方程$r^2 + 2r + 5 = 0$→根$r=-1±2i$）→ 通解：$y = e^{-x}(C_1\cos2x + C_2\sin2x)$。


### 3. 二阶常系数线性非齐次微分方程（必考，难点在“求特解”）

#### （1）定义形式

$y'' + py' + qy = f(x)$（$p,q$为常数，$f(x)≠0$，考研只考2类$f(x)$）。

#### （2）求解步骤（2步）

1. 求对应齐次方程的通解$y_h$（用特征方程法，已掌握）；
2. 求非齐次方程的一个特解$y^*$（核心难点，用“待定系数法”，按$f(x)$类型设特解）；
3. 非齐次通解：$y = y_h + y^*$。

#### （3）重点：按$f(x)$类型设特解（考研高频2类）

考研只考以下2类$f(x)$，特解形式固定，直接套用即可：

##### 类型1：$f(x) = P_m(x)e^{λx}$（$P_m(x)$是$m$次多项式，$λ$是常数）

特解$y^*$的形式由$λ$是否为“特征根”决定：


| $λ$与特征根的关系 | 特解形式 | 说明（$Q_m(x)$是待定$m$次多项式：$a_0x^m + a_1x^{m-1} + ... + a_m$） |
| :-- | :-- | :-- |
| 1. $λ$不是特征根 | $y^* = Q_m(x)e^{λx}$ | 直接设$m$次多项式乘$e^{λx}$ |
| 2. $λ$是单特征根（$r_1=λ$，$r_2≠λ$） | $y^* = xQ_m(x)e^{λx}$ | 多乘一个$x$（保证与齐次解线性无关） |
| 3. $λ$是二重特征根（$r_1=r_2=λ$） | $y^* = x^2Q_m(x)e^{λx}$ | 多乘$x^2$ |

##### 类型2：$f(x) = e^{λx}[P_l(x)\cosωx + P_n(x)\sinωx]$（$P_l,P_n$是多项式，$λ,ω$为常数）

特解$y^*$的形式由$λ±iω$是否为“特征根”决定：


| $λ±iω$与特征根的关系 | 特解形式 | 说明（$R_m(x),S_m(x)$是待定$m$次多项式，$m=\max(l,n)$） |
| :-- | :-- | :-- |
| 1. $λ±iω$不是特征根 | $y^* = e^{λx}[R_m(x)\cosωx + S_m(x)\sinωx]$ | 直接设多项式乘三角函数，再乘$e^{λx}$ |
| 2. $λ±iω$是特征根（共轭复根） | $y^* = xe^{λx}[R_m(x)\cosωx + S_m(x)\sinωx]$ | 多乘一个$x$ |

#### （4）例题（类型1）

求解$y'' - 3y' + 2y = xe^x$（$f(x)=xe^x$，$P_1(x)=x$，$λ=1$）：

1. 齐次通解：特征方程$r^2 - 3r + 2 = 0$→根$r_1=1$，$r_2=2$→$y_h = C_1e^x + C_2e^{2x}$；
2. 设特解：$λ=1$是单特征根→设$y^* = xQ_1(x)e^x = x(ax + b)e^x = (ax^2 + bx)e^x$（$Q_1(x)$是1次多项式$ax + b$）；
3. 求导代入：
$y^{*'} = (2ax + b)e^x + (ax^2 + bx)e^x = (ax^2 + (2a + b)x + b)e^x$；
$y^{*''} = (2ax + 2a + b)e^x + (ax^2 + (2a + b)x + b)e^x = (ax^2 + (4a + b)x + 2a + 2b)e^x$；
代入原方程化简得：$-2ax + (2a - b) = x$；
4. 待定系数：$\begin{cases}-2a = 1 \\ 2a - b = 0\end{cases}$→$a=-\frac{1}{2}$，$b=-1$；
5. 特解：$y^* = x\left(-\frac{1}{2}x - 1\right)e^x = -\frac{1}{2}(x^2 + 2x)e^x$；
6. 非齐次通解：$y = C_1e^x + C_2e^{2x} - \frac{1}{2}(x^2 + 2x)e^x$。

#### （5）例题（类型2）

求解$y'' + y = e^x\sinx$（$f(x)=e^x\sinx$，$λ=1$，$ω=1$，$P_l=0$，$P_n=1$）：

1. 齐次通解：特征方程$r^2 + 1 = 0$→根$r=±i$→$y_h = C_1\cosx + C_2\sinx$；
2. 设特解：$λ±iω=1±i$不是特征根→设$y^* = e^x(A\cosx + B\sinx)$（$m=\max(0,0)=0$，多项式为常数$A,B$）；
3. 求导代入化简：解得$A=-\frac{1}{2}$，$B=0$；
4. 特解：$y^* = -\frac{1}{2}e^x\cosx$；
5. 通解：$y = C_1\cosx + C_2\sinx - \frac{1}{2}e^x\cosx$。

## 四、可降阶的二阶微分方程（数一、数二考，数三不考）

对于“非二阶常系数线性方程”，若能通过“降阶”转化为一阶方程，则可求解。考研只考3类，核心是“换元法”。

### 1. 类型1：$y'' = f(x)$（不含$y$和$y'$）

#### 求解方法：直接积分2次

- 第一次积分：$y' = \int f(x)dx + C_1$；
- 第二次积分：$y = \int \left[ \int f(x)dx + C_1 \right]dx + C_2 = \int\int f(x)dx^2 + C_1x + C_2$。

示例：$y'' = x$→$y' = \frac{1}{2}x^2 + C_1$→$y = \frac{1}{6}x^3 + C_1x + C_2$。

### 2. 类型2：$y'' = f(x,y')$（不含$y$）

#### 求解方法：设$p = y'$，则$y'' = p'$（降为一阶方程）

- 换元：令$p = y'$，则$y'' = \frac{dp}{dx} = p'$，代入方程得$\frac{dp}{dx} = f(x,p)$（一阶方程）；
- 求解一阶方程得$p = φ(x,C_1)$；
- 回代$p = y'$：$y' = φ(x,C_1)$→积分得$y = \int φ(x,C_1)dx + C_2$。

示例：$y'' = \frac{1}{x}y'$（不含$y$）：

- 设$p = y'$→$p' = \frac{1}{x}p$（可分离变量）→$\frac{dp}{p} = \frac{dx}{x}$→$\ln p = \ln x + C_1$→$p = C_1x$；
- 回代：$y' = C_1x$→$y = \frac{1}{2}C_1x^2 + C_2$。


### 3. 类型3：$y'' = f(y,y')$（不含$x$）

#### 求解方法：设$p = y'$，则$y'' = p\frac{dp}{dy}$（降为一阶方程）

- 换元：令$p = y'$，则$y'' = \frac{dp}{dx} = \frac{dp}{dy} \cdot \frac{dy}{dx} = p\frac{dp}{dy}$（链式法则，关键！）；
- 代入方程得$p\frac{dp}{dy} = f(y,p)$（一阶方程，变量为$y$和$p$）；
- 求解一阶方程得$p = φ(y,C_1)$（或隐函数形式）；
- 回代$p = \frac{dy}{dx}$：$\frac{dy}{φ(y,C_1)} = dx$→积分得$\int \frac{dy}{φ(y,C_1)} = x + C_2$。

示例：$yy'' - (y')^2 = 0$（不含$x$）：

- 设$p = y'$→$y'' = p\frac{dp}{dy}$，代入得$y \cdot p\frac{dp}{dy} - p^2 = 0$→$p\left( y\frac{dp}{dy} - p \right) = 0$；
- 情况1：$p=0$→$y'=0$→$y=C$（常数解）；
- 情况2：$y\frac{dp}{dy} - p = 0$→$\frac{dp}{p} = \frac{dy}{y}$→$p = C_1y$；
- 回代：$\frac{dy}{dx} = C_1y$→$\frac{dy}{y} = C_1dx$→$\ln y = C_1x + C_2$→$y = C_2e^{C_1x}$（含常数解$y=C$）。


## 五、考研补充考点（按数学类型区分）

### 1. 欧拉方程（数一专属，考频低）

#### （1）定义形式

$x^n y^{(n)} + a_1x^{n-1}y^{(n-1)} + ... + a_{n-1}xy' + a_n y = f(x)$（考研只考二阶：$x^2y'' + pxy' + qy = f(x)$）。

#### （2）求解方法：变量替换（$x = e^t$或$t = \ln x$）

令$t = \ln x$（$x>0$），则$xy' = \frac{dy}{dt}$，$x^2y'' = \frac{d^2y}{dt^2} - \frac{dy}{dt}$，代入方程转化为“二阶常系数线性方程”，求解后回代$t = \ln x$。

### 2. 差分方程（数三专属，考频中等）

#### （1）核心概念

- 差分：$\Delta y_t = y_{t+1} - y_t$（一阶差分），$\Delta^2 y_t = \Delta y_{t+1} - \Delta y_t$（二阶差分）；
- 一阶线性常系数差分方程：$y_{t+1} + ay_t = f(t)$（$a$为常数）。


#### （2）求解方法

- 齐次方程（$f(t)=0$）：通解$y_h = C(-a)^t$；
- 非齐次方程（$f(t)≠0$）：通解$y = y_h + y^*$，特解$y^*$按$f(t)$类型设（类似二阶线性方程）：
    - $f(t) = P_m(t)$（多项式）：$y^* = Q_m(t)$（$a≠-1$）或$y^* = tQ_m(t)$（$a=-1$）；
    - $f(t) = b^t$（$b>0,b≠1$）：$y^* = kb^t$（$b≠-a$）或$y^* = ktb^t$（$b=-a$）。


## 六、考研常见题型与易错点

### 1. 高频题型

（1）直接求解各类方程（一阶线性、二阶常系数非齐次是重点）；
（2）结合初始条件求特解（注意初始条件的代入时机：通解求出后立即代入，避免复杂计算）；
（3）综合题：

- 微分方程与积分方程互化（比如$\int_0^x f(t)dt = f(x) - 1$，两边求导得$f'(x)=f(x)$）；
- 微分方程与导数应用结合（比如求曲线$y=y(x)$，满足$y''=2$，且在点$(1,3)$处切线斜率为1）；
- 物理应用（数二）：比如牛顿第二定律（加速度与力的关系，转化为微分方程）。


### 2. 易错点

（1）一阶线性方程忘记“标准型”：必须整理为$\frac{dy}{dx} + P(x)y = Q(x)$再代公式，避免符号错误；
（2）二阶非齐次方程特解设法错误：比如$λ$是二重特征根却只乘1个$x$；
（3）特征方程求解错误：二次方程求根时符号出错（比如$r^2 + 2r + 1=0$的根是$r=-1$，不是$r=1$）；
（4）积分时遗漏任意常数$C$：通解中必须含足够的任意常数（一阶1个，二阶2个）。

## 七、零基础学习建议

1. 先掌握“一阶线性方程”和“二阶常系数线性方程”（占考试80%分值），再学齐次、可降阶方程；
2. 每个类型至少做5道例题，重点练“特解设法”和“积分计算”（考研方程的积分都能积出来，不用怕复杂积分）；
3. 真题驱动：学完知识点后直接做近10年真题的微分方程题，总结命题规律（比如数三常考一阶线性和差分方程，数一常考二阶常系数和欧拉方程）。

按照以上逻辑学习，零基础也能在2-3周内掌握考研微分方程的核心内容，后续通过真题巩固即可。如果需要某类方程的更多例题或真题解析，可以进一步补充！
