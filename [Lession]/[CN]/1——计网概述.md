# 计算机网络第一章

## 1.1 计算机网络概述（上）

### 计算机网络基本概念

- **广义观点**：实现远程信息处理的系统，或能进一步达到资源共享的系统。
- **资源共享观点**：以能够相互共享资源的方式互联起来的自治计算机系统的集合。
  - 目的：资源共享
  - 组成单元：分布在不同地理位置的多台独立的“自治计算机”
  - 网络协议：网络中计算机必须遵循的统一规则
- **用户透明性观点**：能为用户自动管理资源的网络操作系统，能够调用用户所需要的资源，整个网络就像一个大的计算机系统一样对用户是透明的。

### 计算机网络的组成

#### 1. 组成部分角度

- **硬件**：主机（端系统）、通信链路（双绞线、光纤）、交换设备（路由器、交换机）、通信处理机（网卡等）
- **软件**：实现资源共享的软件及方便用户使用的各类工具软件（网络操作系统、邮件收发程序、FTP程序、聊天程序）
- **协议**：计算机网络的核心，规定了网络传输数据遵循的规则

#### 2. 工作角度

- **核心部分**：由大量的网络和连接这些网络的路由器组成，为边缘部分提供连通性和交换服务。
- **边缘部分**：由所有连接到因特网上、供用户直接使用的主机组成，用于通信（传输数据、音频或视频）和资源共享，用户直接使用，包含两种方式：
  - C/S方式（客户机/服务器方式）
  - P2P方式（对等方式）

#### 3. 功能组成角度

- **通信子网**：由传输介质、通信设备及相应网络协议组成，使网络具备数据传输、交换、控制和存储能力，实现联网计算机之间的数据通信。
- **资源子网**：实现资源共享功能的硬件和软件的集合，向网络用户提供共享其他计算机硬件、软件和数据的服务。

### 计算机网络的功能

- **数据通信**：最基本、最重要的功能，实现联网计算机之间的信息传输，将分散的计算机联系起来。
- **资源共享**：实现软件、硬件、数据的共享，使计算机网络中的资源互通有无、分工协作，提高硬件、软件和数据资源的利用率。
- **分布式处理**：将某个负载过重的计算机任务分散到多台计算机上，提高整个系统的利用率。
- **提高可靠性**：各台计算机可通过网络互为替代机，当某台计算机故障时，其他计算机可替代其工作。
- **负载均衡**：将工作任务均衡分配给计算机网络中的各台计算机，避免单台计算机负载过高。

### 计算机网络的分类

#### 1. 按分布范围分类

| 类别       | 范围                                     | 距离               | 地位/技术                                            |
| ---------- | ---------------------------------------- | ------------------ | ---------------------------------------------------- |
| 广域网     | 提供长距离通信，运送主机发送的数据       | 几十千米到几千千米 | 因特网核心部分，采用高速链路，通信容量大，用交换技术 |
| 城域网     | 跨越几个街区甚至几个城市                 | 5~50km             | 多采用以太网技术                                     |
| 局域网     | 微机或工作站通过高速线路相连，覆盖范围小 | 几十米到几千米     | 对计算机配置数量无过多限制，采用广播技术             |
| 个人区域网 | 个人工作区域内，电子设备用无线技术连接   | 区域直径10m        | 以无线连接为主                                       |

#### 2. 按传输技术分类

- **广播式网络**：
  - 所有联网计算机共享一个公共通信信道，采用广播通信技术。
  - 一台计算机发送报文分组，其他计算机可收听该分组（根据报文目的地址决定是否接收）。
  - 广域网中的无线、卫星通信网络也采用广播式通信技术。
- **点对点网络**：
  - 每个物理线路连接一对计算机，采用分组存储转发机制。
  - 计算机通过直接或中间结点对分组进行接收、存储和转发，直至到达目的地。

#### 3. 按拓扑结构分类

- **星形网络**：每个终端或计算机都以单独的线路与中央设备相连。
  - 优点：便于集中控制和管理
  - 缺点：成本高，中心节点对故障敏感
- **总线形网络**：用单根传输线把计算机连接起来。
  - 优点：建网容易，增减节点方便，节省线路
  - 缺点：重负载时通信效率不高，总线任意处故障影响整个网络
- **环形网络**：所有计算机接口设备连接成一个环，典型代表为令牌环局域网。
- **网状形网络**：每个结点至少有两条链路与其他节点相连，形成网状结构。
  - 优点：可靠性高
  - 缺点：成本高，控制复杂

#### 4. 按使用者分类

- **公用网**：供公众使用的网络。
- **专用网**：为满足某个部门特殊业务需求建立的网络（如军队、电力、铁路专用网）。

#### 5. 按传输介质分类

- **有线网络**：双绞线网络、同轴电缆网络等。
- **无线网络**：蓝牙、微波、无线电等。

### 计算机网络的标准化工作及相关组织

#### 1. 生成RFC的过程

因特网草案 → 建议标准 → 草案标准 → 因特网标准

#### 2. 国际标准化组织

- **国际标准化组织（ISO）**：制定OSI参考模型、HDLC协议。
- **国际电信联盟（ITU）**：制定远程通信标准。
- **国际电气电子工程师协会（IEEE）**：制定802标准（如局域网相关标准）。

### 计算机网络的性能指标

- **带宽**：网络在通信线路中传送数据的能力，单位为“比特/每秒（bit/s）”。
- **时延**：数据从网络一端传送到另一端所需的总时间，包含四类时延：
  1. **发送时延**：从发送分组的第一个比特开始，到最后一个比特发送结束的时间，公式：`发送时延 = 分组长度 / 信道带宽`。
  2. **传播时延**：一个比特从链路一端到另一端所需的时间，公式：`传播时延 = 信道长度 / 电磁波在信道上的传播速率`。
  3. **处理时延**：数据在交换结点为存储转发而进行必要处理的时间（如分析分组首部、提取数据部分、差错检验、寻找合适路由器）。
  4. **排队时延**：分组进入路由器后，等待被转发的时间。
- **时延带宽积**：发送端连续发送数据且第一个比特即将到达终点时，发送端已发出的比特数，公式：`时延带宽积 = 传播时延 * 信道带宽`。
- **往返时延**：从发送数据到接收到接收端确认的总时延。
- **吞吐量**：单位时间内通过某个网络的数据量，受网络带宽或网络额定速率限制。
- **速率**：连接到计算机网络的主机在数字信道上传送数据的速率（又称数据率或比特率），最高数据率即为带宽。

## 1.2 计算机网络体系结构与参考模型（上）

### 网络分层

#### 1. 分层原则

1. 每层实现一种相对独立的功能，降低系统复杂度。
2. 各层之间界面清晰，易于理解，相互交流少。
3. 各层功能的精确定义独立于具体实现方法，可采用最合适的技术实现。
4. 保持下层对上层的独立性，上层单向使用下层提供的服务。
5. 整个分层结构应能促进标准化工作。

#### 2. 基本概念

- **实体**：任何可以发送或接收信息的硬件（如网卡）或软件进程（如通信程序）。
- **对等层**：不同机器上的同一层；**对等实体**：同一层的实体。
- **服务数据单元（SDU）**：为完成用户要求的功能而传送的数据，第n层的SDU称为“n-SDU”。
- **协议控制信息（PCI）**：控制层协议操作的信息，第n层的PCI称为“n-PCI”。
- **协议数据单元（PDU）**：对等层次之间传送的数据单元，第n层的PDU称为“n-PDU”。

#### 3. 层次结构含义

- 最底层只提供服务，是整个层次结构的基础；中间各层既是下一层的服务使用者，又是上一层的服务提供者；最高层面向用户提供服务。
- 上一层只能通过邻近层的接口使用下一层的服务，不能调用其他层的服务；下一层服务的实现细节对上一层透明。
- 两台主机通信时，对等层在逻辑上有一条直接信道，表现为不经过下层就把信息传送到对方。

### 计算机网络协议、接口、服务的概念

#### 1. 协议

- 定义：控制两个或多个对等实体进行通信的规则集合，是**水平方向**的（仅对等实体间遵循）。
- 组成：
  - **语义**：规定要完成的功能（如“接收方需发送确认”）。
  - **同步**：规定执行各种操作的条件和时序关系（如“发送方先发数据，接收方后发确认”）。
  - **语法**：规定传输数据的格式（如分组首部的字段结构）。
- 特点：不对等实体之间无协议。

#### 2. 接口

- 定义：一个节点内相邻两层间交换信息的连接点，是系统内部的规则，是**垂直方向**的。
- 特点：每层仅为紧邻的层次定义接口，不能为非紧邻层定义接口；下层通过接口为紧邻上层提供功能调用。

#### 3. 服务

- 定义：下层为紧邻上层提供的功能调用，只有本层协议的实现才能保证向上层提供服务；服务用户（上层）仅能看见服务，无法看见下层协议。
- **服务原语**（服务的调用/响应方式）：
  - 请求：由服务用户发往服务提供者，请求完成某项任务。
  - 响应：由服务用户发往服务提供者，作为对“指示”的响应。
  - 指示：由服务提供者发往服务用户，指示用户做某件事情。
  - 证实：由服务提供者发往服务用户，作为对“请求”的证实。

### 面向连接服务和无连接服务

| 类型         | 特点                                                             | 阶段/代表协议                                     |
| ------------ | ---------------------------------------------------------------- | ------------------------------------------------- |
| 面向连接服务 | 可靠服务，通信双方需先建立连接、分配资源，结束后释放连接与资源   | 阶段：连接建立→数据传输→连接释放；代表协议：TCP |
| 无连接服务   | 不可靠服务，通信双方无需建立连接，直接发送数据（尽最大努力交付） | 代表协议：IP、UDP                                 |

### 服务的分类

#### 1. 按可靠性分类

- **可靠服务**：网络具备纠错、检错、应答机制，保证数据正确、可靠地传送到目的地。
- **不可靠服务**：网络尽可能正确、可靠地传送数据，但不能保证数据一定到达；可靠性由应用或用户保障。

#### 2. 按是否应答分类

- **有应答服务**：接收方收到数据后，自动向发送方发出应答；应答由传输系统实现。
- **无应答服务**：接收方收到数据后，不自动给出应答；若需应答，由高层（如应用层）实现。

## 1.2 计算机网络体系结构与参考模型（中）

### OSI参考模型

- **核心目的**：支持异构网络系统的互联互通。
- **分层结构**（从下到上）：物理层、数据链路层、网络层（三者构成**通信子网**）、传输层（承上启下）、会话层、表示层、应用层（三者构成**资源子网**）。

| 层次       | 传输单位                        | 核心任务                                                        | 主要功能                                                                                                                                                | 典型协议/标准                  |
| ---------- | ------------------------------- | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ |
| 物理层     | 比特流                          | 透明传输比特流                                                  | 1. 定义数据终端设备（DTE）与数据通信设备（DCE）的物理/逻辑连接方法；2. 在物理媒体上透明传输原始比特流；3. 规定接口的机械形状、尺寸及交换电路的数量/排列 | EIA-232C、EIA/TIA RS-449、X2.1 |
| 数据链路层 | 帧                              | 将网络层传来的IP数据报组装成帧                                  | 1. 成帧（添加帧头/帧尾）；2. 差错控制（检错、丢弃错误帧）；3. 流量控制（控制发送方速率）；4. 传输管理；5. 介质访问子层控制共享信道访问                  | SDLC、HDLC、PPP、STP、帧中继   |
| 网络层     | 数据报                          | 将分组从源端传到目的端，为分组交换网上的不同主机提供通信服务    | 1. 流量控制；2. 拥塞控制（缓解网络丢包问题）；3. 差错控制；4. 网际互联（通过路由器连接异构网络）                                                        | IP、IPX、ICMP、ARP、RARP、OSPF |
| 传输层     | 报文段（TCP）/用户数据报（UDP） | 实现主机之间两个进程的相互通信，作为资源子网与通信子网的桥梁    | 为应用层提供端到端的通信服务                                                                                                                            | TCP、UDP                       |
| 会话层     | -                               | 允许不同主机上的各个进程之间进行“通话”                        | 1. 建立会话；2. 同步管理主机间的会话进程（建立、管理、终止）；3. 用校验点恢复通信，实现数据同步                                                         | -                              |
| 表示层     | -                               | 处理两个通信系统中交换信息的表示方式                            | 1. 数据压缩；2. 数据加密与解密；3. 数据表示变换（如格式转换）                                                                                           | -                              |
| 应用层     | -                               | 作为用户与网络的界面，为特定类型的网络应用提供访问OSI环境的手段 | 为应用程序提供网络服务                                                                                                                                  | FTP、SMTP、HTTP                |

### TCP/IP模型

- **分层结构**（从下到上）：网络接口层、网际层、传输层、应用层，对应OSI模型的不同层次，是因特网的核心协议体系。

| 层次       | 对应OSI层次              | 核心任务                                             | 主要功能                                                                                                                                           | 典型协议/标准                |
| ---------- | ------------------------ | ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| 网络接口层 | 数据链路层 + 物理层      | 从主机或结点接收IP分组，并将其发送到指定的物理网络   | 1. 指出主机必须使用的协议与网络连接；2. 实现IP分组与物理网络帧的转换                                                                               | -（依赖具体物理网络协议）    |
| 网际层     | 网络层                   | 将分组发送到任何网络，为分组选择合适的路由           | 定义IP协议（IPv4、IPv6），实现异构网络互联                                                                                                         | IP（IPv4、IPv6）、ICMP、ARP  |
| 传输层     | 传输层                   | 实现主机上对等实体的会话，为应用层提供端到端通信服务 | 1. TCP：面向连接、可靠交付，传输单位为报文段；2. UDP：无连接、不可靠交付（尽最大努力），传输单位为用户数据报，不保证有序到达（有序交付由高层负责） | TCP、UDP                     |
| 应用层     | 会话层 + 表示层 + 应用层 | 为特定网络应用提供服务，是用户与网络的交互接口       | 包含所有高层协议，实现具体应用功能                                                                                                                 | Telnet、FTP、DNS、SMTP、HTTP |

## 1.2 计算机网络体系结构与参考模型（下）

### TCP/IP模型与OSI模型的比较

#### 1. 相同点

- 都采用分层结构，将复杂网络功能拆解为独立层次实现。
- 都基于“独立协议栈”的概念，每层协议独立设计、各司其职。
- 都能解决异构网络的互联问题，实现不同厂家计算机的相互通信。

#### 2. 不同点

| 对比维度             | OSI模型                                                | TCP/IP模型                                                                         |
| -------------------- | ------------------------------------------------------ | ---------------------------------------------------------------------------------- |
| 协议与接口定义       | 精确定义服务接口和协议，通用性良好，适用于各类网络系统 | 是对已有协议的描述，仅适用于TCP/IP体系，不适用于非TCP/IP协议，未明确区分服务与协议 |
| 异构网络互联考虑     | 未充分考虑多种异构网络的互联问题                       | 从设计之初就考虑异构网络互联，是因特网的核心协议体系                               |
| 网络层（网际层）功能 | 支持无连接和面向连接两种通信方式                       | 仅支持无连接通信（IP协议）                                                         |
| 传输层功能           | 支持无连接和面向连接两种通信方式                       | 支持面向连接（TCP）和无连接（UDP）两种通信方式                                     |

### 信息传输过程

1. **发送端处理**：用户发送数据报时，应用层首先将自然语言（或用户数据）转化为可传输的通信数据；之后，数据从应用层向下传递，每经过一层，该层会在数据前添加“服务数据单元（SDU）”和“协议控制信息（PCI）”，形成该层的“协议数据单元（PDU）”，完成“包裹包装”。
2. **接收端处理**：数据到达目的主机后，从最底层（物理层）向上传递，每经过一层，该层会拆去自身添加的SDU和PCI，逐步剥离“包裹”；最终到达应用层时，数据恢复为原始的用户数据，供接收方使用。

（注：原文末尾“传输层只有面向连接”为表述误差，结合TCP/IP模型传输层含TCP（面向连接）和UDP（无连接），此处以整体协议逻辑为准。）
