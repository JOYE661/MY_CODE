# 第2章 数据表示和运算

## 2.1 数制与编码（上）

### 2.1.1 进位计数制及其相互转换

#### 1. 基本概念

- **核心特点**：**逢X进一**（X进制），即每一位的数值达到X时向高位进1。
- **常见种类**：十进制、二进制、八进制、十六进制。

#### 2. 各进制特点

| 进制     | 组成元素                      | 权值规则                                                         | 与二进制关系                                 | 关键说明                             |
| -------- | ----------------------------- | ---------------------------------------------------------------- | -------------------------------------------- | ------------------------------------ |
| 二进制   | 0、1组成                      | 任意数位的权值为2^i，i为从右起的位数（注意：i是从零开始计数的）  | 计算机底层唯一使用的进制                     | 最基础的计算机数据表示形式           |
| 八进制   | 0~7组成                       | 任意数位的权值为8^i，i为从右起的位数（注意：i是从零开始计数的）  | 二进制的3位数码编为一组（3位二进制最大为7）  | 二进制的简化书写形式                 |
| 十六进制 | 0~9、A~F组成（A-F对应10-15） | 任意数位的权值为16^i，i为从右起的位数（注意：i是从零开始计数的） | 二进制的4位数码编为一组（4位二进制最大为15） | 二进制的常用简化书写形式（缩短位数） |

#### 3. 进制转换方法

1. **二进制 ↔ 八进制/十六进制**

   - 二进制转八进制：将二进制数从右往左每3位编为一组（不足3位左补0），每组对应1位八进制数。
   - 二进制转十六进制：将二进制数从右往左每4位编为一组（不足4位左补0），每组对应1位十六进制数。
   - 八进制/十六进制转二进制：反向操作，1位八进制数拆为3位二进制数，1位十六进制数拆为4位二进制数。
2. **八进制 ↔ 十六进制**间接转换：先将其中一种进制转为二进制，再由二进制转为目标进制。
3. **任意进制 → 十进制**按权展开求和：任意进制的每一位数码 × 该位的权值（X^i），再将所有乘积相加（X为进制基数，i为从右起的位数，从0开始）。
4. **十进制 → 任意进制**

   - 整数部分：**除基取余法**（除以进制基数，取余数，余数倒序排列即为结果）。
   - 小数部分：**乘基取整法**（乘以进制基数，取整数部分，整数部分正序排列即为结果）。
   - 注意：任意二进制小数都可以用十进制表示，但并非每个十进制小数都能用二进制精确表示（如0.3）。

### 2.1.2 真值和机器数

- **真值**：带符号的实际数值，如-1、+2、-3、+4等（直接体现正负和数值大小）。
- **机器数**：计算机中表示真值的二进制编码，常用**最高位作为符号位**（0表示正数，1表示负数），其余位为数值位。

### 2.1.3 BCD码

BCD码（Binary-Coded Decimal）是用二进制表示十进制数的编码，常用类型如下：

1. **8421码（最常用，有权码）**

   - 规则：用4位二进制数表示1位十进制数（0~9），4位的权值分别为8、4、2、1。
   - 修正规则：若两个8421码相加后的和小于9（十进制），结果有效；若和≥10或有进位，需加6（十进制，即0110）进行修正。
2. **余3码（无权码）**

   - 规则：在对应8421码的基础上加3（二进制0011）。
   - 示例：十进制8的余3码为8421码1000 + 0011 = 1011。
3. **2421码（有权码）**

   - 权值：从高到低为2、4、2、1。
   - 规则：≥5的4位二进制数最高位为1，<5的最高位为0。
   - 示例：十进制5的2421码为1011（2×1 + 4×0 + 2×1 + 1×1 = 5）。

## 2.1 数制与编码（下）

### 2.1.4 字符与字符串

#### 1. 字符串编码：ASCII码

- 本质：7位二进制编码，可表示128个字符（包括大小写字母、数字、标点符号、控制字符等）。
- 存储：每个ASCII编码通常用**两个字节**（16位）表示（高位补0）。

#### 2. 汉字的表示和编码

汉字在计算机中的处理需经过3种编码，分别对应不同阶段：

- **输入编码**：用于将汉字输入计算机，如拼音码、五笔字型码等（用户与计算机的输入接口）。
- **汉字内码**：计算机内部处理汉字时使用的编码（唯一标识汉字，避免与ASCII码冲突）。
- **汉字字形码**：用于汉字输出（如显示、打印），存储汉字的字形点阵或矢量信息。

#### 3. 字符串存放：大端模式与小端模式

- **大端模式**：将数据的**最高有效字节**存放在**低地址单元**中，后续字节按地址递增顺序存放。
- **小端模式**：将数据的**最高有效字节**存放在**高地址单元**中，后续字节按地址递增顺序存放。
- 通用规则：字符串从低地址到高地址逐个字符存储，常采用“\0”作为结尾标志。

### 2.1.5 校验码

校验码是通过添加冗余码实现“检错”或“纠错”的数据编码，核心是通过“码距”提升可靠性（码距：两个编码中不同二进制位的个数）。

#### 1. 奇偶校验码

- **原理**：在有效信息位后添加1位校验位，使“有效信息位+校验位”中1的个数满足指定奇偶性。
  - 奇校验码：1的总个数为奇数。
  - 偶校验码：1的总个数为偶数。
- **码距**：2。
- **局限**：仅能检测奇数位错误，无法检测偶数位错误，且不能纠错。

#### 2. 海明码

- **核心功能**：不仅能检测错误，还能对单比特错误进行纠错（需额外添加“全校验位”时，可实现1位纠错、2位检错）。
- **原理**：在有效信息位中插入若干校验位，通过校验位与信息位的固定对应关系定位错误。
- **关键特性**：
  - 编码最小码距L越大，检错位数越多，纠错能力越强（纠错能力 ≤ 检错能力，需先检错再纠错）。
  - 部分题目中校验位/信息位的位置编号可能从小到大排列，但处理逻辑一致。

#### 3. CRC（循环冗余码）

- **适用场景**：大量数据传送时的检错（如网络通信）。
- **校验过程**：
  1. 发送端：将有效数据作为被除数，生成多项式（预先约定）作为除数，进行**模2除法**，余数作为CRC校验码，附加在有效数据后发送。
  2. 接收端：将接收到的“有效数据+CRC校验码”作为被除数，用相同生成多项式做模2除法；若余数为0，无错误；若余数不为0，对相应位置取反纠错。
- **检错能力**：
  - 可检测出所有奇数个错误。
  - 可检测出所有双比特错误。
  - 可检测出所有小于等于校验位长度的连续错误。
- **纠错条件**：若选择合适的生成多项式，且满足2^R > K+R+1（R为校验位位数，K为有效信息位位数），则可纠正单比特错误。

## 2.2 定点数的表示与运算

### 2.2.1 定点数的表示

定点数是小数点位置固定的机器数，分为“无符号数”和“有符号数”，后者需用符号位表示正负。

#### 1. 无符号数与有符号数

- **无符号数**：整个机器字长的全部二进制位均为数值位，无符号位（仅表示非负整数）。
- **有符号数**：最高位为符号位（0表示正，1表示负），其余位为数值位（表示正负整数或小数）。

#### 2. 定点数的分类（按小数点位置）

| 类型     | 定义                   | 小数点约定位置                     |
| -------- | ---------------------- | ---------------------------------- |
| 定点小数 | 纯小数（仅含小数部分） | 符号位之后、有效数值部分最高位之前 |
| 定点整数 | 纯整数（仅含整数部分） | 有效数值部分的最低位之后           |

#### 3. 有符号数的表示方法（原码、反码、补码、移码）

##### （1）原码表示法

- **规则**：最高位为符号位（0正1负），其余位为数值的绝对值。
- **表示范围**（字长为n+1位，1位符号位+ n位数值位）：
  - 纯小数：-(1-2^(-n)) ≤ X ≤ 1-2^(-n)（关于原点对称）。
  - 纯整数：-(2^n - 1) ≤ X ≤ 2^n - 1（关于原点对称）。
- **真值零的表示**：不唯一（正零：00000，负零：10000）。
- **局限**：加减法运算复杂（需判断符号、比较绝对值大小）。

##### （2）反码表示法

- **规则**：
  - 正数：反码 = 原码（符号位0，数值位不变）。
  - 负数：反码 = 符号位不变，数值位按位取反。
- **表示范围**（字长n+1位）：
  - 纯小数：-(1-2^(-n)) ≤ X ≤ 1-2^(-n)（关于原点对称）。
  - 纯整数：-(2^n - 1) ≤ X ≤ 2^n - 1（关于原点对称）。
- **真值零的表示**：不唯一（正零：00000，负零：11111）。
- **作用**：原码与补码相互转换的过渡工具。

##### （3）补码表示法

- **核心优势**：简化加减法运算（无需判断符号，符号位与数值位一同参与运算）。
- **规则**：
  - 正数：补码 = 原码（符号位0，数值位不变）。
  - 负数：补码 = 原码符号位不变，数值位按位取反后加1（或“反码+1”）。
- **表示范围**（字长n+1位）：
  - 纯小数：-1 ≤ X ≤ 1-2^(-n)（比原码多表示-1）。
  - 纯整数：-2^n ≤ X ≤ 2^n - 1（比原码多表示-2^n）。
- **真值零的表示**：唯一（全0，如00000）。
- **补码的算术移位**（实现除法功能）：
  - 正数：左移/右移均添0（符号位不变，数值位移位后补0）。
  - 负数：左移添0，右移添1（符号位保持1不变）。
- **变形补码（模4补码）**：符号位用2位（00表示正，11表示负），用于检测溢出。

##### （4）移码表示法

- **适用场景**：常用于表示浮点数的阶码（仅表示整数）。
- **规则**：移码 = 补码的符号位取反（或“真值 + 偏置值”，偏置值通常为2^n）。
- **表示范围**（字长n+1位）：-2^n ≤ X ≤ 2^n - 1（与补码相同）。
- **真值零的表示**：唯一（如10000，取决于偏置值）。
- **关键特性**：移码的数值越大，对应的真值越大（便于阶码比较）；最小值为-2^n（全0），最大值为2^n - 1（全1）。

#### 4. 不同机器数的转换关系

- 正数：原码 = 反码 = 补码；移码 = 补码符号位取反。
- 负数：
  1. 原码 → 反码：符号位不变，数值位取反。
  2. 反码 → 补码：反码 + 1。
  3. 补码 → 原码：符号位不变，数值位取反后加1（或“补码的补码 = 原码”）。
  4. 补码 → 移码：符号位取反。

### 2.2.2 定点数的运算（上）

#### 1. 定点数的移位运算

移位运算分为“算术移位”“逻辑移位”“循环移位”，核心是改变数据的位序或数值大小。

| 移位类型 | 适用场景       | 移位规则                                                             | 符号位参与情况         |
| -------- | -------------- | -------------------------------------------------------------------- | ---------------------- |
| 算术移位 | 有符号数运算   | 正数添0；负数左移添0、右移添1                                        | 参与（保持符号位不变） |
| 逻辑移位 | 无符号数运算   | 左移/右移均添0（视为无符号数，高位/低位补0）                         | 不参与（无符号位概念） |
| 循环移位 | 数据位循环利用 | 带进位标志位：移位时携带进位位循环；不带进位标志位：仅数据位内部循环 | 视情况参与             |

#### 2. 原码定点数的加减法运算

##### （1）加法准则

- 符号相同：绝对值相加，符号不变（若有进位，需处理进位）。
- 符号不同：绝对值大的减去绝对值小的，符号取绝对值大的数的符号。

##### （2）减法准则

1. 将减数的符号取反（变为“-减数”的原码）。
2. 按原码加法规则与被减数相加。

#### 3. 补码定点数的加减法运算

- **核心规则**：无需判断符号，直接对补码进行二进制加法（逢二进一），符号位与数值位同时参与运算，符号位产生的进位直接丢掉，结果仍为补码。
- 具体步骤：
  1. 将被减数和减数均转换为补码。
  2. 计算“被减数补码 + 减数补码”（减法运算转化为“加负数补码”，即[A - B]补 = [A]补 + [-B]补）。
  3. 符号位产生的进位丢弃，结果的符号由运算自然得出。

#### 4. 符号扩展（位数扩展）

当需要将定点数的字长扩展时，需保持真值不变，扩展规则如下：

| 数的类型  | 符号扩展规则                                    |
| --------- | ----------------------------------------------- |
| 正数      | 无论原码/反码/补码，均在高位添0（凑足目标位数） |
| 负数-原码 | 符号位移至新符号位，新增高位添0                 |
| 负数-补码 | 符号位移至新符号位，新增高位添1                 |
| 负数-反码 | 符号位移至新符号位，新增高位添1                 |

#### 5. 溢出概念和判别方法

- **溢出定义**：运算结果超出机器数的表示范围（上溢：大于最大正数；下溢：小于最小负数）。
- **判别方法**：

##### （1）一位符号位判别法

- 规则：若参与运算的两个数符号相同，但结果符号与 operand 符号不同，则发生溢出。
- 示例：正数+正数=负数（上溢）；负数+负数=正数（下溢）。

##### （2）双符号位（模4补码）判别法

- 符号位用2位（00=正，11=负），结果符号位组合对应的溢出情况：
  - 00：正数，无溢出。
  - 01：正溢出（上溢）。
  - 10：负溢出（下溢）。
  - 11：负数，无溢出。

##### （3）一位符号位+进位判别法

- 规则：符号位的进位（C_s）与最高数值位的进位（C_1）相同，则无溢出；若不同，则溢出（C_s ⊕ C_1 = 1 表示溢出）。

### 2.2.2 定点数的运算（下）

#### 1. 定点数的乘法运算

##### （1）原码一位乘法

- **核心逻辑**：符号位与数值位分开运算，数值部分按“累加-移位”实现。
- 步骤：
  1. 符号位：由被乘数与乘数的符号位异或（0为正，1为负），不参与数值运算。
  2. 数值部分：取被乘数与乘数的绝对值，初始化部分积为0，按乘数的每一位（从最低位开始）判断：
     - 若乘数当前位为1，部分积 += 被乘数绝对值；
     - 部分积右移1位，乘数右移1位（丢弃当前位）。
  3. 重复步骤2，共进行n次（n为数值位位数），最终结果为“符号位 + 最终部分积”。
- **关键参数**：部分积（n+1位）、乘数（n位）、累加次数（n次）、移位方向（右移）。

##### （2）补码一位乘法（Booth算法）

- **核心逻辑**：符号位参与运算，无需单独处理，通过“累加-移位”实现补码乘法。
- 步骤：
  1. 初始化部分积为0（n+2位，含符号位），乘数补码扩展为n+1位（最低位后加1位辅助位，初始为0）。
  2. 根据乘数的最低2位（当前位与辅助位）判断操作：
     - 00或11：部分积右移1位，辅助位移入当前位，当前位移出。
     - 01：部分积 += 被乘数补码，右移1位。
     - 10：部分积 -= 被乘数补码（即 += [-被乘数]补），右移1位。
  3. 重复步骤2，共进行n+1次（n为数值位位数），最终结果为部分积的前n+1位（含符号位）。
- **关键参数**：部分积（n+2位）、乘数（n+1位+1位辅助位）、累加次数（n+1次）、移位方向（右移）。

#### 2. 定点数的除法运算

##### （1）原码除法运算（不恢复余数法）

- **核心逻辑**：符号位与数值位分开运算，通过“加减-移位”避免余数恢复，提高效率。
- 步骤：
  1. 符号位：由被除数与除数的符号位异或（0为正，1为负），不参与数值运算。
  2. 数值部分：取被除数与除数的绝对值，初始化余数为被除数绝对值，商为0。
  3. 重复n次（n为数值位位数）：
     - 余数左移1位，减去除数绝对值；
     - 若余数≥0，商的最低位补1；若余数<0，商的最低位补0，余数 += 除数绝对值（间接恢复余数）。
  4. 最终结果为“符号位 + 商”，余数需调整符号（与被除数符号一致）。
- **关键参数**：商符（单独计算）、商值（n位）、加减次数（n+1或n+2次）、移位方向（左移）。

##### （2）补码除法运算（加减交替法）

- **核心逻辑**：符号位参与运算，无需单独处理，通过“交替加减-移位”实现补码除法。
- 步骤：
  1. 初始化余数为被除数补码，除数补码为操作数，商为0。
  2. 若被除数与除数同号，余数 -= 除数补码；若异号，余数 += 除数补码。
  3. 重复n次（n为数值位位数）：
     - 余数左移1位；
     - 若余数与除数同号，余数 -= 除数补码，商补1；若异号，余数 += 除数补码，商补0。
  4. 商末位恒置1（修正误差）；若最终余数为负，需恢复余数（余数 += 除数补码）。
- **关键参数**：符号位（参与运算）、商值（n位，末位恒置1）、加减次数（n+1次）、移位方向（左移）。

#### 3. 强制类型转换

- 原理：将一种机器数（如原码、补码）按目标码的规则重新解读，本质是改变二进制的解释方式，而非改变二进制本身。
- 示例：将十进制数5的二进制101，按8421码规则解读为5，按余3码规则解读为2（101 - 011 = 010）。

## 2.3 浮点数的表示与运算

### 2.3.1 浮点数的表示

浮点数是小数点位置可浮动的机器数，用于表示大范围的数值（如科学计数法），格式为：**数符（S） + 阶码（E） + 尾数（M）**，即 `N = (-1)^S × M × R^E`（R为基数，通常为2）。

#### 1. 各部分功能

- **数符（S）**：表示浮点数的符号（0为正，1为负），1位。
- **阶码（E）**：表示小数点的偏移量（整数），由“阶符 + 阶码数值”组成，决定浮点数的表示范围。
- **尾数（M）**：表示浮点数的有效数值（纯小数），决定浮点数的精度（尾数位数越多，精度越高）。

#### 2. 规格化浮点数

规格化是为了使尾数的有效数字最大化（避免冗余），不同基数和编码的规格化规则不同：

| 基数 | 编码类型 | 规格化规则                                          | 关键特征                                 |
| ---- | -------- | --------------------------------------------------- | ---------------------------------------- |
| 2    | 原码     | 正数：0.1XXX...X（尾数最高位为1）；负数：1.1XXX...X | 尾数最高位为1                            |
| 2    | 补码     | 正数：0.1XXX...X；负数：1.0XXX...X                  | 正数最高位1，负数最高位0（与符号位不同） |
| 4    | 原码     | 尾数最高2位不全为0                                  | 避免2位全0的冗余                         |
| 8    | 原码     | 尾数最高3位不全为0                                  | 避免3位全0的冗余                         |

- **规格化操作**：
  - 左规：尾数算术左移1位，阶码减1（适用于尾数最高位为0的情况），可多次进行。
  - 右规：尾数算术右移1位，阶码加1（适用于尾数溢出的情况），仅能进行1次。

#### 3. IEEE 754标准（主流浮点数标准）

IEEE 754标准定义了短浮点数（单精度）、长浮点数（双精度）、临时浮点数（扩展精度），格式统一为“数符（1位） + 阶码（含偏置值） + 尾数（隐含整数部分1）”。

| 类型               | 总位数 | 数符（S） | 阶码（E） | 尾数数值（M） | 阶码偏置值（十进制） | 尾数隐含位 | 表示范围（近似）                  |
| ------------------ | ------ | --------- | --------- | ------------- | -------------------- | ---------- | --------------------------------- |
| 短浮点数（单精度） | 32     | 1         | 8         | 23            | 127                  | 隐含1      | 2^(-126) ~ 2^(127)×(2-2^(-23))   |
| 长浮点数（双精度） | 64     | 1         | 11        | 52            | 1023                 | 隐含1      | 2^(-1022) ~ 2^(1023)×(2-2^(-52)) |
| 临时浮点数         | 80     | 1         | 15        | 64            | 16383                | 无隐含位   | 范围更大，精度更高                |

- **关键说明**：
  - 阶码：采用移码表示，实际阶码 = 阶码字段值 - 偏置值。
  - 尾数：采用原码表示，隐含整数部分“1”（如尾数字段为M，实际尾数为1.M），仅临时浮点数无隐含位。
  - 特殊值：阶码全0且尾数全0表示机器零；阶码全1且尾数全0表示无穷大；阶码全1且尾数非0表示NaN（非数值）。

#### 4. 定点数与浮点数的区别

| 对比维度   | 定点数                                   | 浮点数                           |
| ---------- | ---------------------------------------- | -------------------------------- |
| 表示范围   | 范围小（字长固定时）                     | 范围大（阶码决定）               |
| 精度       | 精度均匀（每一位的权值固定）             | 精度不均匀（阶码越大，精度越低） |
| 运算复杂度 | 运算简单（加减法直接对齐，乘法仅需移位） | 运算复杂（需对阶、规格化、舍入） |
| 溢出判断   | 运算结果超出数值位范围即溢出             | 仅规格化后阶码超出范围才溢出     |
| 存储开销   | 相同字长下存储效率高                     | 需额外存储阶码，存储开销略大     |

### 2.3.2 浮点数的加减运算

浮点数加减法需通过“对阶、尾数求和、规格化、舍入、溢出判断”5个步骤实现，核心是先统一小数点位置（对阶），再按定点小数运算。

#### 1. 运算步骤

##### （1）对阶：小阶看齐大阶

- 目的：使两个浮点数的阶码相等，确保小数点位置一致。
- 规则：比较两个浮点数的阶码，阶码小的浮点数，其尾数右移1位，阶码加1，重复此操作直到两阶码相等（右移尾数会损失精度，需后续舍入处理）。

##### （2）尾数求和

- 方法：将对阶后的两个尾数按“定点小数补码加减法规则”运算（符号位参与运算，数值位相加/减）。

##### （3）规格化

- 目的：使尾数满足规格化要求，保证精度。
- 规则：
  - 若尾数求和结果为“00.1XXX...X”（正数）或“11.0XXX...X”（负数），已规格化，无需操作。
  - 若尾数求和结果溢出（如“01.XXX...X”或“10.XXX...X”），需右规：尾数右移1位，阶码加1。
  - 若尾数求和结果未溢出但未规格化（如“00.0XXX...X”或“11.1XXX...X”），需左规：尾数左移1位，阶码减1，直到规格化。

##### （4）舍入：减少尾数右移的精度损失

舍入的核心是对尾数移位后丢弃的位进行处理，常用方法：

1. **0舍1入法**：

   - 尾数右移时，若移去的最高数值位为0，直接舍去；若为1，尾数末位加1（可能产生进位，需再次规格化）。
2. **恒置1法**：

   - 尾数右移时，无论移去的位是0还是1，均将尾数的末位恒置为1（操作简单，精度略低于0舍1入法）。
3. **截断法**：

   - 直接丢弃移去的位（精度最低，易产生误差，较少使用）。

##### （5）溢出判断

- 浮点数的溢出仅由**阶码**决定（尾数溢出可通过规格化纠正）：
  - 上溢：规格化后阶码大于最大可表示阶码（如单精度阶码>127），结果超出范围，需进入中断处理。
  - 下溢：规格化后阶码小于最小可表示阶码（如单精度阶码<-126），结果接近零，按“机器零”处理（数符、阶码、尾数全置0）。

#### 2. 强制类型转换（不同精度浮点数/定点数 ↔ 浮点数）

- **char → int**：在char的二进制前面补0（扩展为int的字长，符号位按原char的符号扩展）。
- **int ↔ unsigned int**：仅改变二进制的解释方式（无符号数视为非负，有符号数最高位为符号位），可能因溢出丢失数据（如int的负数转为unsigned int会变为大正数）。
- **int ↔ float**：
  - int转float：int的二进制转换为float的规格化形式，可能因尾数位数不足（float尾数23位）导致数据舍入（精度损失）。
  - float转int：截断小数部分，若float数值超出int的表示范围，会发生溢出（结果错误）。

#### 3. 存储相关：字节编址与边界对齐

- **字节编址**：现代计算机通常按字节编址，即每个字节（8位）对应1个唯一的内存地址。
- **边界对齐**：为提高访问效率，计算机支持按字节、半字（16位）、字（32位）、双字（64位）寻址，要求数据存储在对应大小的地址边界上（如半字数据需存在偶地址，字数据需存在4的整数倍地址）。

## 2.4 算术逻辑单元（ALU）

ALU（Arithmetic and Logic Unit）是计算机的核心运算部件，负责执行所有算术运算（加、减、乘、除）和逻辑运算（与、或、非、异或）。

### 2.4.1 串行加法器和并行加法器

加法器是ALU的基础模块，按进位传递方式分为“串行加法器”和“并行加法器”。

#### 1. 位全加器（基础单元）

- **输入**：两个1位加数（A_i、B_i）、低位进位（C_i）。
- **输出**：本位和（S_i）、向高位的进位（C_{i+1}）。
- **逻辑表达式**：
  - 本位和：S_i = A_i ⊕ B_i ⊕ C_i
  - 进位输出：C_{i+1} = (A_i ∧ B_i) ∨ (A_i ∧ C_i) ∨ (B_i ∧ C_i)

#### 2. 串行加法器

- **结构**：仅包含1个位全加器，数据逐位送入加法器运算，逐位将结果送回寄存器。
- **运算过程**：先计算最低位（A_0、B_0、C_0=0），产生S_0和C_1；再计算次低位（A_1、B_1、C_1），产生S_1和C_2；依此类推，直到最高位。
- **特点**：
  - 优点：结构简单，成本低。
  - 缺点：速度慢（n位操作数需进行n次加法，进位串行传递）。

#### 3. 并行加法器

- **结构**：包含n个位全加器（n为操作数字长），每个全加器对应1位数据，同时接收加数和低位进位，并行产生本位和与高位进位。
- **核心问题**：进位传递速度（各级进位相互依赖，会影响运算速度）。
- **进位方式**：

  1. **串行进位（异步进位）**：

     - 规则：将n个全加器串联，每级进位依赖前一级进位（C_{i+1}依赖C_i）。
     - 特点：结构简单，但速度慢（进位传递延迟随n增大而增加）。
  2. **并行进位（同步进位）**：

     - 规则：通过“进位产生函数”和“进位传递函数”，使各级进位信号同时形成（不依赖前一级进位）。
     - 特点：速度快（进位延迟仅与门电路延迟有关），但结构复杂（需额外的进位逻辑电路）。
- **关键结论**：提高并行加法器速度的核心是加快进位产生和传递速度（如采用并行进位、分组并行进位）。

### 2.4.2 算术逻辑单元的功能和结构

#### 1. ALU的核心功能

- **算术运算**：加法、减法、乘法、除法、增量（+1）、减量（-1）、求补等。
- **逻辑运算**：与、或、非、异或、同或、移位（逻辑移位、算术移位）等。
- **控制功能**：根据指令的“运算控制信号”选择执行对应的运算（如ALU控制端输入不同编码，选择加法或逻辑与）。

#### 2. ALU的典型结构

ALU通常由以下部件组成：

- **运算器核心**：并行加法器（实现加法和减法，减法通过“加补码”实现）。
- **逻辑运算单元**：与门、或门、异或门等（实现逻辑运算）。
- **移位器**：实现数据的移位操作（支持算术移位、逻辑移位）。
- **控制电路**：接收CPU的控制信号，选择运算类型（算术/逻辑）和具体操作。
- **状态寄存器（FLAGS）**：存储运算结果的状态（如进位标志CF、溢出标志OF、零标志ZF、符号标志SF等），供CPU判断后续操作。

#### 3. ALU与其他部件的配合

- **累加器（ACC）**：临时存储运算数和运算结果（如加法中，累加器存储被加数和最终和）。
- **通用寄存器组**：提供除累加器外的其他运算数存储（如乘法中，通用寄存器存储乘数）。
- **数据总线**：传输ALU与内存、寄存器之间的数据。
- **控制总线**：传输CPU对ALU的控制信号（如运算类型、启动信号）。
