# 第6章 总线

## 6.1 总线概述

### 一、总线基本概念

#### （一）总线的定义

总线是一组能为多个部件分时共享的公共信息传送线路，包含以下两个核心特性：

- **分时**：同一时刻只允许有一个部件向总线发送信息。
- **共享**：总线上可以挂接多个部件，各个部件之间互相交换的信息可通过这组线路分时共享。

#### （二）总线设备

- **主设备**：获得总线控制权的设备。
- **从设备**：被主设备访问的设备，只能响应主设备发来的各种总线命令。

#### （三）总线特性

1. **电气特性**：规定传输方向和有效的电平范围。
2. **机械特性**：定义总线的尺寸和形状。
3. **功能特性**：明确每根传输线的具体功能。
4. **时间特性**：描述信号和时序之间的关系。

#### （四）总线的猝发传输

一个总线周期内，传输存储地址连续的多个数据字的总线传输方式，称为猝发传输。

### 二、总线的分类

#### （一）按连接范围分类

1. **片内总线**：芯片内部的总线，是CPU芯片内部寄存器与寄存器之间、寄存器与ALU之间的公共连接线。
2. **系统总线**：各个功能部件之间相互连接的总线，包含三类子总线：
   - **数据总线**：传输各功能部件之间的数据信息，为双向传输总线。
   - **地址总线**：传输数据总线上源数据或目的数据所在的主存单元或I/O端口地址，为单向传输总线；其位数与机器字长、存储字长及主存地址空间大小有关。
   - **控制总线**：传输控制信息，包括CPU送出的控制命令和主存返回CPU的反馈信号。
3. **通信总线**：计算机系统之间或计算机系统与其他系统之间传送信息的总线，又称外部总线。

#### （二）按其他维度分类

| 分类依据     | 具体类型 | 说明 |
| ------------ | -------- | ---- |
| 时序控制方式 | 同步总线 | -    |
|              | 异步总线 | -    |
| 数据传输格式 | 并行总线 | -    |
|              | 串行总线 | -    |

### 三、系统总线的结构

#### （一）单总线结构

- **结构**：将CPU、主存、I/O设备都挂载到一组总线上。
- **优点**：结构简单、成本低、容易接入新设备。
- **缺点**：带宽低、负载重；多个部件只能争用唯一的总线，且不支持并发传送操作。

#### （二）双总线结构

- **结构**：一条是主存总线，用于CPU、主存和通道之间传送数据；另一条是I/O总线，用于多个外部设备和通道之间传送数据。
- **优点**：将低速I/O设备从单总线上分离出来，实现了存储总线和I/O总线分离。
- **缺点**：需要增加通道等硬件设备。

#### （三）三总线结构

- **结构**：计算机系统各部件之间采用三条独立总线构成信息通路，分别是主存总线、I/O总线、直接内存访问（DMA）总线。
- **优点**：提高了I/O设备的性能，使其更快响应命令，提升系统吞吐量。
- **缺点**：系统工作效率较低。

### 四、总线的性能指标

1. **总线传输周期**：一次总线操作所需的时间，包含申请阶段、寻址阶段、传输阶段和结束阶段，由若干个总线时钟周期构成。
2. **总线时钟周期**：即机器的时钟周期。
3. **总线的工作频率**：总线周期的倒数。
4. **总线的时钟频率**：时钟周期的倒数。
5. **总线带宽**：单位时间内总线可传输的数据位数，是总线本身的最大传输率，是衡量总线性能的重要指标。
6. **总线复用**：一种信号线在不同时间传输不同的信息，可节约空间和成本。
7. **信号线数**：地址总线、数据总线、控制总线三种总线的数量总和。

## 6.2 总线仲裁

### 一、集中仲裁方式

集中仲裁方式依赖中央仲裁器进行总线控制权分配，主要有以下三种类型：

#### （一）链式查询方式

- **控制线**：1根总线请求线、1根总线忙线、1根总线允许线。
- **优先级规则**：越靠近总线控制器的部件优先级越高。
- **优点**：优先级固定、结构简单、扩充容易。
- **缺点**：对电路故障敏感、优先级不可变。

#### （二）计数器定时查询方式

- **控制逻辑**：使用计数器控制总线使用权。
- **优点**：设备优先级相等、优先次序可以改变。
- **缺点**：增加了控制线数、控制较为复杂。

#### （三）独立请求方式

- **控制线**：每个设备均有1根请求线与1根总线允许线。
- **优点**：响应速度快、优先次序控制灵活。
- **缺点**：控制线数多、总线控制逻辑更复杂。

#### （四）三种集中仲裁方式对比

| 仲裁方式       | 控制线数                                                                                     | 优点                           | 缺点                         |
| -------------- | -------------------------------------------------------------------------------------------- | ------------------------------ | ---------------------------- |
| 链式查询       | 总线请求：1；总线忙：1；总线允许：1（共3根）                                                 | 优先级固定；结构简单；扩充容易 | 对电路故障敏感；优先级不灵活 |
| 计数器定时查询 | $\lceil\log_{2}n\rceil + 2$（总线请求：1；总线忙：1；总线允许：$\lceil\log_{2}n\rceil$） | 优先级灵活                     | 控制线多；控制复杂           |
| 独立请求       | $2n + 1$（总线请求：$n$；总线允许：$n$；总线忙：1）                                    | 响应速度快；优先级灵活         | 控制线多；控制复杂           |

### 二、分布仲裁方式

- **原理**：不需要中央仲裁器，每个潜在主模块都有自己的仲裁号和仲裁器；通过比较仲裁号，获胜者的仲裁号保留在仲裁总线上，从而获得总线控制权。

## 6.3 总线操作和定时

### 一、总线传输的4个阶段

1. **申请分配阶段**：设备提出总线使用申请。
2. **寻址阶段**：获得使用权的主设备，发出要访问模块的地址及相关命令，启动本次传输的从模块。
3. **传输阶段**：主模块与从模块进行双向或单向的数据传送。
4. **结束阶段**：主模块将有关信息从系统总线上撤除，让出总线使用权。

### 二、定时方式

#### （一）同步定时方式

- **原理**：系统采用一个统一的时钟信号，协调发送和接收双方的传送定时关系。
- **适用场景**：总线长度较短、总线所接部件存取时间比较接近的系统。
- **优点**：传送速度快、传输速率高、总线控制逻辑简单。
- **缺点**：主从设备属于强制性同步，不能及时进行数据通信的有效性检验，可靠性较差。

#### （二）异步定时方式

- **原理**：没有统一的时钟，完全按照传送双方相互制约的握手信号实现定时控制。
- **优点**：总线周期长度可变，可保证两个速度相差较大的部件或设备之间的信息传输。
- **缺点**：控制相对复杂，速度相对较慢。
- **分类**：
  1. **不互锁方式**：主设备发送请求信号后，不必等待从设备应答信号，经过一段时间便撤销请求信号。
  2. **半互锁方式**：主设备发送请求信号后，必须接到从设备应答信号，才能撤销请求信号。
  3. **全互锁方式**：主设备发送请求信号，从设备应答；主设备撤销请求信号后，从设备知晓主设备已获得应答信号，再撤销应答信号。

## 6.4 总线标准

### 一、系统总线相关标准

1. **ISA**：最早出现的微型计算机总线。
2. **EISA**：ISA的扩展形式。
3. **VESA**：针对系统高速传送活动图像大量数据的局部总线。
4. **PCI**：为外围设备使用的总线，支持即插即用，可通过桥连接。
5. **PCI-Express**：最新的总线和接口标准，用于代替PCI和AGP。
6. **AGP**：视频接口标准，用于连接主存和图形存储器。

### 二、设备总线相关标准

1. **RS-232C**：应用于串行二进制交换的数据终端设备（DTE）和数据通信设备（DCE）之间的接口标准。
2. **USB**：支持即插即用和热插拔，采用串行传输方式，是连接外部设备的I/O总线，具有很强的连接能力和良好的可扩充性。
3. **PCMCIA**：用于扩展功能的小型插槽，支持即插即用。
4. **IDE**：集成设备电路，又称ATA，是一种IDE接口磁盘驱动器接口类型。
5. **SCSI**：用于计算机和智能设备之间系统级接口的独立处理器标准，是一种智能的通用接口标准。
6. **SATA**：基于行业标准的串行硬件驱动器接口。
