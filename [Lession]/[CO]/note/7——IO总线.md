# 第7章 I/O系统

## 7.1 I/O系统基本概念

### 一、I/O系统组成

#### （一）硬件部分

- **外部设备**：包括输入设备、输出设备以及需通过输入/输出接口访问的外存储设备。
- **设备控制器和接口**：在主机与外设间传输数据时，负责协调工作的逻辑部件。
- **I/O总线**：连接主机与外部设备，用于传输数据、地址和控制信号的公共线路。

#### （二）软件部分

包括驱动程序、用户程序、管理程序、升级补丁，通常通过**I/O指令**和**通道指令**实现CPU与I/O设备的交互。

### 二、核心组件定义

| 组件类型 | 定义                                                               |
| -------- | ------------------------------------------------------------------ |
| 输入设备 | 向计算机系统输入命令、文本、数据等信息的部件，如键盘、鼠标。       |
| 输出设备 | 将计算机系统中的信息输出到外部并显示的部件，如显示器、打印机。     |
| 外存设备 | 除内存、CPU缓存外的存储器，如硬盘、光盘、固态硬盘。                |
| 接口     | 协调主机与外设间数据传输的逻辑部件，解决时序配合、速度差异等问题。 |

### 三、I/O控制方式分类

1. **程序查询方式**：CPU通过程序持续查询I/O设备是否就绪，进而控制数据交换；主要用于数据传输率较低的外设。
2. **程序中断方式**：仅当I/O设备就绪并向CPU发送中断请求时，CPU才响应并处理；适用于中低速外设。
3. **DMA方式**：主存与I/O设备间有直接数据通道，数据交换时无需占用CPU执行中断服务程序；主要用于数据传输率较高的设备。
4. **通道方式**：系统设通道控制部件，每个通道挂接多个外设；主机启动通道后，由通道执行通道程序完成I/O操作。

## 7.2 外部设备（上）

### 一、输入设备

#### （一）键盘

- **运作流程**：1. 检测按下的按键；2. 将按键翻译为主机可接收的键码（如ASCII码）；3. 将键码发送给主机。

#### （二）鼠标

- **运作原理**：鼠标在平面移动时，底部传感器检测移动距离与方向，进而控制光标移动。
- **常见类型**：机械式鼠标、光电式鼠标。

### 二、输出设备

#### （一）显示器

1. **按显示器件分类**

   | 类型              | 原理                                                                     | 优点                                                   | 缺点                         |
   | ----------------- | ------------------------------------------------------------------------ | ------------------------------------------------------ | ---------------------------- |
   | 阴极射线管（CRT） | 由电子枪、偏转线圈、荫罩等组成，通过电子束轰击荧光粉发光                 | 可视角度大、无坏点、色彩还原度高、色度均匀、响应时间短 | 显示复杂图形时可能出现闪烁感 |
   | 液晶显示器（LCD） | 利用液晶电光效应，由图像信号电压控制薄膜晶体管，进而控制液晶分子光学特性 | 体积小、重量轻、省电、无辐射、绿色环保、画面柔和不伤眼 | -                            |
   | 发光二极管（LED） | 控制半导体发光二极管显示文字、图形、图像                                 | 亮度、功耗、可视角度、刷新速率均优于LCD                | -                            |
2. **按显示信息分类**：字符显示器、图形显示器、图像显示器。
3. **主要参数**

   - **屏幕大小**：以屏幕对角线长度衡量。
   - **分辨率**：屏幕能显示的像素总数，即宽×高。
   - **灰度级**：黑白显示器中像素的亮暗差别，彩色显示器中颜色的层次；灰度级越高，图像越清晰逼真。
   - **刷新与刷新频率**：光点需定期重新扫描才能保持显示，单位时间内扫描整个屏幕的次数为刷新频率；≥30Hz时人眼无闪烁感，常见频率60-120Hz。
   - **显示存储器（VRAM）**：又称刷新存储器，存储一帧图像数据。
     - 容量计算公式：**VRAM容量 = 分辨率 × 灰度级位数**
     - 带宽计算公式：**VRAM带宽 = 分辨率 × 灰度级位数 × 帧频**

#### （二）打印机

| 类型         | 原理                                                                     | 优点                                                          | 缺点                                   |
| ------------ | ------------------------------------------------------------------------ | ------------------------------------------------------------- | -------------------------------------- |
| 针式打印机   | 主机发打印命令，经接口、控制电路驱动送纸和打印头移动，打印头冲击色带印字 | 擅长多层复写打印、可打印票据/蜡纸、原理简单、造价低、耗材便宜 | 打印分辨率低、速度慢                   |
| 喷墨式打印机 | 带电喷墨雾点经电极偏转后，直接在纸上形成字形                             | 打印噪声小、可实现高质量彩色打印、速度比针式快                | 防水性差、打印成本高、需专用打印纸     |
| 激光打印机   | 激光束经调制扫描感光鼓形成潜像，再经显影、转印、定影完成打印             | 打印质量高、速度快、噪声小、处理能力强                        | 耗材多、价格贵、不能复写、对纸张要求高 |

## 7.2 外部设备（下）

### 一、磁表面存储器

#### （一）硬盘存储器

1. **组成**

   - **磁头**：读取/写入盘片记录面信息，一个记录面对应一个磁头。
   - **存储区域参数**：柱面数（每个盘片的磁道数）、扇片数（每条磁道的扇区数）。
   - **磁盘驱动器**：核心为磁头组件和盘片组件。
   - **磁盘控制器**：硬盘与主机的接口，如IDE、SCSI、SATA等。
2. **磁记录原理**

   - **工作方式**：磁头与磁性记录介质相对运动，通过“电转磁”完成写操作，“磁转电”完成读操作。
   - **编码方法**：将二进制信息转换为存储介质磁层的磁化翻转序列，便于读写控制电路实现。
   - **记录方式**：常用调频制（FM）、改进型调频制（MFM）。
3. **性能指标**

   - **容量**：
     - 非格式化容量：存储介质可利用的磁化单元总数。
     - 格式化容量：按特定记录方式实际可记录信息的总量。
   - **记录密度**：
     - 道密度：沿磁盘半径方向单位长度的磁道数。
     - 位密度：磁道单位长度可记录的二进制代码位数。
     - 面密度：位密度与道密度的乘积。
   - **平均存取时间**：**寻道时间（磁头移至目的磁道） + 旋转延迟时间（磁头定位到目的扇区） + 传输时间（数据传输）**。
   - **数据传输率**：单位时间内向主机传送数据的字节数，公式为 **Dₜ = rN**（r为磁盘转速，N为每条磁道的字节数）。

#### （二）磁盘阵列（RAID）

- **定义**：将多个独立物理磁盘组成一个逻辑盘，数据在物理盘上分割交叉存储、并行访问，提升存储性能、可靠性和安全性。
- **常见分级**：
  - RAID 0：无冗余、无校验，仅提升速度。
  - RAID 1：镜像模式，通过数据备份提高可靠性。
  - RAID 2：采用海明码纠错，适用于对容错要求高的场景。
  - RAID 3：位交叉奇偶校验，单盘容错。
  - RAID 4：块交叉奇偶校验，独立校验盘。
  - RAID 5：无独立校验盘，校验信息分散存储，兼顾性能与容错。

### 二、光盘存储器

- **原理**：利用光学原理，通过聚集激光束以非接触方式在盘式介质上记录/读取信息。
- **特点**：存储密度高、携带方便、成本低、容量大、存储期限长、易保存。
- **分类**：
  - CD-ROM：只读型光盘，仅可读取预制信息。
  - CD-R：一次写入型光盘，写入后不可修改。
  - CD-RW：可擦写型光盘，可重复读写。
  - DVD-ROM：高容量光盘，又称“通用数字化多功能光盘”，容量远大于CD-ROM。

### 三、固态硬盘

- **特点**：采用闪存芯片存储数据，无机械部件，读写速度快、抗震性好、功耗低。
- **应用场景**：常用于高档笔记本电脑、服务器等对存储速度要求高的设备。

## 7.3 I/O接口

### 一、I/O接口功能

1. 协调主机与外设的通信联络（解决时序配合、速度差异问题），保证系统统一工作。
2. 进行地址译码和设备选择，确定需访问的外设。
3. 实现数据缓冲，弥补CPU与外设的速度差。
4. 完成信号格式转换，消除主机与外设间的电平、数据格式差异。
5. 传送控制命令和状态信息：如CPU向外设发启动命令，外设向CPU发准备就绪信号。
6. 支持中断和DMA请求：外设提出请求时，CPU反馈响应信号。

### 二、I/O接口的基本结构

| 接口类型 | 连接对象                      | 数据传输方式   | 说明                                    |
| -------- | ----------------------------- | -------------- | --------------------------------------- |
| 内部接口 | 系统总线（间接连接CPU、内存） | 仅并行传输     | 负责与主机内部部件的信号交互            |
| 外部接口 | 外设（通过接口电缆连接）      | 可能为串行传输 | 需具备串/并转换功能，适配外设的传输方式 |

### 三、I/O接口类型

#### （一）按数据传输方式分类

- **并行接口**：一次传送一个字节或一个字的所有位，速度快，适用于短距离传输。
- **串行接口**：一位一位依次传送，线路简单，适用于长距离传输。

#### （二）按控制方式分类

- 程序查询接口、中断接口、DMA接口。

#### （三）按功能分类

- **可编程接口**：可通过程序设置接口功能，灵活性高。
- **不可编程接口**：功能固定，需通过硬件电路调整，灵活性低。

### 四、I/O端口及其编址

#### （一）统一编址（存储器映射方式）

- **原理**：将I/O端口视为内存单元，分配内存地址。
- **优点**：无需专门I/O指令，CPU访问方式灵活，端口编址空间大。
- **缺点**：端口占用内存地址，数据输入输出速度较慢。

#### （二）独立编址（I/O映射方式）

- **原理**：I/O端口地址与内存地址独立，单独编址空间。
- **优点**：程序编制清晰，便于区分内存操作与I/O操作。
- **缺点**：需设置专门的输入/输出指令，增加了控制逻辑的复杂性。

## 7.4 I/O方式（上）

### 一、程序查询方式

- **原理**：数据交换完全由主机执行程序控制，CPU持续查询外设状态，决定是否传送数据。
- **优点**：设计简单，所需硬件少。
- **缺点**：CPU大量时间用于查询等待，仅能与一台外设交互，效率低，存在“原地踏步”现象。

### 二、程序中断方式

#### （一）中断的基本概念

- **定义**：计算机出现异常或特殊请求时，CPU暂时中止当前程序，转去处理请求，处理完毕后返回原程序继续执行。
- **作用**：
  1. 实现CPU与I/O设备并行工作。
  2. 处理硬件故障和软件错误。
  3. 实现人机交互，响应用户干预。
  4. 支持多道程序、分时操作，实现程序切换。
  5. 满足实时处理需求，快速响应任务。
  6. 实现应用程序与操作系统（管态程序）的切换（软中断）。
  7. 多处理器系统中，实现处理器间信息交流与任务切换。

#### （二）中断的分类

| 分类维度   | 具体类型   | 定义                                                     |
| ---------- | ---------- | -------------------------------------------------------- |
| 中断源位置 | 内中断     | 处理器或内存内部产生，如地址非法、校验错等程序运算错误。 |
|            | 外中断     | 处理器或内存外部部件产生，如I/O设备的I/O中断。           |
| 产生方式   | 硬件中断   | 由外部硬件产生，属于外中断。                             |
|            | 软件中断   | 由指令触发，可编程实现，属于内中断。                     |
| 响应优先级 | 非屏蔽中断 | 硬件中断，不受中断标志位IF影响，关中断（IF=0）时仍响应。 |
|            | 可屏蔽中断 | 硬件中断，受IF影响，关中断时不响应。                     |

#### （三）中断判优

1. **实现方式**：
   - **硬件实现**：通过硬件排队器，可集成在CPU内或分散在各中断源中。
   - **软件实现**：通过查询程序，按预设顺序判断中断优先级。
2. **优先级逻辑**：
   - 硬件故障中断 > 软件中断 > 非屏蔽中断 > 可屏蔽中断。
   - DMA请求 > I/O设备中断请求。
   - 高速设备 > 低速设备，输入设备 > 输出设备，实时设备 > 普通设备。

#### （四）CPU响应中断的条件

1. 中断源发出中断请求。
2. CPU允许中断（开中断，IF=1）。
3. 当前指令执行完毕，且无更紧迫任务（如DMA请求）。

#### （五）中断隐指令与中断处理过程

1. **中断隐指令**：CPU响应中断后自动执行的指令，完成三项操作：
   - 关中断：保证被中断程序后续能正确恢复执行。
   - 保存断点：存储原程序计数器（PC）内容，用于后续返回。
   - 引出中断服务程序：将中断服务程序入口地址（中断向量）送入PC，采用**中断向量法**实现。
2. **中断处理过程**：
   1. 关中断 → 2. 保存断点 → 3. 引出中断服务程序 → 4. 保存现场和屏蔽字 → 5. 开中断 → 6. 执行中断服务程序 → 7. 关中断 → 8. 恢复现场和屏蔽字 → 9. 开中断并中断返回。

#### （六）多重中断和中断屏蔽技术

- **多重中断**：处理中断时响应更高优先级的新中断。
- **实现条件**：
  1. 中断服务程序中设置开中断指令，允许更高优先级中断介入。
  2. 优先级高的中断源可中断优先级低的中断服务程序。

## 7.4 I/O方式（下）

### 一、DMA方式

#### （一）概述

- **定义**：完全由硬件控制的成组信息传送方式，主存与I/O设备间开辟“直接数据通道”，无需CPU干预数据传输。
- **适用场景**：磁盘机、磁带机等高速外设。
- **特点**：
  1. 主存与CPU的联系脱钩，主存可同时被CPU和外设访问。
  2. 主存地址确定、数据计数等由硬件电路实现，无需CPU执行程序。
  3. 主存需开辟专用缓冲区，用于暂存外设数据。
  4. 传送速度快，CPU与外设并行工作，提升系统效率。
  5. 传送前需CPU预处理（设置参数），传送后需中断方式后处理。

#### （二）DMA控制器组成

1. **主存地址计数器**：存储待交换数据的主存地址，每传送一次数据自动递增。
2. **传送长度计数器**：记录待传送数据长度，计数溢出时自动发中断请求。
3. **数据缓冲寄存器**：暂存每次传送的数据，平衡主存与外设的速度差。
4. **DMA请求触发器**：接收I/O设备的控制信号，置位后向CPU发DMA请求。
5. **中断机构**：数据块传送完毕后，向CPU发中断请求，触发后处理。
6. **“控制/态”逻辑**：由控制时序电路和状态标志组成，指定传送方向、修改参数，协调DMA请求与CPU响应信号。

#### （三）DMA传送方式

| 方式             | 原理                                                              | 适用场景                            |
| ---------------- | ----------------------------------------------------------------- | ----------------------------------- |
| 停止CPU访问主存  | DMA接口获得总线控制权，CPU放弃地址线、数据线、控制线使用权        | 高速外设大量数据传送，对CPU影响较大 |
| DMA与CPU交替访存 | CPU和DMA轮流访存，无冲突                                          | CPU工作周期长于主存存取周期的系统   |
| 周期挪用（窃取） | CPU访存时，DMA需等待存取周期结束；二者同时请求时，CPU暂时让出总线 | 平衡CPU与外设的访存需求，影响较小   |

#### （四）DMA传送过程

1. **预处理**：CPU完成准备工作，包括设置主存地址初值、传送长度、传送方向，启动I/O设备。
2. **数据传送**：DMA硬件控制数据传输，以单字节（或字）或数据块为单位，无需CPU干预。
3. **后处理**：DMA控制器向CPU发中断请求，CPU执行中断服务程序，完成数据校验、结果反馈等操作。

#### （五）DMA方式与中断方式的区别

| 对比维度 | 中断方式                   | DMA方式                                 |
| -------- | -------------------------- | --------------------------------------- |
| 资源占用 | 需CPU干预（保护/恢复现场） | 仅预处理、后处理占用CPU，数据传送无干预 |
| 响应时机 | 指令执行完毕后             | 机器周期结束后                          |
| 适用场景 | 中低速外设、异常处理       | 高速外设成组数据传送                    |
| 优先级   | 低于DMA请求                | 高于中断请求                            |
| 处理能力 | 支持异常事件处理           | 仅支持数据传送，无异常处理能力          |
| 实现方式 | 软件（中断服务程序）主导   | 硬件（DMA控制器）主导                   |
