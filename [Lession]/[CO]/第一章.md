## 1.1 计算机发展历程

### 1.1.1 计算机的硬件发展

#### 1. 各代计算机特点与发展变化

- **第一代：电子管时代**
  - 特点：使用机器语言编程；容量小、体积大、成本高、性能低
  - 发展变化：速度提升
- **第二代：晶体管时代**
  - 特点：软件使用高级语言
  - 发展变化：形成操作系统雏形；使用半导体存储器
- **第三代：中小规模集成电路时代**
  - 特点：操作系统继续发展，出现分时操作系统；高级语言开始发展
- **第四代：超大规模集成电路时代**
  - 特点：微处理器出现；并行、流水线、高速缓存、虚拟存储器出现

#### 2. 关键发展规律与元件变化

- **摩尔定律**：18个月晶体管数量翻一倍
- **元件更新变化**：半导体存储器不断发展；微处理器不断发展

### 1.1.2 计算机软件发展

#### 软件与语言发展脉络

- **语言分类与演进**
  - 面向机器的语言：机器语言、汇编语言
  - 面向问题的高级语言：FORTRAN→PASCAL→C++→JAVA
- 核心逻辑：所有高级语言最终都会转化为机器语言，因为机器语言是计算机唯一可直接识别和执行的语言

### 1.1.3 计算机的分类与发展方向

#### 1. 计算机分类

| 分类维度                 | 具体类别                                                                                                                                                 |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 核心技术                 | 电子模拟计算机、电子数字计算机                                                                                                                           |
| 用途                     | 专用计算机、通用计算机（根据效率、速度、价格、运行经济性与适应性划分）                                                                                   |
| 体积与性能（通用计算机） | 巨型机、大型机、中型机、小型机、微型机、单片机（体积、功耗等依次递减）                                                                                   |
| 指令与数据流             | 单指令流单数据流（SISD，冯诺依曼体系结构）、单指令流多数据流（SIMD）、多指令流单数据流（MISD，不存在）、多指令流多数据流（MIMD，多处理器和多计算机系统） |

#### 2. 发展方向

- 巨型机：追求更大规模、超高速并行处理、更高智能
- 微型计算机：追求体积小、高性能、多用途

#### 3. 重要概念区分：DBMS与DBS

- **DBS（数据库系统）**：计算机系统引入数据库后的完整系统
- **DBMS（数据库管理系统）**：位于用户和操作系统之间的一层数据管理系统（系统软件）
- DBS组成结构：数据库、数据库管理系统、数据库管理员、应用系统

#### 4. 硬件与软件的关系

- 核心原则：硬件与软件在逻辑上是等效的
- 功能实现选择：若功能使用频繁且硬件实现成本低，则优先用硬件实现（硬件实现效率高于软件）

## 1.2 计算机系统结构（上）

### 1.2.1 计算机系统构成

- **核心组成**：运算器、存储器、控制器、输入设备、输出设备

### 1.2.2 计算机硬件的基本组成

#### 1. 冯诺依曼体系结构核心特点

- 指令与数据共存于存储器，按地址访问
- 指令与数据均以二进制代码构成
- 指令组成：操作码（表示操作）+ 地址码（表示操作数存储位置）
- 指令顺序存放、顺序执行（特定条件可改变执行顺序）
- “存储程序”原理：将指令以二进制代码形式事先输入主存储器，按首地址执行第一条指令，再按程序规定顺序执行后续指令，直至结束

#### 2. 计算机结构演进

- **早期冯诺依曼机**：以运算器为中心，输入输出设备通过运算器与存储器传送数据
- **现代计算机**：以存储器为中心，I/O操作尽可能绕开CPU，实现I/O设备与存储器直接交互，提升运行效率

### 1.2.3 计算机软件的分类

#### 1. 按功能分类

| 类别     | 包含内容                                                                                                   |
| -------- | ---------------------------------------------------------------------------------------------------------- |
| 系统软件 | 操作系统（OS）、数据库管理系统（DBMS）、语言处理程序、分布式软件系统、网络软件系统、标准库程序、服务性程序 |
| 应用软件 | 为解决特定问题的程序，如科学计算类、工程设计类、数据统计与处理类程序                                       |

#### 2. 语言分类与转换

- **机器语言**：二进制代码语言，计算机唯一可直接识别和执行的语言
- **汇编语言**：用英文单词代替二进制指令代码（便于记忆），需经汇编程序翻译为机器语言
- **高级语言**：需经转换为机器语言才能执行，转换路径：高级语言→汇编语言→机器语言 或 高级语言→机器语言

## 1.2 计算机系统结构（下）

### 1.2.4 计算机工作过程

#### 1. 具体步骤

1. 程序、数据装入主存
2. 从程序起始地址开始运行：
   - 从程序首地址取出指令→指令译码→指令执行→完成功能并计算下一条指令地址
   - 按新得到的指令地址读出下一条指令，直至程序结束

#### 2. 信息流程

- **取指令**：PC（程序计数器）→MAR（地址寄存器）→M（存储器）→MDR（数据寄存器）→IR（指令寄存器）；取完指令后PC自动加1，形成下一条指令地址
- **分析指令**：OP（IR中的操作码）→CU（控制单元）
- **执行指令**：Ad（IR中的地址码）→MAR→M→MDR→ACC（累加计数器）

### 1.2.5 计算机系统的多级层次结构

| 层级                     | 核心功能                                   |
| ------------------------ | ------------------------------------------ |
| 虚拟机器（高级语言机器） | 用汇编程序将高级语言程序翻译为汇编语言程序 |
| 虚拟机器（汇编语言机器） | 用汇编程序将汇编语言程序翻译为机器语言程序 |
| 虚拟机器（操作系统机器） | 用机器语言解释操作系统                     |
| 传统机器（机器语言机器） | 用微程序解释机器指令                       |
| 微程序机器（微指令系统） | 硬件直接执行微指令                         |
| 软硬件交互界面           | 连接硬件与软件的交互层                     |

### 1.2.6 计算机核心硬部件功能

| 硬部件         | 英文缩写 | 核心功能                                       |
| -------------- | -------- | ---------------------------------------------- |
| 地址寄存器     | MAR      | 指明要读/写的存储单元，位数反映存储单元数量    |
| 数据寄存器     | MDR      | 暂存要读/写的数据，位数=存储字长               |
| 累加计数器     | ACC      | 存放操作数、运算结果                           |
| 通用寄存器     | X        | 存放操作数                                     |
| 乘商寄存器     | MQ       | 进行乘法、除法运算时使用                       |
| 算术逻辑单元   | ALU      | 用电路实现各种算术运算、逻辑运算               |
| 程序计数器     | PC       | 存放下一条指令的地址，取指令后自动加1          |
| 指令寄存器     | IR       | 存放当前执行的指令                             |
| 控制单元       | CU       | 分析指令（来自IR），给出控制信号               |
| 程序状态寄存器 | PSW      | 保留运算指令和测试指令的结果状态，表征系统状态 |

## 1.3 计算机性能指标

### 1.3.1 计算机的主要性能指标

#### 1. 核心硬件相关指标

- **机器字长**：计算机一次整数运算可处理的二进制位数；一般等于内部寄存器大小，且为字节的整数倍（2/4/8倍）；字长越长，数值表示范围越大、精度越高；受CPU寄存器位数、加法器影响
- **数据通路带宽**：数据总线一次性可传送信息的位数（此处指外部数据总线宽度，可能与CPU内部数据总线宽度不同）
- **主存容量**：主存储器的最大容量；MAR位数反映存储单元个数，即最大寻址范围（最大寻址范围≠实际寻址范围）

#### 2. 系统效率相关指标

- **吞吐量**：单位时间内处理请求的数量，取决于主存的存取周期
- **响应时间**：用户发送请求到系统返回结果的等待时间，=CPU时间+等待时间（磁盘访问、存储器访问、I/O操作、操作系统开销）

#### 3. CPU相关指标

- **CPU时钟周期**：CPU的最小时间单位（又称节拍脉冲/T周期），=1/主频；每个动作至少需要1个时钟周期
- **主频**：机器内部主时钟的频率，是衡量机器速度的重要参数；同一型号计算机，主频越高，执行指令速度越快
- **运算速度**：
  - **CPI**：执行一条指令所需的时钟周期数
  - **CPU执行时间**：=CPU时钟周期数/主频=（指令条数×CPI）/主频
  - **MIPS**：每秒执行百万条指令
  - **浮点运算能力**：MFLOPS（每秒百万次浮点运算）、GFLOPS（每秒十亿次）、TFLOPS（每秒万亿次）；浮点运算能力可衡量科学计算类计算机性能

### 1.3.2 专业术语

- **系列机**：具有相同体系结构、使用基本指令系统的多个不同型号计算机组成的产品系列
- **兼容**：计算机软件与硬件的通用性
- **软件可移植性**：某系列计算机的软件，无需修改或仅需少量修改即可在另一系列计算机上运行的可能性
- **固件**：将程序固定在ROM中组成的部分，是软硬结合产物；速度快于软件，灵活性高于硬件；后期类似产物有段页表

## 1.4 计算机核心部件补充说明

### 1.4.1 存储器

#### 1. 基本概念

- 存储元、存储单元、存储字、存储字长、地址
- **主存**：CPU可直接访问，按地址存取信息（相联存储器可按内容访问，如快表）
- **辅存**：辅助存储主存信息，CPU不可直接访问（类比：CPU=顾客，主存=商店，辅存=供货商，顾客需等供货商将货物放入商店后才能购买）

#### 2. 主存组成

- MAR（地址寄存器）：存放地址，位数与PC长度相等
- MDR（数据寄存器）：暂存读/写数据，位数与存储字长相等（一般为字节的2次幂整数倍）
- 时序控制逻辑：产生存储器操作的时序信号

### 1.4.2 运算器

- **核心**：算术逻辑单元（ALU）
- **组成**：累加器（AC）、乘商寄存器（MQ）、操作数寄存器（X）、变址寄存器（IX）、基址寄存器（BR）

### 1.4.3 控制器

- **功能**：计算机指挥中心，控制指令执行流程
- **组成**：
  - PC（程序计数器）：存放当前欲执行指令的地址，可自动加1生成下一条指令地址，与主存MAR有直接通路
  - IR（指令寄存器）：存放当前指令，内容来自MDR
  - CU（控制单元）：分析来自IR的数据，发出微操作命令

### 1.4.4 输入/输出设备

- **输入设备**：接收外部信息，如键盘、鼠标、扫描仪、摄像机
- **输出设备**：输出处理结果（便于用户理解），如显示器、打印机
