## 一、虚拟存储器和Cache异同

### （一）相同之处

- 目的为了提高系统性能
- 数据分为小信息块，作为基本的传递单位
- 都存在地址映射、替换算法、更新策略
- 按照局部性原理，将活跃的数据放到高速部件中

### （二）不同之处

- 解决问题不同：Cache解决系统速度问题；虚拟存储器解决主存容量问题
- 实现方式不同：Cache全部由硬件实现，是硬件存储器；虚拟存储器有OS和硬件共同实现，是逻辑上的存储器
- 透明性不同：Cache对所有程序员透明；虚拟存储器对应用程序员透明，对系统程序员不透明
- 与CPU交互不同：CPU只能与Cache和主存直接交互；虚拟存储系统只能先将数据从硬盘调入主存，不能与CPU直接通信

## 二、3.1~3.2 存储器的层次结构

### 3.1.1 存储器分类

#### 1. 层次分类

- **主存**：存放计算机运行时的程序与数据；可以被CPU直接访问，也可以与Cache和辅存进行交换数据；特点：容量小、速度快、价格高
- **辅存（转存）**：存储当前暂时不用的程序和数据，以及一些永久保留数据；不可以与CPU直接交互；特点：容量大、速度慢、价格低
- **高速缓冲存储器（Cache）**：位于主存与CPU之间，缓解CPU与主存之间速度差距问题；CPU可以直接访问；特点：容量小、速度与CPU相匹配、价格高；高档计算机将其放在CPU中

#### 2. 存储介质分类

- 磁表面存储器：磁盘、磁带
- 磁芯存储器
- 半导体存储器：MOS存储器、双极型存储器
- 光存储器：光盘

#### 3. 存取方式分类

- **随机存储器（RAM）**：随机存取，读写方便，使用灵活；用途：主存、高速缓冲存储器；类型：静态RAM（触发原理）、动态RAM（电容充电原理）
- **只读存储器（ROM）**：只能读出不能写入；用途：与随机存储器构成主存，存储固定不变的程序（甚至操作系统的固化）；注：ROM与RAM都是随机存取，广义上的只读存储器可以通过电擦除写入，写入速度比读速度慢；ROM也派生出可以反复重写的类型

#### 4. 信息可保存性

- **易失性存储器**：RAM（断电后信息丢失）
- **非易失性存储器**：ROM、磁表面存储器、光存储器（断电后，仍然可以保持信息）

#### 5. 读出类型

- 破坏性读出：读出后需要对存储信息再生
- 非破坏性读出：不会对原存储信息破坏

### 3.1.2 存储器的性能指标

- **计算机追求目标**：大容量、低成本、高速度（联系自身买电脑）
- **存储容量**：存储字数×字长
- **单位成本**：总成本/总容量
- **存取时间**：存储器启动到完成操作，分为读出时间与写入时间
- **存储速度**：数据传输率=数据宽度/存储周期
- **存取周期（读写周期、访问周期）**：存储器进行一次完整读写操作需要的时间；注：存储周期一般大于存取时间（读写操作后需要内部复原时间）
- **主存带宽**：数据传输率，每秒主存进出信息的最大数量

#### 存储系统目标

更大、更快、更便宜

### 3.2 存储器的层次化结构

- **Cache-主存层次**：解决CPU和主存速度不匹配问题
- **主存-辅存层次**：解决存储系统容量问题；该层次不断发展，衍生出虚拟存储器系统

## 三、3.3 半导体随机存储器（上）

### 3.3.1 半导体存储芯片

- **核心组成**：
  1. 存储矩阵：大量相同的位存储单元阵列构成
  2. 译码驱动：地址信号翻译成对应存储单元的选通信号
  3. 读写电路：完成读写操作
  4. 片选线：确定哪个芯片被选中
  5. 读/写控制线：决定芯片是读还是写
- **地址线**：单向输入，位数与存储字的个数有关
- **数据线**：数据线数与地址线数共同反映存储芯片容量大小
- **半导体随机存储器分类（按存储原理不同）**：
  - DRAM：用于主存
  - SRAM：用于高速缓存
- 相关器件：74138译码器

### 3.3.2 SRAM和DRAM

| 类型 | 存储原理                          | 读出特性     | 易失性 | 存取速度 | 集成度 | 功耗 | 成本 | 用途           | 地址传输方式                       |
| ---- | --------------------------------- | ------------ | ------ | -------- | ------ | ---- | ---- | -------------- | ---------------------------------- |
| SRAM | 使用双稳态触发器（六MOS）记忆信息 | 非破坏性读出 | 易失性 | 快       | 低     | 大   | 高   | 高速缓冲存储器 | -                                  |
| DRAM | 利用电荷存储信息                  | 破坏性读出   | 易失性 | 慢       | 高     | 低   | 低   | 主存系统       | 分两次送行列地址（同时送行列地址） |

#### DRAM特有：刷新相关

- 刷新单位：行
- **刷新方法**：
  1. **集中刷新**：读写不受刷新影响，存取速度快；但存在死区（死区：刷新时停止对存储器的读写操作，称为死时间），死区不能访问存储器，刷新时间固定
  2. **分散刷新**：将每行刷新分散到各个工作周期中；没有死区，但存取周期变长，降低整机速度
  3. **异步刷新**：集中刷新和异步刷新结合；缩短了死时间，又提高了整机速度
  4. **透明刷新**：刷新安排在译码阶段，不存在死时间

#### 存储器的读写周期

- **RAM写周期**：数据总线上的信息能够可靠地写入存储器的周期
- **RAM读周期**：存储芯片进行两次连续读操作时，必须间隔的时间；读周期总是大于等于读出时间

### 3.3.3 只读存储器（ROM）

#### ROM特点

- 随机存取，非易失性存储器
- 结构简单，位密度比可读写存储器高
- 可靠性高，集成度高，价格便宜

#### ROM类型

1. **掩膜式只读存储器（MROM）**：灵活性差
2. **一次性可编程只读存储器（PROM）**：写入内容无法更改
3. **可擦除可编程只读存储器（EPROM）**：可以对内容进行多次改写；分为紫外线擦除（UVEPROM）、电擦除（E²PROM）
4. **闪速存储器（Flash Memory）**：可长期保存信息、可重写；价格便宜，集成度高，擦写速度快
5. **固态硬盘（SSD）**：可长期保存信息，快速擦除、重写；相对于传统硬盘，读写速度快、低功耗；缺点：价格高

## 四、3.4 主存储器和CPU的连接

### （一）连接原理

主存储器与CPU通过**数据总线、地址总线、控制总线**连接

### （二）主存容量扩展

1. **位扩展**：将多个存储芯片并联；例：8片8K×1位 → 8K×8位存储器
2. **字扩展**：多个存储芯片串联；例：4片16K×8位 → 64K×8位存储器
3. **字位同时扩展法**：并联与串联结合在一起

### （三）存储芯片的地址分配和片选

#### 1. 线选法

- 原理：通过地址线直接对芯片进行选择
- 优点：不需要地址译码器，线路简单
- 缺点：地址空间不连续，不能充分利用系统存储空间，造成地址资源浪费

#### 2. 译码片选法

- 原理：通过使用地址译码器对芯片进行选择
- 优点：每片芯片的地址范围是唯一确定的，而且是连续的，也便于扩展
- 缺点：对译码电路要求过高

### （四）连接关键要点

1. **选择合理存储芯片**：
   - ROM：存放系统程序
   - RAM：为用户编程设置
2. **地址线的选择**：
   - 芯片容量不同，地址线数量也不同
   - CPU地址线低位与存储芯片的地址线连接
   - CPU地址线高位用于扩充芯片使用
3. **数据线的连接**：
   - CPU数据线数与存储芯片线数相等时：可直接连接
   - CPU数据线数与存储芯片线数不等时：必须对存储芯片进行扩位，使其相等
4. **读/写命令线的连接**：高电平为读，低电平为写
5. **片选线的连接**：片选线的作用是选择哪一片存储芯片被选中（是CPU与存储芯片连接的关键）

## 五、3.5 双端口RAM和多模块存储器

### （一）设计目的

提高CPU访问存储器的速度；采用两种技术：双端口存储器（空间并行）、多模块存储器（时间并行）

### （二）双端口RAM

- 结构：一个存储器有左、右两个独立端口，分别具有两组相互独立的地址线、数据线、读写控制线
- **访问冲突情况**：
  - 无冲突：对同一个地址单元，两个端口不同时写；对同一个地址单元，两个端口同时读
  - 冲突：对同一个地址单元，两个端口同时写入数据；对同一个地址单元，一个端口写、一个口读

### （三）多模块存储器

#### 设计目的

提高访问速度

#### 1. 单体多字存储器

- 结构：多个模块构成，每个模块有着相同的容量和存取速度，各模块可并行工作又可以交叉工作
- 工作方式：按照地址顺序读出数据，存储单元存储m个字，总线宽度也为m个字，一次性并行读出m个字
- 优点：增大了存储器带宽，提高单体存储器工作速度

#### 2. 多体并行存储器

| 编址方式     | 特点                                                                                                                       |
| ------------ | -------------------------------------------------------------------------------------------------------------------------- |
| 高位交叉编址 | 本质上仍然是顺序存储器                                                                                                     |
| 低位交叉编址 | 可以在不改变每个模块的存取周期的前提下，采用流水线的方式并行存储，可提高存储器的带宽；多体低位交叉编制可以有效提高存储速度 |

## 六、3.6 高速缓冲存储器（Cache）

### （一）核心依据

程序访问的局部性原理：

- 时间局部性：将要使用的信息，可能是现在正在使用的信息
- 空间局部性：将来使用的信息，可能在正在使用信息的存储空间的附近
- 基于局部性原理创造出高速缓冲技术（Cache）

### （二）基本特性

- 通常使用SRAM制造
- 存储主存中最为活跃的信息副本，按照某种策略将这些活跃的信息存入到Cache中
- 数据交换单位：Cache与主存之间交换数据的基本单位是Cache块；CPU与Cache之间交换数据的基本单位是字
- 特殊情况：某些计算机也可能是同时访问Cache和主存

### （三）Cache与主存的映射方式

#### 1. 直接映射

- 规则：主存数据块只能装入Cache中的唯一位置
- 优点：实现简单
- 缺点：冲突率高，利用率低

#### 2. 全相联映射

- 规则：主存数据块可以放在Cache中的任何位置
- 地址结构：主存字块标记 + 字块内地址
- 优点：比较灵活，冲突率低
- 缺点：地址变换慢，实现成本高

#### 3. 组相联映射

- 规则：将Cache分为不同的组，主存的数据块可以装入一组内的任何位置
- 地址结构：主存字块标记 + 组地址 + 字块内地址

### （四）Cache中的替换算法

1. **随机算法**：

   - 原理：随机确定替换的Cache块
   - 优点：实现简单
   - 缺点：没有依据局部性原理，命中率低
2. **先进先出算法（FIFO）**：

   - 原理：最早调入的行进行替换
   - 优点：容易实现
   - 缺点：没有依据局部性原理
3. **近期最少使用算法（LRU）**：

   - 原理：根据局部性原理，选择近期内最久没有访问的存储行
   - 优点：平均命中率高
   - 缺点：需要设置计数器比较存储行；属于堆栈类算法
4. **最不经常使用算法**：

   - 原理：一段时间内访问次数最少的存储行换出

### （五）Cache写策略

#### 1. 写命中场景

- **写回法（write-back）**：
  - 操作：只修改Cache内容，不立即写入主存
  - 优点：减少了访存次数
  - 缺点：存在数据不一致的隐患，同时需要设置一个脏位
- **全写法（写直通法、write-through）**：
  - 操作：数据同时写入Cache和主存
  - 优点：实现简单，随时保持主存数据正确性
  - 缺点：增加了访存次数，降低了效率

#### 2. 写不命中场景

- **写分配法（write-allocate）**：
  - 操作：加载主存中的块到Cache中，然后更新Cache块
  - 原理：试图使用空间局部性原理
  - 搭配：通常与写回法搭配
- **非写分配法（not-write allocate）**：
  - 操作：写入主存，不进行调块
  - 优点：每次不命中无需从主存调块；可有效避免频繁写时造成的写缓冲饱和和溢出
  - 搭配：通常与全写法搭配

### （六）多级Cache

- 常见级别：通常为3级

## 七、3.7 虚拟存储器

### （一）基本概念

- 地址编址：将主存或者辅存的地址空间统一编址
- 地址类型：
  - 实地址：对应主存地址空间
  - 虚地址：使用时需辅助硬件找出与实地址的关系，并判断对应存储单元装入状态
- 数据存放原则：需要使用的先送入主存，暂时不用的放在磁盘中

### （二）虚拟存储器的类型

#### 1. 页式虚拟存储器

- 基本单位：页
- 虚地址结构：虚地址 = 虚页号 + 页内地址
- **地址计算过程**：
  1. 虚页号 + 页表起始地址 = 页表地址
  2. 根据页表地址查找实页号
  3. 实页号 + 页内地址 = 实地址
- 优点：页面长度固定，调入方便
- 缺点：零头浪费，对页的处理、保护、共享不是特别方便

#### 2. 段式虚拟存储器

- 划分依据：按照程序的逻辑结构划分
- 虚地址结构：虚地址 = 段号 + 段内地址
- **地址计算过程**：
  1. 段号 + 段表起始地址 = 段表地址
  2. 查询段表数据
  3. 实地址 = 段表所得数据 + 段内地址
- 优点：段分界与程序分界相对应，易于编译、管理、修改、保护、共享
- 缺点：段长分配不便，存在段间碎片

#### 3. 段页式存储器

- 划分逻辑：先将程序按逻辑分段，再将每段分为固定大小页；段长必须是页的整数倍
- 虚地址结构：虚地址 = 段号 + 段内页号 + 页内地址
- 优点：可以按段实现共享和保护，同时也有着页的调用方便
- 缺点：地址变换要两次查表，开销较大

### （三）快表（TLB）

#### 1. 设计依据与结构

- 依据：根据局部性原理，将一些经常访问的页放入高速缓冲器中构成快表，可极大提高查询效率
- 结构：采用相联存储器构成，可以按照内容查询

#### 2. 访问顺序

TLB → 页表 → Cache → 主存

#### 3. 命中情况规律

- Page不命中，Cache和主存不会命中，此时要执行调页策略
- Cache命中，Page必然命中，TLB不一定命中
- Cache不命中，无法直接判断TLB与Page命中情况；只要抓住存储数据的来源就可以推导出命中情况
