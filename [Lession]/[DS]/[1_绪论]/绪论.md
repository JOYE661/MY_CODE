# 数据结构绪论

## 1.1 数据结构的基本概念

### 一、基本概念和术语

| 术语         | 定义                                                                                                                                                             |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 数据         | 信息的载体，是描述客观事物属性的数、字符及所有能输入到计算机中并被计算机程序识别和处理的符号的集合                                                               |
| 数据元素     | 数据的基本单位，通常作为一个整体进行考虑和处理                                                                                                                   |
| 数据对象     | 具有相同性质的数据元素的集合，是数据的一个子集                                                                                                                   |
| 数据类型     | 一个值的集合和定义在此集合上的一组操作的总称，分为两类：`<br>`- 原子类型：其值不可再分的数据类型`<br>`- 结构类型：其值可以再分解为若干成分（分量）的数据类型 |
| 抽象数据类型 | 抽象数据组织及与之相关的操作                                                                                                                                     |

### 二、数据结构的三要素

数据结构是相互之间存在一种或多种特定关系的数据元素的集合，包含**逻辑结构**、**存储结构**、**数据的运算**三方面核心内容。

#### （一）数据的逻辑结构

逻辑结构是指数据元素之间的逻辑关系，即从逻辑关系上描述数据，与数据的存储无关，是独立于计算机的。根据数据元素间关系的不同，可分为两类：

- **线性结构**：数据元素间存在一对一的线性关系，包括线性表、栈、队列、数组。
- **非线性结构**：数据元素间存在一对多或多对多的关系，包括集合、树、图。

#### （二）数据的存储结构

存储结构是指数据结构在计算机中的表示（又称映像），也称物理结构，包括数据元素的表示和关系的表示，是用计算机语言实现的逻辑结构，依赖于计算机语言。常见存储结构分为四类：

| 存储结构类型 | 定义                                                                                           | 优点                                                   | 缺点                                                                                 |
| ------------ | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------ | ------------------------------------------------------------------------------------ |
| 顺序存储     | 把逻辑上相邻的元素存储在物理位置上也相邻的存储单元中，元素之间的关系由存储单元的邻接关系来体现 | 1. 可实现随机存取`<br>`2. 每个元素占用最少的存储空间 | 只能使用相邻的一整块存储单元，可能产生较多的外部碎片                                 |
| 链式存储     | 不要求逻辑上相邻的元素在物理位置上也相邻，借助指示元素存储地址的指针来表示元素之间的逻辑关系   | 1. 不会出现碎片现象`<br>`2. 能充分利用所有存储单元   | 1. 每个元素因存储指针而占用额外的存储空间`<br>`2. 只能实现顺序存取                 |
| 索引存储     | 在存储元素信息的同时，还建立附加的索引表（索引表中记录元素关键字与存储地址的对应关系）         | 检索速度快                                             | 1. 附加的索引表额外占用存储空间`<br>`2. 增加和删除数据时需修改索引表，花费较多时间 |
| 散列存储     | 根据元素的关键字直接计算出该元素的存储地址，又称哈希（Hash）存储                               | 检索、增加和删除结点的操作都很快                       | 若散列函数设计不佳，可能出现元素存储单元的冲突，解决冲突会增加时间和空间开销         |

#### （三）数据的运算

施加在数据上的运算包含两方面：

1. **运算的定义**：针对逻辑结构，指出运算的功能（如线性表的插入、删除、查找）。
2. **运算的实现**：针对存储结构，指出运算的具体操作步骤（如顺序表的插入需移动元素，链表的插入需修改指针）。

## 1.2 算法和算法评价

### 一、算法的基本概念

- **算法的定义**：对特定问题求解步骤的一种描述，是指令的有限序列，其中每条指令表示一个或多个操作。

### 二、算法的重要特性

算法需满足以下5个核心特性，缺一不可：

1. **有穷性**：一个算法必须执行有穷步之后结束，且每一步都可在有穷时间内完成。
2. **确定性**：算法中每条指令必须有确切的含义，对于相同的输入只能得出相同的输出。
3. **可行性**：算法中描述的操作都可以通过已经实现的基本运算执行有限次来实现。
4. **输入**：一个算法有零个或多个输入，这些输入取自于某个特定对象的集合。
5. **输出**：一个算法有一个或多个输出，这些输出是与输入有着某种特定关系的量。

### 三、优秀算法的标准

评价一个算法的优劣，需从以下4个维度判断：

1. **可读性**：算法应具有良好的可读性，便于人们理解、调试和维护。
2. **健壮性**：输入非法数据时，算法能适当地做出反应或进行处理（如报错提示），而不会产生莫名其妙的输出结果。
3. **正确性**：算法应能够正确解决目标求解问题，对于符合输入规范的所有情况，都能输出正确结果。
4. **效率与低存储量需求**：`<br>`- 效率：指算法执行的时间，与问题规模（如数据量n）相关，规模越大，时间差异越明显。`<br>`- 低存储量需求：指算法执行过程中所需的最大存储空间，同样与问题规模相关。

### 四、算法效率的度量

算法效率通过**时间复杂度**和**空间复杂度**量化描述，两者均为问题规模n的函数。

#### （一）时间复杂度

1. **核心概念**：一个语句的**频度**是指该语句在算法中被重复执行的次数。通常情况下，算法中循环语句的执行次数是决定时间复杂度的关键（存在特殊情况，如嵌套循环需综合多层循环次数）。
2. **渐近时间复杂度**：
   忽略常数项、低次项和系数，只保留最高次项，用符号“O”表示，常见的渐近时间复杂度从优到劣依次为：O(1)＜O(log₂n)＜O(n)＜O(nlog₂n)＜O(n²)＜O(n³)＜O(2ⁿ)＜O(n!)。

#### （二）空间复杂度

1. **定义**：算法的空间复杂度S(n)定义为该算法所耗费的存储空间，是问题规模n的函数。
2. **存储空间构成**：程序执行时所需的存储空间包括两部分：
   - 固定部分：存放算法本身的指令、常数、变量和输入数据，与问题规模无关。
   - 可变部分：对数据进行操作的工作单元、存储计算所需辅助信息的空间（如链表的指针、排序算法的临时数组），与问题规模相关，是计算空间复杂度的核心。

#### （三）复杂度计算规则

1. **乘法规则**：O(f(n))×O(g(n))=O(f(n)×g(n))（如嵌套循环，外层循环时间复杂度O(n)，内层O(log₂n)，总复杂度O(nlog₂n)）。
2. **加法规则**：O(f(n))+O(g(n))=O(max(f(n),g(n)))（如两个独立循环，分别为O(n)和O(n²)，总复杂度O(n²)）。
3. **原地工作**：若算法所需的辅助空间为常量（即可变部分空间不随n变化），则空间复杂度为O(1)，称为“原地工作”（如冒泡排序、插入排序）。
