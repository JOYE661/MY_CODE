# 串（数据结构）

## 4.1 串的定义和实现

### 1. 串的基本概述

#### （1）串的定义

串（又称字符串）是由零个或多个字符组成的有限序列，通常记为 `S = "a₁a₂…aₙ"`（`n ≥ 0`）。其中：

- `S` 为串名；
- 双引号内的字符序列 `a₁a₂…aₙ` 为串值（引号本身不属于串的内容）；
- `aᵢ`（`1 ≤ i ≤ n`）是任意字符（可来自ASCII字符集、Unicode字符集等，如英文字符用ASCII编码，中英文混用用Unicode编码）；
- `n` 为串的长度，即串中字符的个数；
- 当 `n = 0` 时，称为**空串**（用 `∅` 表示），不含任何字符。

串是一种**特殊的线性表**：逻辑结构与线性表一致（元素间呈一对一线性关系），但数据对象限定为“字符”，且基本操作多以“子串”为操作对象（区别于线性表对单个元素的操作）。

#### （2）串的核心术语

- **子串**：串中任意个连续字符组成的子序列（含空串），如串 `"abcde"` 的子串有 `"a"`、`"bc"`、`""` 等。
- **主串**：包含子串的串，如上述例子中 `"abcde"` 是 `"bc"` 的主串。
- **子串的位置**：子串的第一个字符在主串中的序号，如 `"bc"` 在 `"abcde"` 中的位置为 2（假设序号从1开始）。
- **空格串**：由一个或多个空格字符（空格是特殊字符）组成的串，其长度为空格的个数，如 `"   "`（长度为3），注意与空串（长度为0）区分。
- **串相等**：当且仅当两个串的**长度相等**，且**每个对应位置的字符都相等**时，两串相等。例如 `"abc"` 与 `"abc"` 相等，`"abc"` 与 `"ab"`、`"abd"` 均不相等。

### 2. 串的存储结构

串的存储结构基于线性表的存储逻辑，分为**顺序存储**和**链式存储**，具体可细分为三类：

#### （1）定长顺序存储表示

- **定义**：类似于线性表的顺序存储，用一组地址连续的存储单元（如定长数组）存放串值的字符序列，预定义最大串长 `MAXLEN`。
- **串长表示方式**：
  1. 用额外变量 `length` 存放串的实际长度（推荐，直观且便于操作）；
  2. 在串值末尾添加不计入串长的结束标记字符 `'\0'`（C语言默认方式，串长需通过遍历计算）。
- **特点**：
  - 优点：存储密度高，存取速度快（直接通过数组下标访问）；
  - 缺点：串的实际长度不能超过 `MAXLEN`，超出部分会被**截断**（舍弃），灵活性差。
- **C语言结构体实现示例**：
  ```c
  #define MAXLEN 255  // 预定义最大串长
  typedef struct {
      char ch[MAXLEN];  // 存储串值的定长数组
      int length;       // 串的实际长度（额外变量记录）
  } SString;  // 定长顺序串类型
  ```

#### （2）堆分配存储表示

- **定义**：仍采用连续存储单元存放串值，但存储空间在程序执行过程中**动态分配**（从内存“堆区”申请，通过 `malloc()`/`calloc()` 函数实现），无固定预定义长度。
- **特点**：
  - 优点：可根据串的实际长度动态调整存储空间，避免截断问题，灵活性高；
  - 缺点：需手动管理内存（用 `free()` 释放，否则会导致内存泄漏）。
- **C语言结构体实现示例**：
  ```c
  typedef struct {
      char *ch;     // 指向堆区连续存储单元的指针（串的基地址）
      int length;   // 串的实际长度
      int maxsize;  // 当前分配的最大存储空间（可选，便于动态扩容）
  } HString;  // 堆分配串类型

  // 初始化堆分配串（示例）
  void InitHString(HString *T) {
      T->ch = (char *)malloc(10 * sizeof(char));  // 初始分配10字节（可自定义）
      T->maxsize = 10;
      T->length = 0;
  }

  // 销毁堆分配串（释放内存）
  void DestroyHString(HString *T) {
      free(T->ch);  // 释放堆区空间
      T->ch = NULL; // 避免野指针
      T->length = 0;
      T->maxsize = 0;
  }
  ```

#### （3）块链存储表示

- **定义**：采用链表存储串值，每个链表结点（称为“块”）可存放1个或多个字符（结点大小可自定义，如4个字符/块），整个链表称为“块链结构”。
- **结构组成**：
  - 数据域：存放1个或多个字符（如 `CHUNKSIZE` 个，可设为80、4等）；
  - 指针域：指向后续结点；
  - 串的整体信息：头指针 `head`、尾指针 `tail`（便于快速定位首尾）、串的实际长度 `length`。
- **特点**：
  - 优点：无存储长度限制，插入/删除操作灵活（尤其适合长串）；
  - 缺点：存储密度较低（每个结点含指针域，占用额外空间），若结点大小为1（每个结点存1个字符），空间浪费最严重。
- **C语言结构体实现示例**：
  ```c
  #define CHUNKSIZE 80  // 自定义每个结点存放的字符数（块大小）
  typedef struct Chunk {  // 块链的结点结构
      char ch[CHUNKSIZE];  // 数据域：存放CHUNKSIZE个字符
      struct Chunk *next;  // 指针域：指向后续结点
  } Chunk;

  typedef struct {  // 块链串的整体结构
      Chunk *head;   // 头指针：指向第一个结点
      Chunk *tail;   // 尾指针：指向最后一个结点
      int length;    // 串的实际长度
  } LString;  // 块链串类型
  ```

### 3. 串的基本操作

串的基本操作以“串”或“子串”为操作对象，核心操作及功能如下（操作名参考文档，实现逻辑结合实际应用补充）：

| 操作名                           | 功能描述                                                                                                     | 关键逻辑说明                                                                                                                                                              |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `StrAssign(&T, chars)`         | 赋值操作：将字符序列 `chars` 赋值给串 `T`                                                                | 若为堆分配串，需先判断 `chars` 长度，动态调整 `T` 的存储空间，再复制字符序列。                                                                                        |
| `StrEmpty(S)`                  | 判空操作：判断串 `S` 是否为空串                                                                            | 若 `S.length == 0`（或 `S.ch[0] == '\0'`），返回 `TRUE`，否则返回 `FALSE`。                                                                                       |
| `StrCopy(&T, S)`               | 复制操作：由串 `S` 复制得到串 `T`（`T` 原有内容被覆盖）                                                | 先初始化 `T`，再将 `S` 的字符序列逐位复制到 `T`，同步更新 `T.length`。                                                                                            |
| `StrCompare(S, T)`             | 比较操作：比较串 `S` 和 `T` 的大小                                                                       | 逐位比较对应字符的ASCII值：`<br>`- 若 `S` 先出现更大字符，返回 `>0`；`<br>`- 若 `T` 先出现更大字符，返回 `<0`；`<br>`- 所有字符相等且长度相同，返回 `0`。 |
| `StrLength(S)`                 | 求串长：返回串 `S` 的实际字符个数                                                                          | 直接返回 `S.length`（定长/堆分配串）；或遍历 `S.ch` 到 `'\0'`，计数返回。                                                                                           |
| `SubString(&Sub, S, pos, len)` | 求子串：用 `Sub` 返回串 `S` 中第 `pos` 个字符起、长度为 `len` 的子串                                 | 先校验合法性（`pos ≥ 1`、`len ≥ 0`、`pos + len - 1 ≤ S.length`），再截取对应字符到 `Sub`。                                                                     |
| `Concat(&T, S1, S2)`           | 串联接：用 `T` 返回由 `S1` 和 `S2` 首尾连接而成的新串                                                  | 若 `S1.length + S2.length` 超过 `T` 的最大存储（如定长串），需截断；堆分配串则动态扩容后拼接。                                                                        |
| `Index(S, T)`                  | 定位操作（模式匹配基础）：若主串 `S` 存在与模式串 `T` 相等的子串，返回其第一次出现的位置；否则返回 `0` | 依赖模式匹配算法（如BF算法、KMP算法）实现，是串查找的核心操作。                                                                                                           |
| `ClearString(&S)`              | 清空操作：将串 `S` 清为空串                                                                                | 无需释放存储空间，仅将 `S.length = 0`（或在 `S.ch[0]` 处设 `'\0'`）。                                                                                               |
| `DestroyString(&S)`            | 销毁串：释放串 `S` 占用的存储空间（仅针对堆分配/块链存储）                                                 | 堆分配串调用 `free(S.ch)`；块链串需遍历所有结点，逐个释放后置空指针。                                                                                                   |

## 4.2 串的模式匹配

串的模式匹配是指：在**主串**中查找与**模式串**（子串）相等的子串，并返回其第一次出现的位置（若存在）。核心算法分为“简单模式匹配”和“改进的模式匹配（KMP算法）”。

### 1. 简单模式匹配算法（BF算法，Brute-Force）

#### （1）实现思想

采用“穷举法”，将主串中所有长度与模式串相等的子串，逐个与模式串对比：

1. 初始化主串指针 `i = 1`（指向主串当前比较位置，从1开始计数），模式串指针 `j = 1`（指向模式串当前比较位置）；
2. 若 `S.ch[i] == T.ch[j]`（字符匹配），则 `i++`、`j++`，继续比较下一个字符；
3. 若字符不匹配（`S.ch[i] != T.ch[j]`），则**主串指针回溯**（`i = i - j + 2`，回到上一次比较起始位置的下一个字符），**模式串指针重置**（`j = 1`），重新开始比较；
4. 循环步骤2~3，直到 `i > S.length`（主串遍历完，匹配失败）或 `j > T.length`（模式串遍历完，匹配成功）；
5. 匹配成功时，返回子串在主串的起始位置（`i - T.length`）；失败则返回 `0`。

#### （2）缺点

主串指针 `i` 会频繁回溯，导致时间开销增加（例如主串为 `"aaaaaab"`，模式串为 `"aaab"`，每次匹配失败后 `i` 都需回溯，重复比较已检查过的字符）。

#### （3）时间复杂度

- 最坏情况：`O(n×m)`（`n` 为主串长度，`m` 为模式串长度），如主串全为 `'a'`、模式串为 `'aa…aab'`（`m` 个 `'a'` + `'b'`）；
- 平均情况：`O(n + m)`，适用于字符集较大、匹配失败较早的场景。

#### （4）C语言实现示例（基于定长顺序串）

```c
int Index_BF(SString S, SString T, int pos) {
    int i = pos;  // 主串起始比较位置（默认从1开始）
    int j = 1;    // 模式串起始比较位置
    while (i <= S.length && j <= T.length) {
        if (S.ch[i-1] == T.ch[j-1]) {  // 数组下标从0开始，需偏移1
            i++;
            j++;
        } else {
            i = i - j + 2;  // 主串回溯
            j = 1;          // 模式串重置
        }
    }
    if (j > T.length) {
        return i - T.length;  // 匹配成功，返回起始位置
    } else {
        return 0;  // 匹配失败
    }
}
```

### 2. 改进的模式匹配算法（KMP算法，Knuth-Morris-Pratt）

#### （1）核心思路

利用“已匹配部分的前缀和后缀重叠信息”，避免主串指针 `i` 回溯，仅调整模式串指针 `j` 的位置，从而降低时间复杂度。

#### （2）关键概念：前缀、后缀与部分匹配值

- **前缀**：模式串中从第一个字符开始，不包含最后一个字符的连续子串；
- **后缀**：模式串中从最后一个字符开始，不包含第一个字符的连续子串；
- **部分匹配值**：模式串的某个前缀（长度为 `k`）中，“最长相等前缀与后缀”的长度（若无前缀与后缀相等，部分匹配值为 `0`）。

**示例**：模式串 `"ababa"` 的部分匹配值计算：

- 长度1（`"a"`）：前缀、后缀均为空集 → 部分匹配值 = 0；
- 长度2（`"ab"`）：前缀 `{"a"}`，后缀 `{"b"}` → 无相等 → 0；
- 长度3（`"aba"`）：前缀 `{"a", "ab"}`，后缀 `{"a", "ba"}` → 最长相等为 `"a"` → 1；
- 长度4（`"abab"`）：前缀 `{"a", "ab", "aba"}`，后缀 `{"b", "ab", "bab"}` → 最长相等为 `"ab"` → 2；
- 长度5（`"ababa"`）：前缀 `{"a", "ab", "aba", "abab"}`，后缀 `{"a", "ba", "aba", "baba"}` → 最长相等为 `"aba"` → 3；
- 最终部分匹配值序列：`[0, 0, 1, 2, 3]`。

#### （3）next数组

- **定义**：`next[j]` 表示当模式串的第 `j` 个字符匹配失败时，模式串应跳转的下一个比较位置（`j` 从1开始计数）。
- **推导规则**：`next[j] = 部分匹配值（模式串前 j-1 个字符的最长相等前缀后缀长度）`，具体：
  - `next[1] = 0`（模式串第一个字符匹配失败，需从0开始重新定位）；
  - 若模式串前 `j-1` 个字符的部分匹配值为 `k`，则 `next[j] = k`；
  - 示例：模式串 `"ababa"`（`j=1~5`）的 `next` 数组为 `[0, 0, 1, 2, 3]`。

#### （4）KMP算法执行步骤

1. 预处理模式串 `T`，计算其 `next` 数组；
2. 初始化主串指针 `i = 1`，模式串指针 `j = 1`；
3. 若 `S.ch[i] == T.ch[j]`，则 `i++`、`j++`，继续比较；
4. 若不匹配：
   - 若 `j == 1`（模式串第一个字符就不匹配），则 `i++`（主串直接后移）；
   - 否则，`j = next[j]`（模式串跳转至 `next[j]` 位置，主串 `i` 不回溯）；
5. 循环步骤3~4，直到 `i > S.length`（匹配失败）或 `j > T.length`（匹配成功）；
6. 匹配成功返回 `i - T.length`，失败返回 `0`。

#### （5）时间复杂度

- 预处理 `next` 数组：`O(m)`（`m` 为模式串长度）；
- 主串匹配：`O(n)`（`n` 为主串长度）；
- 总时间复杂度：`O(n + m)`，且主串指针 `i` 仅遍历一次，无回溯。

#### （6）C语言实现示例（next数组构建与KMP匹配）

```c
// 1. 构建模式串T的next数组
void GetNext(SString T, int next[]) {
    int j = 1, k = 0;
    next[1] = 0;  // 初始值
    while (j < T.length) {
        if (k == 0 || T.ch[j-1] == T.ch[k-1]) {  // 数组下标偏移1
            j++;
            k++;
            next[j] = k;
        } else {
            k = next[k];  // 不匹配时，k回溯到next[k]
        }
    }
}

// 2. KMP模式匹配
int Index_KMP(SString S, SString T, int pos) {
    int i = pos;  // 主串起始位置
    int j = 1;    // 模式串起始位置
    int next[T.length + 1];  // next数组（长度为模式串长度+1）
    GetNext(T, next);        // 预处理next数组
  
    while (i <= S.length && j <= T.length) {
        if (j == 0 || S.ch[i-1] == T.ch[j-1]) {  // j=0表示需重新匹配
            i++;
            j++;
        } else {
            j = next[j];  // 模式串跳转，主串i不回溯
        }
    }
  
    if (j > T.length) {
        return i - T.length;  // 匹配成功
    } else {
        return 0;  // 匹配失败
    }
}
```

### 3. KMP算法的进一步优化（nextval数组）

#### （1）优化原因

当模式串中存在“当前字符与 `next[j]` 对应的字符相等”时，`next[j]` 跳转后仍会匹配失败，导致重复比较（例如模式串 `"aaaaa"`，`next[3] = 2`，但 `T.ch[3] = T.ch[2] = 'a'`，跳转后仍不匹配）。

#### （2）nextval数组定义

`nextval[j]` 是对 `next[j]` 的优化：若模式串第 `j` 个字符与第 `next[j]` 个字符相等，则 `nextval[j] = nextval[next[j]]`；否则 `nextval[j] = next[j]`。

#### （3）优化效果

避免无效的重复比较，进一步提升匹配效率，时间复杂度仍为 `O(n + m)`，但实际执行速度更快。

#### （4）C语言实现示例（构建nextval数组）

```c
void GetNextVal(SString T, int next[], int nextval[]) {
    int j = 1;
    nextval[1] = 0;  // 初始值
    while (j < T.length) {
        int k = next[j];
        if (k == 0 || T.ch[j-1] != T.ch[k-1]) {  // 字符不相等，直接取next[j]
            nextval[j+1] = k;
        } else {  // 字符相等，取nextval[k]
            nextval[j+1] = nextval[k];
        }
        j++;
    }
}

// 优化后的KMP匹配：仅需将GetNext替换为GetNextVal，其余逻辑不变
```
