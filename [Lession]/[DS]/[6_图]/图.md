# 图的相关概念、存储、遍历及应用

## 一、图的基本概念

### 1. 图的定义

图G由顶点集V和边集E组成，记为**G=(V, E)**，其中：

- **顶点集V(G)**：表示图G中顶点的有限非空集，用|V|表示图G中顶点的个数，也称图G的“阶”。
- **边集E(G)**：表示图G中顶点之间关系（边）的有限集，边的表示为E={(u, v) | u∈V, v∈V}，用|E|表示图G中边的条数。

**注意**：线性表可以是空表，树可以是空树，但**图不可以是空图**（顶点集V非空）。

### 2. 有向图与无向图

#### （1）有向图

若E是**有向边（也称弧）** 的有限集合，则图G为有向图：

- 弧是顶点的有序对，记为**<v, w>**，其中v称为“弧尾”，w称为“弧头”。
- 关系描述：<v, w>表示“从顶点v到顶点w的弧”，也称“v邻接到w”或“w邻接自v”。

#### （2）无向图

若E是**无向边（简称边）** 的有限集合，则图G为无向图：

- 边是顶点的无序对，记为**(v, w)** 或**(w, v)**（因(v, w)=(w, v)）。
- 关系描述：顶点v和顶点w互为“邻接点”；边(v, w)依附于顶点v和w，或边(v, w)与顶点v、w相关联。

### 3. 图的分类（按边的特性）

| 类型       | 定义                                                                              |
| ---------- | --------------------------------------------------------------------------------- |
| 简单图     | 不存在“重复边”（同一对顶点间边数≤1），且不存在“顶点到自身的边”（自环）的图。 |
| 多重图     | 某两个顶点间边数＞1，或允许顶点通过同一条边与自身关联（自环）的图。               |
| 无向完全图 | 无向图中，                                                                        |
| 有向完全图 | 有向图中，                                                                        |

### 4. 子图与生成子图

- **子图**：设两个图G=(V, E)和G'=(V', E')，若V'是V的子集，且E'是E的子集，则称G'是G的子图。
- **生成子图**：若子图G'满足V'(G')=V(G)（顶点集与原图形同），则称G'是G的生成子图。

### 5. 连通性相关概念

#### （1）无向图的连通性

- **连通**：无向图中，若从顶点v到顶点w有路径存在，则称v和w是连通的。
- **连通图**：若图G中任意两个顶点都是连通的，则称G为连通图；否则为非连通图。
- **连通分量**：无向图中的“极大连通子图”（无法再添加原图顶点使子图仍连通）。
- **重要结论**：若一个图有n个顶点，且边数＜n-1，则此图必是非连通图。

#### （2）有向图的连通性

- **强连通**：有向图中，若从顶点v到w和从w到v都有路径，则称v和w是强连通的。
- **强连通图**：若图中任意一对顶点都是强连通的，则称此图为强连通图。
- **强连通分量**：有向图中的“极大强连通子图”。

### 6. 生成树与生成森林

#### （1）生成树（针对连通图）

- 定义：包含图中全部顶点的“极小连通子图”（无法再删除边使子图仍连通且含全部顶点）。
- 特性：
  1. 若顶点数为n，则生成树含n-1条边。
  2. 砍去一条边→非连通图；添加一条边→形成回路。

#### （2）生成森林（针对非连通图）

- 定义：非连通图中，每个连通分量的生成树共同构成生成森林。

### 7. 顶点的度、入度与出度

#### （1）无向图的度

- 定义：顶点v的度是依附于该顶点的边的条数，记为TD(v)。
- 重要结论：无向图全部顶点的度的和 = 边数×2（每条边贡献2个度）。

#### （2）有向图的入度与出度

- **出度OD(v)**：以顶点v为弧尾的弧的条数（v发出的边数）。
- **入度ID(v)**：以顶点v为弧头的弧的条数（v接收的边数）。
- 重要结论：有向图全部顶点的入度之和 = 出度之和 = 边数（每条弧贡献1个入度和1个出度）。

### 8. 其他基础概念

- **边的权与网**：每条边标有数值（权值），带权图称为“网”。
- **稠密图与稀疏图**：
  - 稀疏图：边数很少，一般满足**|E| < |V|log|V|**。
  - 稠密图：边数较多，反之于稀疏图。
- **路径与回路**：
  - 路径：两个顶点之间相连的边的序列。
  - 路径长度：路径上边的数目。
  - 回路（环）：第一个顶点和最后一个顶点相同的路径。
  - 简单路径：顶点不重复出现的路径。
  - 简单回路：除首尾顶点外，其余顶点不重复的回路。
- **距离**：
  - 若从u到v有最短路径，则路径长度称为u到v的距离。
  - 若不存在路径，距离记为无穷（∞）。
- **有向树**：一个顶点入度为0（根），其余顶点入度均为1的有向图。

## 二、图的存储及基本操作（6.2）

### 1. 邻接矩阵法

#### （1）结构定义

- 用**一维数组**存储顶点信息（顶点表）；
- 用**二维数组**（邻接矩阵A）存储边的信息：
  - 无向图/有向图（非带权）：若(v_i, v_j)∈E或<v_i, v_j>∈E，则A[i][j]=1；否则A[i][j]=0。
  - 带权图：若(v_i, v_j)∈E或<v_i, v_j>∈E，则A[i][j]=权值；否则A[i][j]=∞。

#### （2）特点

- 无向图的邻接矩阵是**对称矩阵**，实际存储可只存上（或下）三角矩阵。
- 空间复杂度：**O(n²)**（n为顶点数），适合存储稠密图。
- 优点：易判断任意两个顶点间是否有边（直接查A[i][j]）。
- 缺点：统计边数需遍历整个矩阵，时间代价大。
- 度的计算：
  - 无向图：第i行非零元素个数 = TD(v_i)。
  - 有向图：第i行非零元素个数 = OD(v_i)；第i列非零元素个数 = ID(v_i)。

### 2. 邻接表法

#### （1）结构定义

结合顺序存储（顶点表）和链式存储（边表）：

- **顶点表**：顺序存储，每个结点含“顶点数据”和“边表头指针”（指向依附该顶点的第一条边）。
- **边表**：链式存储，每个结点（边结点）含“邻接点索引”（与当前顶点相邻的顶点位置）、“下一条边指针”和“边权值（可选）”。
  - 有向图中，边表也称“出边表”（仅存储以当前顶点为弧尾的弧）。

#### （2）特点

- 存储空间：
  - 无向图：O(|V| + 2|E|)（每条边存2次，对应两个顶点的边表）。
  - 有向图：O(|V| + |E|)（每条弧存1次）。
- 适合存储稀疏图（节省空间）。
- 优点：
  - 易查找某顶点的所有邻边（遍历边表）。
  - 有向图求某顶点出度（统计边表结点数）便捷。
- 缺点：
  - 有向图求某顶点入度需遍历所有顶点的边表（效率低）。
  - 邻接表表示不唯一（边表中边的顺序可不同）。

### 3. 十字链表（有向图专用）

#### （1）结构定义

- **弧结点**：含“弧头索引（headvex）”、“弧尾索引（tailvex）”、“同弧头下一条弧指针（hlink）”、“同弧尾下一条弧指针（tlink）”、“弧信息（info）”。
- **顶点结点**：含“顶点数据（data）”、“以该顶点为弧头的第一条弧指针（firstin）”、“以该顶点为弧尾的第一条弧指针（firstout）”。

#### （2）特点

- 时间复杂度：遍历图的时间为O(|V| + |E|)。
- 优点：兼顾“出边”和“入边”的查找，适合有向图的复杂操作。

### 4. 邻接多重表（无向图专用）

#### （1）结构定义

- **边结点**：含“边依附的两个顶点索引（ivex, jvex）”、“标记域（mark，标记边是否被访问）”、“依附ivex的下一条边指针（ilink）”、“依附jvex的下一条边指针（jlink）”、“边信息（info）”。
- **顶点结点**：含“顶点数据（data）”、“依附该顶点的第一条边指针（firstedge）”。

#### （2）特点

- 解决无向图邻接表中“同一条边存两次”的冗余问题，适合无向图的边操作（如边的删除、标记）。

## 三、图的遍历（6.3）

图的遍历是从某一顶点出发，访问所有顶点且仅访问一次的过程，主要有两种方式：广度优先搜索（BFS）和深度优先搜索（DFS）。

### 1. 广度优先搜索（BFS）

#### （1）算法思想（类似二叉树层序遍历）

1. 访问起始顶点v，标记为已访问。
2. 将v入队，依次出队顶点u，访问u的所有未访问邻接顶点，标记后入队。
3. 重复步骤2，直至队空（所有顶点访问完毕）。

#### （2）实现工具

- 队列（先进先出，保证“按层访问”）。

#### （3）性能分析

- **空间复杂度**：O(|V|)（队列最多存储所有顶点）。
- **时间复杂度**：
  - 邻接表存储：O(|V| + |E|)（访问顶点O(|V|)，遍历边O(|E|)）。
  - 邻接矩阵存储：O(|V|²)（每个顶点需遍历一行，共|V|行）。

#### （4）应用与特性

- 应用：求解“无权图的最短路径”（BFS首次访问顶点的路径即为最短路径）。
- 广度优先生成树：遍历过程中形成的树（含全部顶点，边为遍历经过的边）。
  - 唯一性：邻接矩阵存储时唯一（顶点邻接顺序固定）；邻接表存储时不唯一（边表顺序可变）。

### 2. 深度优先搜索（DFS）

#### （1）算法思想（类似二叉树先序遍历）

1. 访问起始顶点v，标记为已访问。
2. 从v的未访问邻接顶点中选一个u，递归执行DFS(u)。
3. 若v的所有邻接顶点已访问，回溯至前一个顶点，重复步骤2，直至所有顶点访问完毕。

#### （2）实现工具

- 递归工作栈（递归实现）或手动栈（非递归实现）。

#### （3）性能分析

- 空间复杂度：O(|V|)（栈最多存储递归深度，最坏为所有顶点）。
- 时间复杂度：与BFS一致（邻接表O(|V|+|E|)，邻接矩阵O(|V|²)）。

#### （4）特性

- 深度优先生成树/森林：
  - 连通图→生成树（1棵）；非连通图→生成森林（多棵，对应各连通分量）。
- 遍历序列唯一性：邻接矩阵存储时唯一；邻接表存储时不唯一。

### 3. 遍历与图的连通性

- **无向图**：
  - 连通图：从任一顶点出发，1次遍历可访问所有顶点。
  - 非连通图：1次遍历仅能访问起始顶点所在的连通分量，需多次遍历才能访问所有顶点。
- **有向图**：
  - 强连通图：从任一顶点出发，1次遍历可访问所有顶点。
  - 非强连通图：需多次遍历（按强连通分量）才能访问所有顶点。

## 四、图的应用

### （一）最小生成树（6.4 上）

#### 1. 定义与性质

- 定义：带权连通图中，**权值之和最小**的生成树。
- 性质：
  1. 边数固定：n个顶点的最小生成树含n-1条边。
  2. 权和唯一：无论树形如何，最小权值之和唯一。
  3. 树形不唯一：若存在多条权值相同的边，可能有多个最小生成树。

#### 2. 常用算法

| 算法        | 核心思想                                                                                    | 时间复杂度 | 适用场景 |
| ----------- | ------------------------------------------------------------------------------------------- | ---------- | -------- |
| Prim算法    | 从任一顶点开始，每次选“与当前树中顶点集合距离最近”的顶点及对应边加入树，直至含所有顶点。  | O(         | V        |
| Kruskal算法 | 初始为n个孤立顶点（无边），按边权从小到大选边，若边连接两个不同连通分量则加入，直至形成树。 | O(         | E        |

### （二）最短路径（6.4 上）

#### 1. Dijkstra算法（单源最短路径）

- 适用场景：带权有向/无向图，**边权非负**。
- 核心思想：
  1. 初始化：设源点为v0，辅助数组dist[]（dist[i]为v0到vi的当前最短距离，初始为边权或∞）、S[]（已确定最短路径的顶点集合，初始为空）。
  2. 重复n-1次：
     - 从V-S中选dist[j]最小的顶点j，加入S。
     - 更新V-S中顶点k的dist[k]：若dist[j] + 边(j,k)权 < dist[k]，则dist[k] = dist[j] + 边(j,k)权。
- 时间复杂度：O(|V|²)（邻接矩阵存储）。

#### 2. Floyd算法（各顶点间最短路径）

- 适用场景：带权有向/无向图，**允许边权为负，但不允许含负权回路**（会导致路径长度无限小）。
- 核心思想：动态规划，逐步尝试以每个顶点k为“中间顶点”，更新任意两点(i,j)的最短路径：
  - 初始：dist[i][j] = 边(i,j)权（无直接边则为∞）。
  - 迭代：dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])（k=0,1,...,n-1）。
- 时间复杂度：O(|V|³)。

### （三）有向无环图（DAG）的应用（6.4 上）

#### 1. AOV网（顶点表示活动的网络）

- 定义：用顶点表示“活动”，用有向边<Vi, Vj>表示“活动Vi必须先于Vj进行”，是DAG的一种。
- 前驱/后继：Vi是Vj的直接前驱，Vj是Vi的直接后继（前驱关系具有传递性，无自环）。

#### 2. 拓扑排序

- 定义：对AOV网的顶点进行线性排序，满足“若Vi在序列中排在Vj前，则不存在从Vj到Vi的路径”。
- 实现步骤：
  1. 选一个“入度为0”的顶点（无前驱活动），输出。
  2. 删除该顶点及所有以它为起点的有向边（更新邻接顶点的入度）。
  3. 重复1-2，直至网空（排序成功）或无入度为0的顶点（网含环，排序失败）。
- 唯一性：若顶点有多个直接后继，拓扑排序结果通常不唯一；若各顶点前驱/后继唯一，则结果唯一。

### （四）AOE网与关键路径（6.4 下）

#### 1. AOE网（边表示活动的网络）

- 定义：用顶点表示“事件”，用有向边表示“活动”，边权表示“活动的开销（如时间）”，是DAG的一种。
- 与AOV网的异同：
  - 相同点：均为有向无环图。
  - 不同点：AOE网边有权值（活动开销），AOV网边无权值（仅表顺序）。
- 性质：
  1. 事件发生条件：进入该顶点的所有活动均已结束。
  2. 活动开始条件：该活动起点的事件已发生。

#### 2. 关键路径与关键活动

- **关键路径**：从源点（起始事件）到汇点（结束事件）的所有路径中，**路径长度最大**的路径（决定工程总工期）。
- **关键活动**：关键路径上的活动（延误将导致总工期延长）。

#### 3. 关键参数计算

设边<vk, vj>表示活动ai，Weight(vk, vj)为活动ai的开销：

| 参数              | 定义与计算方法                                                                                 |
| ----------------- | ---------------------------------------------------------------------------------------------- |
| 事件最早时间ve(k) | 事件vk最早发生时间：ve(源点)=0；ve(k)=Max{ve(j) + Weight(vj, vk)}（vj是vk的前驱事件）。        |
| 事件最迟时间vl(k) | 事件vk最迟发生时间：vl(汇点)=ve(汇点)；vl(k)=Min{vl(j) - Weight(vk, vj)}（vj是vk的后继事件）。 |
| 活动最早时间e(i)  | 活动ai最早开始时间：e(i)=ve(k)（vk是活动ai的起点事件）。                                       |
| 活动最迟时间l(i)  | 活动ai最迟开始时间：l(i)=vl(j) - Weight(vk, vj)（vj是活动ai的终点事件）。                      |
| 活动差额d(i)      | d(i)=l(i)-e(i)（d(i)=0的活动为关键活动）。                                                     |

#### 4. 关键路径算法步骤

1. 按拓扑有序求所有事件的ve(k)。
2. 按逆拓扑有序求所有事件的vl(k)。
3. 按ve(k)和vl(j)求所有活动的e(i)和l(i)。
4. 计算d(i)，d(i)=0的活动构成关键路径。

#### 5. 关键活动的注意事项

- 缩短关键活动可缩短总工期，但需缩短“所有关键路径共有的关键活动”（仅缩短某一条关键路径的活动无效）。
- 关键活动缩短至一定程度后，可能变为非关键活动（需重新计算关键路径）。
- 关键活动耗时增加→总工期延长。

### （五）逆拓扑排序（6.4 下）

- 定义：对AOV网的顶点进行线性排序，满足“若Vi在序列中排在Vj前，则不存在从Vi到Vj的路径”。
- 实现步骤：
  1. 选一个“出度为0”的顶点（无后继活动），输出。
  2. 删除该顶点及所有以它为终点的有向边（更新邻接顶点的出度）。
  3. 重复1-2，直至网空或无出度为0的顶点（含环）。
- 实现方式：可基于DFS算法（访问完顶点所有邻接顶点后再输出该顶点）。
