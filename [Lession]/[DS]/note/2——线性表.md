# 线性表

## 2.1 线性表的定义和基本操作

### 一、线性表的定义

线性表是具有相同数据类型的n个数据元素的有限序列，其中n为表长，当n=0时线性表是一个空表。

### 二、线性表的特点

1. 表中元素的个数有限。
2. 表中元素具有逻辑上的顺序性，表中元素有其先后次序。
3. 表中元素都是数据元素，每个元素都是单个元素。
4. 每个元素占有相同大小的存储空间。

### 三、注意事项

- 线性表是一种**逻辑结构**，表示元素之间一对一的相邻关系。
- 顺序表和链表是指**存储结构**。

### 四、线性表的基本操作

| 操作函数       | 功能说明                                       |
| -------------- | ---------------------------------------------- |
| Initlist(BL)   | 初始化表，构造一个空的线性表                   |
| GetElem(L)     | 按位查找操作，获取表L中第i个位置的元素的值     |
| LInsert(L,i,e) | 插入操作，在表L中的第i个位置上插入指定元素e    |
| PrintList(L)   | 输出操作，按前后顺序输出线性表L的所有元素值    |
| Empty(L)       | 判空操作，若L为空表，则返回true，否则返回false |

> 注意：考试尽量使用上述函数名称，方便老师阅卷。

## 2.2 线性表的顺序表示

### 一、顺序表的定义

线性表的顺序存储又称**顺序表**，用一组地址连续的存储单元依次存储线性表中的数据元素，逻辑上相邻的两个元素在物理位置上也相邻。

### 二、一维数组空间分配方式

| 分配方式 | 特点                                                                                                                               |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 静态分配 | 数组的大小和空间已经固定，一旦空间占满，再加入新的数据将会产生溢出，程序就会崩溃                                                   |
| 动态分配 | 存储数组的空间是在程序执行过程中通过动态存储分配语句分配的；一旦数据空间占满，就另外开辟一块更大的存储空间，用以替换原来的存储空间 |

> 注意：动态分配仍然是顺序存储结构，物理结构没有变化，依然是随机存取方式，只是分配的空间大小可以在运行时决定。

### 三、顺序表的特点

1. **随机访问**：通过首地址和元素序号可在时间O(1)内找到指定的元素。
2. **存储密度高**：每个结点只存储数据元素。
3. **元素存储关联性**：逻辑上相邻的元素物理上也相邻，当执行插入和删除操作时，需要移动大量元素（与链表形成对比）。

### 四、顺序表上基本操作的实现

#### （一）插入操作（长度为n）

1. 最好情况：在表尾插入（i=n+1），元素后移语句将不执行，时间复杂度为O(1)。
2. 最坏情况：在表头插入（i=1），元素后移语句将执行n次，时间复杂度为O(n)。
3. 平均情况：假设p_i（p_i=1/(n+1)）是在第i个位置上插入一个结点的概率，则在长度为n的线性表中插入一个结点时，移动结点的平均次数为$\sum_{i=1}^{n+1} p_i \times (n - i + 1) = \frac{n}{2}$，时间复杂度为O(n)。

#### （二）删除操作

1. 核心逻辑：移动元素，对想要删除的元素进行覆盖。
2. 最好情况：删除表尾元素（i=n），无须移动元素，时间复杂度为O(1)。
3. 最坏情况：删除表头元素（i=1），需移动除第一个元素外的所有元素，时间复杂度为O(n)。
4. 平均情况：假设p_i（p_i=1/n）是在第i个位置上删除一个结点的概率，则在长度为n的线性表中删除一个结点时，删除节点的平均次数为$\sum_{i=1}^{n} p_i \times (n - i) = \frac{n-1}{2}$，时间复杂度为O(n)。

#### （三）按值查找（顺序查找）

1. 最好情况：查找的元素就在表头，仅需比较一次，时间复杂度为O(1)。
2. 最坏情况：查找的元素在表尾（或不存在）时，需要比较n次，时间复杂度为O(n)。
3. 平均情况：假设p_i（p_i=1/n）是查找的元素在第i（1<=i<=L.length）个位置上的概率，则在长度为n的线性表中查找值为e的元素所需比较的平均次数为$\sum_{i=1}^{n} p_i \times i = \frac{n+1}{2}$，时间复杂度为O(n)。

## 2.3 线性表的链式表示

### 一、链式表示（上）

#### （一）单链表的定义

线性表的链式存储又称**单链表**，是指通过一组任意的存储单元来存储线性表中的数据元素。对每个链表结点，除存放元素自身的信息外，还需要存放一个指向其后继的指针。

#### （二）单链表的结构

| 域的类型       | 功能说明             |
| -------------- | -------------------- |
| data（数据域） | 存放数据元素         |
| next（指针域） | 存放其后继结点的地址 |

#### （三）单链表的实现方式及空表判断

| 实现方式   | 空表判断条件  | 特点         |
| ---------- | ------------- | ------------ |
| 不带头结点 | L==NULL       | 代码书写不便 |
| 带头结点   | L->next==NULL | 写代码更方便 |

#### （四）顺序表与单链表的优缺点对比

| 类型   | 优点                                                                                  | 缺点                                                                                                                            |
| ------ | ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 顺序表 | 可以随时存取表中的任意一个元素                                                        | 插入和删除操作需要移动大量元素                                                                                                  |
| 单链表 | 1. 不需要使用地址连续的存储单元 `<br>`2. 插入和删除操作不需要移动元素，只需修改指针 | 1. 失去顺序表可随机存取的优点 `<br>`2. 附加指针域，浪费存储空间 `<br>`3. 查找某个特定的结点时，需要从表头开始遍历，依次查找 |

#### （五）单链表上基本操作的实现

##### 1. 建立单链表

| 建立方式 | 实现逻辑                                                                                                                                      | 时间复杂度                                                        | 优点                                       | 缺点                                         |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ------------------------------------------ | -------------------------------------------- |
| 头插法   | 从一个空表开始，生成新结点，将读取到的数据存放到新结点的数据域中，然后将新结点插入到当前链表的表头（即头结点之后）                            | 设单链表长为n，总时间复杂度为O(n)（每个结点插入时间复杂度为O(1)） | 算法实现简单；可利用该特点进行链表转置     | 生成的链表中结点的次序和输入数据的顺序不一致 |
| 尾插法   | 从一个空表开始，生成新结点，将读取到的数据存放到新结点的数据域中，将新结点插入到当前链表的表尾（需增加尾指针r，使其始终指向当前链表的尾结点） | 设单链表长为n，总时间复杂度为O(n)（每个结点插入时间复杂度为O(1)） | 生成的链表中结点的次序和输入数据的顺序一致 | 需维护尾指针，实现稍复杂                     |

##### 2. 查找操作

| 查找类型         | 实现逻辑                                   | 时间复杂度                         |
| ---------------- | ------------------------------------------ | ---------------------------------- |
| 按序号查找结点值 | 从表头开始遍历，依次查找目标序号的结点     | O(n)（链表本身特点，只能依次遍历） |
| 按值查找表结点   | 从表头开始遍历，依次比较结点数据域与目标值 | O(n)（链表本身特点，只能依次遍历） |

##### 3. 插入结点操作

1. 普通插入（在第i个位置插入）
   - 实现代码段：
     ```
     p = GetElem(L, i-1);  // 查找第i-1个结点
     s->next = p->next;
     p->next = s;
     ```
   - 时间复杂度：主要时间开销在于查找第i-1个元素，为O(n)。
2. 给定结点后插：若在给定的结点p后插入新结点s，时间复杂度为O(1)。
3. 给定结点前插：寻找到要插入结点的前一个结点，按正常插入方法执行，时间复杂度为O(n)。

##### 4. 删除结点操作

| 删除方式                     | 实现逻辑                                                                                            | 时间复杂度                           |
| ---------------------------- | --------------------------------------------------------------------------------------------------- | ------------------------------------ |
| 方法一（删除第i个结点）      | 1. 检查删除位置的合法性 `<br>`2. 查找表中第i-1个结点（被删结点的前驱结点）`<br>`3. 执行删除操作 | O(n)（主要时间开销在于查找前驱结点） |
| 方法二（删除给定结点*p）     | 1. 不直接删除*p，而是将*p后继结点的值赋予*p自身 `<br>`2. 删除*p的后继结点                     | O(1)                                 |
| 方法三（常规删除给定结点*p） | 从链表的头结点开始顺序找到*p的前驱结点，再执行删除操作                                              | O(n)                                 |

##### 5. 求表长操作

- 实现逻辑：从第一个结点开始顺序依次访问表中的每个结点，设置计数器变量，每访问一个结点计数器加1，直到访问到空结点为止。
- 时间复杂度：O(n)。

#### （一）双链表

##### 1. 概念

双链表结点中有两个指针：`prior`（指向其前驱结点）和 `next`（指向其后继结点），解决单链表只能从头结点依次顺序向后遍历、无法快速对前驱结点进行操作的缺点。

#### （二）循环链表

##### 1. 循环单链表

- 与单链表的区别：表中最后一个结点的指针不是NULL，而是改为指向头结点，形成一个环。
- 判空条件：头结点的指针是否等于头指针。
- 优化：仅设尾指针时，在链首之前插入结点的效率更高，时间复杂度为O(1)。

##### 2. 循环双链表

- 结构特点：头结点的 `prior`指针指向表尾结点，表尾结点的 `next`指针指向头结点。
- 关键判断：
  - 某结点*p为尾结点时，p->next == L（L为头指针）。
  - 空表时，头结点的 `prior`域和 `next`域都等于L。

### 三、链式表示（下）

#### （一）静态链表

##### 1. 基本结构

静态链表借助数组来描述线性表的链式存储结构，结点包含 `data`（数据域）和 `next`（指针域），其中 `next`是结点的相对地址（数组下标），又称游标。静态链表需预先分配一块连续的内存空间。

##### 2. 特点

- 优点：增、删操作不需要大量移动元素，操作与动态链表相同，只需修改游标。
- 缺点：1. 不能随机存取，只能从头结点开始依次往后查找；2. 容量固定不可变。

##### 3. 适用场景

1. 不支持指针的低级语言。
2. 数据元素数量固定不变的场景（如操作系统的文件分配表FAT）。

#### （二）顺序表和链表的比较

##### 1. 存取（读写）方式

- 顺序表：可以顺序存取，也可以随机存取。
- 链表：只能从表头顺序存取元素。

##### 2. 逻辑结构与物理结构

- 顺序存储：逻辑上相邻的元素，对应的物理存储位置也相邻。
- 链式存储：逻辑上相邻的元素，物理存储位置不一定相邻，逻辑关系通过指针链接表示。

##### 3. 查找、插入和删除操作

| 操作类型   | 顺序表                                                                          | 链表                                                           |
| ---------- | ------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| 按值查找   | 1. 有序：可采用折半查找，时间复杂度为O(log₂n)`<br>`2. 无序：时间复杂度为O(n) | 时间复杂度为O(n)（需遍历）                                     |
| 按序号查找 | 支持随机访问，时间复杂度为O(1)                                                  | 平均时间复杂度为O(n)（需遍历）                                 |
| 插入、删除 | 平均需要移动半个表长的元素，时间复杂度为O(n)                                    | 只需修改相关结点的指针域，时间复杂度为O(1)（查找前驱结点除外） |

##### 4. 空间分配

- 顺序存储：
  - 分为静态分配和动态分配。
  - 动态分配扩充空间时需进行数据移动，效率低下；存储空间满则无法扩充，会出现内存溢出。
- 链式存储：空间分配非常灵活，无需预先估计存储规模。

#### （三）存储结构的选取原则

##### 1. 基于存储的考虑

- 难以估计线性表的长度或存储规模时，不宜采用顺序表。
- 链表不用事先估计存储规模，但存储密度较低（需附加指针域）。

##### 2. 基于运算的考虑

- 频繁进行**按序号访问数据元素**操作：顺序表优于链表。
- 频繁进行**插入、删除**操作：链表优于顺序表。

##### 3. 基于环境的考虑

- 顺序表基于数组，更容易实现。
- 链表基于指针，在某些编程语言中不适合实现。
