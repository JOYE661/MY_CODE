# 树（数据结构）

## 5.1 树的基本概念

### 1. 树的定义

树是 `n(n≥0)` 个节点的有限集，具体规则如下：

- 当 `n=0` 时，称为**空树**；
- 当 `n>0`（非空树）时，需满足两个条件：
  1. 有且仅有一个特定的称为**根**的节点（无前驱节点）；
  2. 其余节点可分为 `m(m>0)` 个互不相交的有限集 `T₁,T₂,…,Tₘ`，每个集合本身又是一棵树，称为根的**子树**。

树的核心特性：

- 逻辑结构：递归结构（子树仍是树），同时是**分层结构**；
- 节点关系：根节点无前驱，除根外所有节点有且仅有一个前驱；所有节点可有零个或多个后继。

（示意图说明：存在高度为4的树，分为第1层、第2层、第3层、第4层，层内节点按分层逻辑排列）

### 2. 基本术语

以“节点K”为例，结合树的结构定义核心术语：

- **祖先**：根（如A）到节点K的唯一路径上的任意节点（如A、B、E）；
- **双亲与孩子**：路径上最接近K的节点（如E）称为K的**双亲**，K称为E的**孩子**；
- **子孙**：若节点（如B）是K的祖先，则K是B的**子孙**；
- **兄弟**：有相同双亲的节点（如K和L，双亲均为E）互为兄弟；
- **节点的度**：树中一个节点的孩子个数；**树的度**：树中所有节点的最大度数；
- **分支节点（非终端节点）**：度大于0的节点；
- **叶子节点（终端节点）**：度为0（无子女）的节点；
- **节点的层次**：从树根开始定义，根节点为第1层，其子节点为第2层，以此类推；
- **节点的高度**：从叶节点开始自底向上逐层累加的层数；
- **节点的深度**：从根节点开始自顶向下逐层累加的层数；
- **树的高度（或深度）**：树中节点的最大层数；
- **有序树与无序树**：若节点的各子树从左到右有次序、不可互换，称为**有序树**；否则为**无序树**；
- **路径和路径长度**：两个节点之间的路径是经过的节点序列，路径长度是路径上经过的**边的个数**；
- **森林**：`n(n≥0)` 棵互不相交的树的集合；
  - 森林转树：给m棵独立的树加一个新节点，将m棵树作为新节点的子树；
  - 树转森林：删除树的根节点，原树的子树构成森林。

### 3. 树的性质

1. 树中的节点数 = 所有节点的度数之和 + 1；
2. **m叉树（每个节点最多m个孩子）** 相关性质：
   - 度为m的树中，第i层上至多有 `m^(i-1)` 个节点（`i≥1`）；
   - 高度为h的m叉树，至少有 `h` 个节点，至多有 `(m^h - 1)/(m - 1)` 个节点；
   - 高度为h、度为m的树，至少有 `h + m - 1` 个节点；
   - 具有n个节点的m叉树，最小高度为 `⌈logₘ(n(m - 1) + 1)⌉`（`⌈⌉` 表示向上取整）；
3. **m叉树与度为m的树的区别**：| 对比维度   | m叉树                            | 度为m的树                              |
   | ---------- | -------------------------------- | -------------------------------------- |
   | 节点度限制 | 任意节点的度 ≤ m（最多m个孩子） | 任意节点的度 ≤ m，且至少1个节点度 = m |
   | 是否为空树 | 可以是空树                       | 一定是非空树，至少有m + 1个节点        |
   | 子树数量   | 允许所有节点的度 < m             | 必须存在一个节点有m个子树              |

## 5.2 二叉树的概念

### 1. 二叉树的定义

二叉树是另一种树形结构，核心特点：

- 每个节点至多只有两棵子树（左子树和右子树）；
- 子树有左右之分，次序不能任意颠倒（即使只有一棵子树，也需区分左/右）。

### 2. 二叉树与“度为2的有序树”的区别

| 对比维度   | 二叉树                          | 度为2的有序树                                                  |
| ---------- | ------------------------------- | -------------------------------------------------------------- |
| 空树可能性 | 可以是空树                      | 非空树，至少有3个节点（根+两个孩子）                           |
| 子树次序   | 无论孩子数是否为2，均需区分左右 | 孩子的左右次序相对于另一孩子而言；若只有一个孩子，无需区分左右 |

### 3. 特殊的二叉树

#### （1）满二叉树

- 定义：高度为h、且含有 `2^h - 1` 个节点的二叉树（每层节点数均为该层最大可能值）；
- 节点编号规则（按层序从左到右编号1~2^h - 1）：
  - 对于编号为i的节点：
    - 双亲编号为 `⌊i/2⌋`（`⌊⌋` 表示向下取整）；
    - 若有左孩子，左孩子编号为 `2i`；
    - 若有右孩子，右孩子编号为 `2i + 1`。

#### （2）完全二叉树

- 定义：高度为h、有n个节点的二叉树，当且仅当其每个节点都与高度为h的满二叉树中编号为1~n的节点一一对应时，称为完全二叉树；
- 核心特点：
  1. 叶子节点只可能在层次最大的两层上出现；
  2. 最大层次中的叶子节点，依次排列在该层最左边的位置；
  3. 若有度为1的节点，则只可能有一个，且该节点只有左孩子、无右孩子；
  4. 按层序编号后，若某节点（编号i）为叶子或只有左孩子，则编号大于i的节点均为叶子；
  5. 节点总数n与分支节点的关系：
     - 若n为奇数，每个分支节点都有左、右孩子；
     - 若n为偶数，编号最大的分支节点（编号 `n/2`）只有左孩子，其余分支节点有左、右孩子；
  6. 分支节点判定：编号 `i ≤ ⌊n/2⌋` 的节点为分支节点，否则为叶子节点。

#### （3）二叉排序树

- 定义（有序性）：
  1. 若左子树非空，则左子树上所有节点的关键字均小于根节点的关键字；
  2. 若右子树非空，则右子树上所有节点的关键字均大于根节点的关键字；
  3. 左、右子树也分别是一棵二叉排序树。

#### （4）平衡二叉树

- 定义：树上任一节点的左子树和右子树的深度之差（称为**平衡因子**）的绝对值不超过1；
- 平衡因子的可能值：-1、0、1。

### 4. 二叉树的性质

1. 非空二叉树上的叶子节点数 = 度为2的节点数 + 1（即 `n₀ = n₂ + 1`）；
2. 非空二叉树上第k层上至多有 `2^(k-1)` 个节点（`k≥1`）；
3. 高度为h的二叉树至多有 `2^h - 1` 个节点；
4. 对完全二叉树按层序编号（1~n），节点i（1≤i≤n）的关系：
   - 当i>1时，双亲编号为 `⌊i/2⌋`：
     - i为偶数时，是双亲的左孩子；
     - i为奇数时，是双亲的右孩子（i≠1）；
   - 若 `2i ≤ n`，则左孩子编号为 `2i`；否则无左孩子；
   - 若 `2i + 1 ≤ n`，则右孩子编号为 `2i + 1`；否则无右孩子；
   - 节点i所在层次（深度）为 `⌊log₂i⌋ + 1`；
5. 具有n个节点（n>0）的完全二叉树的高度为 `⌈log₂(n + 1)⌉` 或 `⌊log₂n⌋ + 1`。

### 5. 二叉树的存储结构

#### （1）顺序存储结构

- 实现方式：用一组地址连续的存储单元，按层序（自上而下、自左至右）存储完全二叉树的节点；完全二叉树编号为i的节点，存储在一维数组下标为 `i-1` 的分量中；
- 适用场景：完全二叉树、满二叉树（空间利用率高）；
- 一般二叉树的处理：需添加“空节点”（用特殊值标记），使每个节点与完全二叉树的节点对应，再存储到数组中（空间利用率低）。

#### （2）链式存储结构

- 定义：用链表节点存储二叉树的每个节点，每个节点包含3个域：
  - 数据域（data）：存储节点值；
  - 左孩子指针域（lchild）：指向左子树的根节点；
  - 右孩子指针域（rchild）：指向右子树的根节点；
- 结构描述（C语言风格）：
  ```c
  typedef struct BiTNode {
      ElemType data;          // 数据域
      struct BiTNode *lchild; // 左孩子指针
      struct BiTNode *rchild; // 右孩子指针
  } BiTNode, *BiTree;
  ```
- 特点：空间利用率高（无冗余空节点），是二叉树的主流存储方式；
- 空链域数量：含有n个节点的二叉链表中，共有 `n + 1` 个空链域。

## 5.3 二叉树的遍历和线索二叉树

### 1. 二叉树的遍历

遍历是按一定规则将二叉树的节点排列成线性序列，核心遍历方式有4种，时间复杂度均为 `O(n)`（n为节点数）。

#### （1）先序遍历（根→左→右）

- 递归步骤：
  1. 访问根节点；
  2. 先序遍历左子树；
  3. 先序遍历右子树。
- 非递归实现：利用栈存储待访问的节点，先压右子树、再压左子树（保证左子树先访问）。

#### （2）中序遍历（左→根→右）

- 递归步骤：
  1. 中序遍历左子树；
  2. 访问根节点；
  3. 中序遍历右子树。
- 非递归实现：利用栈，先遍历左子树至最左节点，弹出节点访问后，再遍历右子树。

#### （3）后序遍历（左→右→根）

- 递归步骤：
  1. 后序遍历左子树；
  2. 后序遍历右子树；
  3. 访问根节点。
- 非递归实现：利用栈，需标记节点是否已访问（或通过两次入栈区分），避免重复遍历。

#### （4）层次遍历（按层访问）

- 实现方式：利用队列；
- 步骤：
  1. 将二叉树根节点入队；
  2. 出队，访问出队节点；
  3. 若出队节点有左子树，将左子树根节点入队；
  4. 若出队节点有右子树，将右子树根节点入队；
  5. 重复步骤2~4，直至队列为空。

### 2. 由遍历序列构造二叉树

- 唯一构造条件（满足其一即可）：
  1. 二叉树的**先序序列 + 中序序列**；
  2. 二叉树的**后序序列 + 中序序列**；
  3. 二叉树的**层序序列 + 中序序列**（或层序序列 + 后序序列）；
- 注意：先序序列 + 后序序列**不能唯一确定**一棵二叉树（无法区分单孩子的左右位置）。

### 3. 线索二叉树

#### （1）基本概念

- 定义：将二叉链表中的**空链域**改为指向“前驱”或“后继”的指针（称为**线索**），使遍历序列中的每个节点（除首尾）都有唯一前驱和后继；
- 线索化：遍历二叉树的过程中，将空链域改为线索的操作（实质是“遍历+记录前驱/后继”）。

#### （2）节点结构

每个节点新增两个**标志域**（ltag、rtag），区分指针指向“孩子”还是“线索”：

| 标志域 | 取值 | 含义（lchild/rchild的作用） |
| ------ | ---- | --------------------------- |
| ltag   | 0    | 指向左孩子                  |
| ltag   | 1    | 指向前驱节点                |
| rtag   | 0    | 指向右孩子                  |
| rtag   | 1    | 指向后继节点                |

节点结构描述（C语言风格）：

```c
typedef struct ThreadNode {
    ElemType data;          // 数据域
    struct ThreadNode *lchild, *rchild; // 左/右指针（孩子或线索）
    int ltag, rtag;         // 左/右标志域（0=孩子，1=线索）
} ThreadNode, *ThreadTree;
```

#### （3）中序线索二叉树（核心类型）

##### ① 中序线索二叉树的构造（线索化）

- 核心思路：中序遍历过程中，用指针 `pre` 记录“刚刚访问过的节点”（当前节点 `p` 的前驱），检查 `p` 和 `pre` 的空链域，改为线索；
- 步骤：
  1. 初始化 `pre = NULL`；
  2. 中序遍历二叉树，访问当前节点 `p`；
  3. 若 `p->lchild == NULL`：设置 `p->ltag = 1`，`p->lchild = pre`（左空链改为前驱线索）；
  4. 若 `pre != NULL` 且 `pre->rchild == NULL`：设置 `pre->rtag = 1`，`pre->rchild = p`（pre的右空链改为后继线索）；
  5. 更新 `pre = p`，继续遍历下一个节点。

##### ② 中序线索二叉树的遍历

- 遍历规则：无需栈/队列，利用线索直接找前驱/后继；
- 步骤：
  1. 从根节点出发，找到中序遍历的第一个节点（最左下节点，`ltag=0` 时继续找左孩子）；
  2. 访问当前节点；
  3. 若当前节点 `rtag=1`：后继为 `rchild` 指向的节点；
  4. 若当前节点 `rtag=0`：后继为右子树的“最左下节点”；
  5. 重复步骤2~4，直至节点为NULL。

#### （4）先序线索二叉树与后序线索二叉树

- 先序线索二叉树：
  - 构造：先序遍历过程中线索化，先访问节点再处理左/右子树；
  - 遍历：找先序后继简单（利用右线索或右子树先序第一个节点），找先序前驱需知道双亲节点；
- 后序线索二叉树：
  - 构造：后序遍历过程中线索化，先处理左/右子树再访问节点；
  - 遍历：找后序前驱简单（利用左线索或左子树后序最后一个节点），找后序后继需知道双亲节点。

## 5.4 树、森林

### 1. 树的存储结构

#### （1）双亲表示法

- 实现方式：用一组连续空间存储节点，每个节点增设“伪指针”（parent），指示其双亲在数组中的位置；
  - 根节点的parent域为 `-1`（下标从0开始）；
- 优点：快速查找节点的双亲（通过parent域直接定位）；
- 缺点：查找节点的孩子需遍历整个数组（需检查所有节点的parent是否等于当前节点下标）。

#### （2）孩子表示法

- 实现方式：每个节点的孩子用“链表”存储（称为“孩子表”），所有节点的信息存储在数组中，数组元素包含“节点值”和“孩子表头指针”；
  - 叶子节点的孩子表为空表；
- 优点：快速查找节点的所有孩子（直接遍历孩子表）；
- 缺点：查找节点的双亲需遍历所有节点的孩子表（检查当前节点是否在某孩子表中）。

#### （3）孩子兄弟表示法（二叉树表示法）

- 实现方式：每个节点包含3个域：
  - 数据域（data）：存储节点值；
  - 第一个孩子指针（lchild）：指向节点的第一个孩子；
  - 右兄弟指针（rsibling）：指向节点的下一个兄弟；
- 结构描述（C语言风格）：
  ```c
  typedef struct CSNode {
      ElemType data;              // 数据域
      struct CSNode *lchild;      // 指向第一个孩子
      struct CSNode *rsibling;    // 指向右兄弟
  } CSNode, *CSTree;
  ```
- 优点：
  1. 灵活，可直接转换为二叉树（lchild为左子树，rsibling为右子树）；
  2. 快速查找节点的孩子（通过lchild找第一个孩子，再通过rsibling找其他孩子）；
- 缺点：查找节点的双亲需遍历树（需回溯兄弟或孩子指针）。

### 2. 树、森林与二叉树的转换

#### （1）树转换为二叉树

- 规则（核心：“孩子→左子树，兄弟→右子树”）：
  1. 对树中每个节点，只保留它与**第一个孩子**的连线，删除与其他孩子的连线；
  2. 对每个节点的孩子，将其**右兄弟**用连线连接起来；
  3. 以树根为轴心，顺时针旋转45°，使结构符合二叉树的左/右子树逻辑。

#### （2）森林转换为二叉树

- 规则：
  1. 将森林中的每棵树分别转换为二叉树；
  2. 将每棵二叉树的根节点视为“兄弟关系”，从左到右依次将前一棵二叉树的根节点的**右子树**与后一棵二叉树的根节点连接；
  3. 最终形成一棵以第一棵树的根为总根的二叉树。

#### （3）二叉树转换为森林

- 规则：
  1. 若二叉树非空，其根及其**左子树**为第一棵树的二叉树形式；
  2. 将根的**右子树**断开，视为新的二叉树，重复步骤1，直至所有右子树断开；
  3. 将得到的多棵二叉树分别转换为树，构成森林。

### 3. 树和森林的遍历

#### （1）树的遍历

| 遍历方式 | 规则                                       | 与二叉树遍历的对应关系         |
| -------- | ------------------------------------------ | ------------------------------ |
| 先根遍历 | 1. 访问根节点；2. 依次先根遍历根的每棵子树 | 对应二叉树的**先序遍历** |
| 后根遍历 | 1. 依次后根遍历根的每棵子树；2. 访问根节点 | 对应二叉树的**中序遍历** |

#### （2）森林的遍历

| 遍历方式 | 规则                                                                        | 与二叉树遍历的对应关系         |
| -------- | --------------------------------------------------------------------------- | ------------------------------ |
| 先序遍历 | 1. 访问第一棵树的根节点；2. 先序遍历第一棵树的子树森林；3. 先序遍历剩余森林 | 对应二叉树的**先序遍历** |
| 中序遍历 | 1. 中序遍历第一棵树的子树森林；2. 访问第一棵树的根节点；3. 中序遍历剩余森林 | 对应二叉树的**中序遍历** |

#### （3）遍历对应关系总表

| 树       | 森林     | 二叉树   |
| -------- | -------- | -------- |
| 先根遍历 | 先序遍历 | 先序遍历 |
| 后根遍历 | 中序遍历 | 中序遍历 |

### 4. 树的应用——并查集

#### （1）支持的操作

1. `Initial(S)`：初始化集合S，将每个元素初始化为“仅含自身的子集合”；
2. `Find(S, x)`：查找元素x所在的子集合，返回该子集合的根节点（子集合名）；
3. `Union(S, Root₁, Root₂)`：将子集合Root₂并入子集合Root₁（要求Root₁与Root₂互不相交，否则不执行）。

#### （2）存储结构

- 采用**树的双亲表示法**（数组存储）：
  - 数组下标代表元素名；
  - 数组值代表双亲下标；
  - 根节点的数组值为负数（通常为-1，标识根身份）。

#### （3）核心实现（C语言风格）

```c
#define SIZE 100  // 集合最大元素数
int UFSets[SIZE];  // 双亲表示数组（下标=元素，值=双亲下标）

// 初始化
void Initial() {
    for (int i = 0; i < SIZE; i++) {
        UFSets[i] = -1;  // 根节点标记为-1
    }
}

// 查找（找x所在子集合的根）
int Find(int x) {
    while (UFSets[x] >= 0) {  // 非根节点（值≥0），继续找双亲
        x = UFSets[x];
    }
    return x;  // 返回根节点下标
}

// 合并（Root2并入Root1）
void Union(int Root1, int Root2) {
    UFSets[Root2] = Root1;  // Root2的双亲设为Root1
}
```

## 5.5 树与二叉树的应用

### 5.5.1 二叉排序树（BST）

#### 1. 定义（回顾）

- 左子树所有节点值 < 根节点值；
- 右子树所有节点值 > 根节点值；
- 左、右子树均为二叉排序树；
- 中序遍历二叉排序树，可得到**递增有序序列**。

#### 2. 二叉排序树的查找

- 核心逻辑：从根节点开始，沿分支逐层比较（利用有序性）；
- 步骤：
  1. 若二叉排序树为空，查找失败；
  2. 若给定值 `key == 根节点值`，查找成功；
  3. 若 `key < 根节点值`，在左子树中查找；
  4. 若 `key > 根节点值`，在右子树中查找；
  5. 重复步骤2~4，直至找到或子树为空。

#### 3. 二叉排序树的插入

- 核心逻辑：插入节点必为**新叶节点**，插入位置为“查找失败时的最后一个节点”的左/右孩子；
- 步骤：
  1. 若原二叉排序树为空，直接将新节点作为根节点；
  2. 若 `key < 根节点值`：
     - 若左子树为空，新节点作为左孩子；
     - 否则，在左子树中插入；
  3. 若 `key > 根节点值`：
     - 若右子树为空，新节点作为右孩子；
     - 否则，在右子树中插入；
- 示例：关键字序列 `(45,24,53,45,12,24)` 生成二叉排序树（相同关键字不重复插入，或按规则插入左/右子树）。

#### 4. 二叉排序树的删除

需保证删除后仍满足二叉排序树的有序性，分3种情况：

1. **被删除节点z是叶节点**：直接删除z，将z的双亲的对应孩子指针设为NULL；
2. **节点z只有一棵子树（左或右）**：让z的子树直接替代z的位置（z的双亲指向z的子树）；
3. **节点z有左、右两棵子树**：
   - 方法1：找z的**直接后继**（右子树的最左下节点，值最小的大于z的节点），用后继的值替代z的值，再删除后继节点（后继为叶节点或只有右子树，归为情况1或2）；
   - 方法2：找z的**直接前驱**（左子树的最右下节点，值最大的小于z的节点），用前驱的值替代z的值，再删除前驱节点。

#### 5. 查找效率分析

- 平均查找长度（ASL）取决于树的高度：
  - 理想情况（平衡二叉排序树）：ASL = `O(log₂n)`；
  - 最坏情况（树呈单链，如有序序列插入）：ASL = `O(n)`（等同于顺序查找）。
