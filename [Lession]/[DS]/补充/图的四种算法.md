你提的这四个算法是图论的核心，覆盖了最小生成树和最短路径两大经典问题，理解它们的区别和适用场景非常关键。

这四个算法的核心定位不同：**Prim和Kruskal用于求最小生成树（MST）**，即连接图中所有顶点且总边权最小的无环子图；**Dijkstra和Floyd用于求最短路径**，前者是“单源”（从一个起点到所有其他顶点），后者是“多源”（任意两点之间）。

### 一、Prim最小生成树算法：（不是单原点出发）

Prim算法是“**加点法**”，从一个起点顶点开始，逐步将与当前生成树最近的顶点加入，直到包含所有顶点。

#### 1. 核心思想

以任意顶点为初始生成树，每次从“生成树外的顶点”中，选择一条与“生成树内顶点”相连的**权值最小的边**，将对应的顶点加入生成树，重复此过程直到所有顶点都被加入。

#### 2. 适用场景

- 图为**稠密图**（顶点少、边多），因为算法效率与顶点数量关联更紧密。
- 无向图（最小生成树仅针对无向图）。

#### 3. 关键步骤

1. 初始化：选择一个起点（如顶点A），标记为“已加入生成树”，其他顶点标记为“未加入”。
2. 找最小边：遍历所有“已加入顶点”与“未加入顶点”之间的边，选权值最小的边，将对应的“未加入顶点”标记为“已加入”。
3. 重复步骤2：直到所有顶点都被加入生成树，此时收集的边即为最小生成树的边。

#### 4. 时间复杂度

- 邻接矩阵实现：O(n²)（n为顶点数），适合稠密图。
- 邻接表+优先队列实现：O(m log n)（m为边数），适合稀疏图，但效率不如Kruskal。

### 二、Kruskal最小生成树算法：

Kruskal算法是“**加边法**”，先将所有边按权值排序，再依次选权值最小的边，确保加入后不构成环，直到包含所有顶点。

#### 1. 核心思想

将图中所有边按权值从小到大排序，依次选取边：若该边连接的两个顶点不在同一连通分量（即加入后不构成环），则保留该边；否则丢弃，直到保留的边数为“顶点数-1”（生成树的边数固定为n-1）。

#### 2. 适用场景

- 图为**稀疏图**（顶点多、边少），因为算法效率与边的排序关联更紧密。
- 无向图（同Prim）。

#### 3. 关键步骤

1. 边排序：将所有边按权值从小到大排序。
2. 初始化并查集（Union-Find）：用于判断两个顶点是否在同一连通分量（避免环）。
3. 选边：按排序后的顺序遍历边，对每条边：
   - 若边的两个顶点不在同一集合，合并集合并保留该边。
   - 若在同一集合，跳过该边。
4. 终止条件：当保留的边数为n-1时，停止遍历，保留的边即为最小生成树的边。

#### 4. 时间复杂度

- 主要耗时在边的排序：O(m log m)（m为边数），适合稀疏图（m远小于n²）。

### 三、Dijkstra最短路径算法：（单原点出发）

Dijkstra算法是“**单源最短路径**”算法，用于求从一个起点顶点到所有其他顶点的最短路径，**不支持负权边**。

#### 1. 核心思想

以起点为初始点，维护一个“起点到各顶点的当前最短距离”数组，每次选择“当前最短距离最小且未确定”的顶点，更新其邻接顶点的最短距离（即“松弛操作”），直到所有顶点的最短距离都确定。

#### 2. 适用场景

- 求**单源最短路径**（如从“顶点A”到所有其他顶点的最短距离）。
- 图中**无负权边**（负权边会导致算法误判最短距离，无法收敛）。
- 有向图或无向图均可。

#### 3. 关键步骤

1. 初始化：
   - 距离数组dist[]：dist[起点] = 0，其他顶点dist[] = 无穷大。
   - 标记数组visited[]：标记顶点是否已确定最短距离，初始全为false。
2. 选当前最短顶点：在未标记的顶点中，选dist[]最小的顶点u，标记visited[u] = true。
3. 松弛操作：遍历u的所有邻接顶点v，若dist[v] > dist[u] + 边(u,v)的权值，则更新dist[v] = dist[u] + 边权。
4. 重复步骤2-3：直到所有顶点都被标记，此时dist[]数组即为起点到各顶点的最短距离。

#### 4. 时间复杂度

- 邻接矩阵实现：O(n²)。
- 邻接表+优先队列实现：O(m log n)，效率更高。


### 四、Floyd最短路径算法：

**每个节点都当一次 “中间跳板”，能绕路更短就更新**

Floyd算法是“**多源最短路径**”算法，用于求**任意两个顶点之间**的最短路径，**支持负权边，但不支持负权环**。

#### 1. 核心思想

基于“动态规划”，通过引入“中间顶点”优化任意两点的最短路径：对于任意两点i和j，判断是否存在中间顶点k，使得i→k→j的路径比i→j的直接路径更短，若存在则更新i到j的最短距离，直到所有中间顶点都被尝试。

#### 2. 适用场景

- 求**多源最短路径**（任意两点之间的最短距离）。
- 图中可含负权边，但**不能有负权环**（负权环会导致路径长度无限减小，无最短路径）。
- 有向图或无向图均可，适合顶点数较少的图（时间复杂度较高）。

#### 3. 关键步骤

1. 初始化距离矩阵dist[][]：
   - dist[i][i] = 0（自身到自身距离为0）。
   - 若i和j之间有直接边，dist[i][j] = 边权；否则dist[i][j] = 无穷大。
2. 引入中间顶点k：遍历所有顶点作为中间顶点k（k从1到n）。
3. 更新距离：对于任意两点i和j，判断dist[i][j] > dist[i][k] + dist[k][j]，若成立则更新dist[i][j] = dist[i][k] + dist[k][j]。
4. 终止条件：当k遍历完所有顶点后，dist[i][j]即为i到j的最短距离。

#### 4. 时间复杂度

- 固定为O(n³)（n为顶点数），因为需要三重循环（i、j、k各遍历n次），适合顶点数较少的图。

### 五、四大算法核心对比

| 算法     | 核心用途     | 适用图类型     | 负权处理                 | 时间复杂度（常用实现） |
| -------- | ------------ | -------------- | ------------------------ | ---------------------- |
| Prim     | 最小生成树   | 无向图、稠密图 | 无负权要求（边权非负）   | O(n²)（邻接矩阵）     |
| Kruskal  | 最小生成树   | 无向图、稀疏图 | 无负权要求（边权非负）   | O(m log m)（边排序）   |
| Dijkstra | 单源最短路径 | 有/无向图      | 不支持负权边             | O(m log n)（优先队列） |
| Floyd    | 多源最短路径 | 有/无向图      | 支持负权边，不支持负权环 | O(n³)                 |
