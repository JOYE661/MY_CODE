## 二、考点优先级排序（按考试占分权重+出现频次）

### 第一优先级（核心必掌握，占总分60%+，每年有大题）

1. 数据结构：二叉树遍历与平衡调整、图的拓扑/最短路径、快排/堆排过程
2. 组成原理：Cache映射与虚拟存储地址转换、指令寻址方式、CPU流水线计算
3. 操作系统：PV操作同步互斥、进程调度算法、LRU/FIFO页面置换
4. 计算机网络：TCP三次握手/拥塞控制、IP子网划分与路由聚合、CSMA/CD最小帧长

### 第二优先级（必考选择，占总分30%，偶尔出大题）

1. 数据结构：栈/队列判空判满、折半查找、B树结点计算
2. 组成原理：补码/浮点数运算、中断处理流程、总线带宽计算
3. 操作系统：死锁银行家算法、文件索引结构、SCAN磁盘调度
4. 计算机网络：ARP协议、RIP/OSPF区别、HTTP/DNS协议特点

### 第三优先级（高频选择，占总分10%，冷门考点）

1. 数据结构：B+树与B树区别、稀疏矩阵存储
2. 组成原理：硬布线/微程序控制器、I/O端口编址
3. 操作系统：Spooling技术、设备分配策略
4. 计算机网络：物理层编码、ICMP报文、FTP数据/控制连接

## 三、分阶段复习计划

### 阶段一：基础攻坚（总复习时间50%，主攻第一优先级考点）

1. **时间分配**（共8周）
   - 数据结构（2周）：手写二叉树前中后序/层序遍历代码、手动模拟Dijkstra最短路径、掌握快排/堆排的完整过程，完成2009-2015年相关大题
   - 组成原理（2周）：推导Cache直接/组相联映射的地址、计算流水线吞吐率、掌握页式虚拟存储地址转换，吃透2009-2015年存储/指令大题
   - 操作系统（2周）：总结PV操作的5类经典模型（生产者消费者、读者写者等）、手动计算响应比和LRU置换缺页次数，完成2009-2015年PV和置换大题
   - 计算机网络（2周）：画图理解TCP三次握手/拥塞控制、手动计算子网划分和路由聚合，攻克2009-2015年TCP/IP大题
2. **核心要求**：每个考点必须**手动推导+真题验证**，形成错题本标记易错步骤

### 阶段二：强化巩固（总复习时间30%，掌握第二优先级考点）

1. **时间分配**（共4周）
   - 数据结构（1周）：总结栈/队列判空判满公式、折半查找比较次数规律、B树插入删除规则，刷2016-2023年相关选择
   - 组成原理（1周）：整理补码运算步骤、IEEE754浮点数转换流程、中断处理的关键步骤，完成2016-2023年数据表示/中断选择
   - 操作系统（1周）：掌握银行家算法的安全序列判断、文件索引结构的最大长度计算、SCAN调度磁道数计算，做2016-2023年相关小题
   - 计算机网络（1周）：区分RIP/OSPF协议的跳数/链路状态、总结HTTP请求头字段含义，刷2016-2023年协议类选择
2. **核心要求**：针对同类题型**总结模板**，如子网划分的“先算子网掩码再定主机范围”

### 阶段三：查漏补缺（总复习时间20%，覆盖第三优先级考点+套卷模拟）

1. **时间分配**（共4周）
   - 冷门考点速记（2周）：整理第三优先级考点的速记口诀（如B树“根最少2子，叶在同一层”），快速过2016-2023年冷门选择
   - 真题套卷模拟（2周）：按考试时间完成2016-2023年完整真题，统计各科失分点，回归第一优先级考点查漏补缺
2. **核心要求**：套卷模拟后**针对性复盘**，确保核心考点不丢分，冷门考点不拖后腿
