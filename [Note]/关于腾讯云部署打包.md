部署前端到腾讯云轻量服务器（Docker方式）的完整步骤，从**系统安装**到**访问验证**，全程手把手操作，新手也能看懂：

### 一、第一步：给轻量服务器装系统（CentOS 7/8 推荐）

腾讯云轻量服务器装系统很简单，全程在控制台操作，无需复杂命令：

1. 登录 [腾讯云控制台](https://console.cloud.tencent.com/)，进入「轻量应用服务器」列表
2. 找到你的服务器，点击「更多」→「重装系统」
3. 系统选择：推荐 **CentOS 7.9 64位**（兼容性最好，Docker安装无坑），也可以选 CentOS 8 或 Ubuntu 20.04
4. 登录方式：建议选「设置密码」，设置一个高强度密码（后续SSH登录用），确认后开始重装
5. 等待5-10分钟，系统重装完成，记录服务器的 **公网IP**（控制台列表里能看到）

### 二、第二步：连接服务器（本地操作，2种方式可选）

装完系统后，需要通过「SSH」连接服务器，才能执行后续命令：

#### 方式1：Windows电脑（用Xshell，免费）

1. 下载安装 [Xshell免费版](https://www.xshell.com/zh/free-for-home-school/)
2. 打开Xshell，点击「新建」：
   - 名称：随便填（比如「我的前端服务器」）
   - 主机：填服务器的「公网IP」
   - 端口：默认22（不用改）
3. 点击「连接」，输入用户名（CentOS默认是 `root`），再输入第一步设置的密码，即可登录成功

#### 方式2：Mac/Linux电脑（自带终端）

1. 打开终端，输入命令（替换成你的公网IP）：
   ```bash
   ssh root@你的服务器公网IP
   ```
2. 提示「Are you sure...」，输入 `yes` 回车，再输入服务器密码，即可登录

### 三、第三步：服务器安装Docker（核心依赖）

登录服务器后，执行以下命令安装Docker（CentOS 7/8通用，复制粘贴执行即可）：

#### 1. 先卸载旧版本（防止冲突）

```bash
yum remove docker docker-client docker-client-latest docker-common docker-latest docker-latest-logrotate docker-logrotate docker-engine
```

#### 2. 安装Docker依赖包

```bash
yum install -y yum-utils device-mapper-persistent-data lvm2
```

#### 3. 设置Docker镜像源（用阿里云，国内下载快）

```bash
yum-config-manager --add-repo http://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo
```

#### 4. 安装Docker（社区版，免费）

```bash
yum install -y docker-ce docker-ce-cli containerd.io
```

#### 5. 启动Docker并设置开机自启

```bash
# 启动Docker
systemctl start docker
# 设置开机自启（重启服务器后Docker自动运行）
systemctl enable docker
```

#### 6. 验证Docker是否安装成功

执行命令，能看到Docker版本就说明成功：

```bash
docker --version
```

### 四、第四步：准备前端代码和Docker文件

需要在**本地电脑**做2件事，再把文件传到服务器：

#### 1. 本地前端代码打包（关键！必须先构建）

如果是Vue/React/Angular等框架项目，先执行打包命令生成静态文件（纯HTML/CSS/JS项目可跳过，直接用原文件）：

- Vue项目：`npm run build`（打包后生成 `dist` 文件夹）
- React项目：`npm run build`（打包后生成 `build` 文件夹）
- 纯静态项目：直接用你的HTML/CSS/JS文件（建议放在一个文件夹里，比如叫 `frontend`）

#### 2. 本地创建Dockerfile（和打包后的文件夹同级）

在打包后的文件夹（比如 `dist`）**同级目录**，新建一个文件，命名为 `Dockerfile`（无后缀名），内容如下：

```dockerfile
# 基础镜像：用Nginx来运行静态文件（Nginx是web服务器，适合部署前端）
FROM nginx:alpine

# 清除Nginx默认的静态文件（可选，避免冲突）
RUN rm -rf /usr/share/nginx/html/*

# 把本地打包后的前端文件，复制到Nginx的静态文件目录
# 注意：如果你的打包文件夹是build，就改成COPY build /usr/share/nginx/html
COPY dist /usr/share/nginx/html

# 暴露80端口（Nginx默认端口，后续访问用）
EXPOSE 80

# 启动Nginx（前台运行，避免容器启动后退出）
CMD ["nginx", "-g", "daemon off;"]
```

#### 3. 把文件传到服务器

用「文件传输」工具，把以下2个东西传到服务器的同一个目录（比如 `/root/frontend`）：

- 打包后的前端文件夹（`dist` 或 `build`）
- `Dockerfile` 文件

##### 传输工具推荐：

- Windows：用Xshell自带的「Xftp」（和Xshell配套，免费）
- Mac/Linux：用 `scp` 命令（终端直接传），示例：
  ```bash
  # 本地终端执行，替换成你的文件路径和服务器IP
  scp -r /本地打包文件夹路径 root@你的服务器公网IP:/root/frontend
  scp /本地Dockerfile路径 root@你的服务器公网IP:/root/frontend
  ```

### 五、第五步：构建Docker镜像并启动容器

回到服务器的SSH连接（Xshell/终端），执行以下命令：

#### 1. 进入前端文件所在目录

```bash
cd /root/frontend  # 替换成你上传文件的目录
```

#### 2. 构建Docker镜像（给镜像起个名字，比如 `frontend-image`）

```bash
docker build -t frontend-image .
```

- 注意命令最后有个 `.`，表示当前目录的Dockerfile
- 执行后会下载Nginx基础镜像，然后复制前端文件，耐心等几十秒，出现「Successfully built」就是构建成功

#### 3. 启动Docker容器（运行前端服务）

```bash
# 启动容器，命名为frontend-container，映射80端口
docker run -d -p 80:80 --name frontend-container frontend-image
```

- 参数说明：
  - `-d`：后台运行容器
  - `-p 80:80`：端口映射（服务器80端口 → 容器80端口，外部通过服务器IP:80访问）
  - `--name`：给容器起个名字，方便后续管理

#### 4. 验证容器是否启动成功

```bash
docker ps
```

如果能看到 `frontend-container` 一行，状态是 `Up`，就说明启动成功了！

### 六、第六步：开放服务器端口（关键！否则访问不到）

腾讯云轻量服务器默认会拦截80端口，需要在控制台开放：

1. 回到腾讯云轻量服务器控制台，找到你的服务器，点击「防火墙」
2. 点击「添加规则」，配置如下：
   - 端口：`80`（Nginx默认端口，和容器映射的一致）
   - 协议：`TCP`
   - 备注：随便填（比如「前端访问端口」）
3. 保存规则，等待1-2分钟生效

### 七、第七步：访问验证！

打开本地浏览器，输入地址：

```
http://你的服务器公网IP
```

如果能看到你的前端页面，说明部署成功了！🎉

### 常见问题排查（部署失败看这里）

1. 浏览器访问超时/无法连接：

   - 检查服务器防火墙是否开放80端口（第六步）
   - 检查容器是否启动：`docker ps`，如果没启动，执行 `docker start frontend-container`
   - 检查服务器80端口是否被占用：`netstat -tuln | grep 80`，如果被占用，换个端口（比如 `-p 8080:80`，记得同步开放防火墙8080端口）
2. 访问显示Nginx默认页面（不是你的前端页面）：

   - 检查Dockerfile里的 `COPY` 命令是否正确（比如打包文件夹是build，却写了dist）
   - 重新构建镜像：`docker build -t frontend-image --no-cache .`（--no-cache清除缓存）
   - 重新启动容器：先删除旧容器 `docker rm -f frontend-container`，再重新执行 `docker run` 命令
3. Docker安装失败：

   - 确认系统是CentOS 7/8，如果是Ubuntu，命令略有不同（可以告诉我，我给Ubuntu专属命令）
   - 执行 `yum clean all` 后，重新执行Docker安装步骤

### 后续优化（可选）

1. 域名访问：买个域名，解析到服务器IP，再配置Nginx支持HTTPS（更安全）
2. 容器自动重启：`docker run` 时加 `--restart=always`，服务器重启后容器自动启动
3. 日志查看：`docker logs frontend-container`，查看前端访问日志或错误日志

按照以上步骤，基本能一次部署成功，如果遇到具体报错，可以截图或复制报错信息，我帮你排查！
